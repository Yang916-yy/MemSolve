\begin{abstract}
Gated Delta Networks (GDNs) learn and refine associations by writing
prediction errors back into memory. This error-correcting mechanism has
advanced causal sequence modeling.
In bidirectional settings, the model can access the entire context.
It can therefore build a shared memory from all positions.
Yet extending sequential error correction to this setting can be costly.
The direct full-attention DeltaNet formulation studied in LION requires a
sequence-sized matrix inverse. Its cubic cost undermines the efficiency
of a compact memory. We propose MemSolve, which constructs memory by directly
solving a joint error-correction problem over the full context.
Associations from all positions jointly determine a compact equilibrium state.
Each position then reads context from this shared memory.
Memory writes and reads depend on the entire context.
This allows information on both sides of a position to interact.
Locally parameterized bidirectional scans with linear merging cannot express
all such interactions. We prove that the equilibrium is unique and that the
readout is contractive for each fixed write--read frame.
To execute this global computation efficiently, we design a hardware-aware
parallel algorithm. It supports exact sequence parallelism across devices.
At fixed rank, computation scales linearly with sequence length.
With a simple non-hierarchical visual backbone, our Base model reaches
$82.7\%$ Top-1 on ImageNet-1K with $78$M parameters.
It exceeds Vim-B without extra fine-tuning by $0.8$ percentage points
with approximately $20\%$ fewer parameters.
It also surpasses Hydra-ViT-B by $1.1$ points.
Our Small model reaches $81.0\%$ with $20$M parameters.
Both results use EMA. After C4 masked-language pretraining, a parameter-matched
BERT-style encoder achieves an $81.9$ average of GLUE development task means.
\end{abstract}

\section{Introduction}

Error-correcting memories have strengthened causal sequence models
\cite{yang2025gdn,kimi2025linear,hatamizadeh2026gdn2}.
These models must retain useful associations in a limited state.
Self-attention retains an explicit context for retrieval
\cite{vaswani2017attention}. Linear attention and state-space models (SSMs)
compress that context into a fixed-size memory
\cite{katharopoulos2020linear,gu2024mamba}.
Within an associative memory, additive writes can interfere with stored
associations. The delta rule corrects this interference: it predicts
content from the current memory, then writes the prediction residual
\cite{schlag2021fastweights,yang2025deltanet}.
Gated Delta Networks (GDNs) combine this correction with adaptive forgetting
\cite{yang2025gdn}. Recent variants introduce channel-wise forgetting and
separate erase/write controls \cite{kimi2025linear,hatamizadeh2026gdn2}.
Together, these methods treat memory as an internal model that learns
from context. Test-time training (TTT) makes this perspective explicit
\cite{sun2025ttt}. MesaNet takes it further by solving for locally optimal
regression states \cite{vonoswald2026mesanet}.

In bidirectional settings, the complete context is available when memory
is constructed. All associations can therefore contribute to the same
state. This state can use evidence from both sides of any position,
without having to serve every intermediate prefix.
ViT$^3$ explores a related opportunity in vision: its full-batch inner
updates can outperform sequential mini-batch updates \cite{han2026vit3}.
However, additional inner steps increase cost and can impair stability.
A direct equilibrium would let all associations act jointly without
an inner iteration budget.

The challenge is to retain the efficiency of compact memory.
Vim, Hydra, and LION already offer efficient bidirectional context mixing
\cite{zhu2024vim,hwang2024hydra,afzal2025lion}.
For delta-rule memory, each correction also depends on the current state.
Removing the causal mask does not remove that dependence.
LION's Appendix~B.7 derives recurrent and chunkwise bidirectional DeltaNet
forms \cite{afzal2025lion}. Its direct full-attention expression, however,
requires a sequence-sized matrix inverse. The inversion costs cubic time:
doubling the sequence length multiplies that cost by eight.
A compact memory thus loses its efficiency advantage if the joint solve
grows with the sequence.

We introduce \textbf{MemSolve}, which constructs full-context memory
through a direct solve in compact memory space. Its design connects
joint error correction, controlled readout, and parallel computation.

\paragraph{Global Equilibrium ($\S$\ref{sec:method}, $\S$\ref{sec:stability}).}
MemSolve combines all associations in one residual equation.
An input-dependent soft frame sets the coordinates for writing and reading
memory. An accretive core makes the equation uniquely solvable.
We couple the frame to the regularizer, reducing the memory equation to
a learned core shared across inputs. We solve it directly and read the
state back through the same frame.
The readout adds a low-rank contextual correction to a content branch.
For each realized frame, we prove that the resulting token map is contractive.
Its exact spectrum can also be computed in compact space.

\paragraph{Beyond Directional Scans ($\S$\ref{sec:ssm}).}
MemSolve is not a reparameterization of a standard bidirectional SSM mixer
with local coefficients and a linear merge of the two directions.
Such a mixer adds a prefix response to a suffix response.
MemSolve instead normalizes its frame using the entire context.
Changing the suffix can therefore change how prefix content reaches a
token, even when that token is fixed. Theorem~\ref{thm:ssm} proves this
separation with a three-token counterexample.

\paragraph{Parallel Algorithm ($\S$\ref{sec:implementation}).}
The full context enters the solve through two compact sufficient statistics.
We compute these statistics in parallel, solve the compact system, and
read out each token independently. The forward pass exchanges only these statistics between sequence shards.
This partition preserves the operator exactly. The learned core is shared
across inputs and evaluated once per head per forward pass.
Selective fusion avoids storing the token-sized frame and reduces GPU
memory traffic. The total cost is linear in sequence length at fixed rank.

\paragraph{Architectures and Results ($\S$\ref{sec:experiments}).}
We use the same operator in plain visual backbones and a BERT-style encoder.
On ImageNet-1K, MemSolve-ViT-S and MemSolve-ViT-B reach
$81.0\%$ and $82.7\%$ Top-1 with $20$M and $78$M parameters, respectively.
Both results use EMA.
The Base model exceeds Vim-B without extra fine-tuning by $0.8$
percentage points with approximately $20\%$ fewer parameters.
The Small model also reaches the same validation accuracy in fewer
epochs than an author-released DeiT-S run.
The parameter-matched language encoder achieves an $81.9$ average of
GLUE development task means. Execution measurements show where
exact sequence parallelism improves training throughput.
Appendix~\ref{app:related} expands the connections to memory updates,
regression layers, and bidirectional sequence operators.

\section{MemSolve}
\label{sec:method}

MemSolve builds one memory from all positions. We first express this task
as joint error correction. We then choose the memory coordinates and
regularization so that the equilibrium has a compact, shared system.
Finally, we read the memory back to tokens with a controlled gain.
All equations describe one head with $N$ valid tokens, rank $r$, and
content width $h$.

\subsection[Correcting all associations together]{\raggedright Correcting all associations together}
\label{sec:joint-memory}

Let $C\in\R^{N\times h}$ contain the content to be stored, and let
$P\in\R^{N\times r}$ assign memory coordinates to each position.
A memory $U\in\R^{r\times h}$ predicts content as $PU$.
For row $p_i^\T$ of $P$ and row $c_i^\T$ of $C$, the prediction error is
$c_i^\T-p_i^\T U$. Writing all errors back gives
\begin{equation}
 P^\T(C-PU)=\sum_{i=1}^{N}p_i(c_i^\T-p_i^\T U).
 \label{eq:joint-residual}
\end{equation}
Each association is evaluated against the same memory. This is the
full-context counterpart of correcting associations one at a time.

To control the joint correction, we add a positive-definite regularizer
$\Gamma_X$ and a learned skew-symmetric coupling $\Omega$:
\begin{equation}
 \dot U=P^\T(C-PU)-\Gamma_X U-\Omega U.
 \label{eq:joint-field}
\end{equation}
The regularizer damps the memory. The skew term couples its coordinates
with zero contribution to memory energy: $\langle U,\Omega U\rangle_F=0$.
MemSolve obtains the memory by solving for the equilibrium of this field.
The next step is to construct $P$ and $\Gamma_X$ so that this solve is
well posed and its core can be shared across inputs.

\subsection{Constructing a compact equilibrium}
\label{sec:equilibrium}

A learned projection produces relation features $B\in\R^{N\times r}$
and content $C$ from the input $X$. We normalize the relations and define
\begin{equation}
 \begin{aligned}
 A&=B/\sqrt{N}, & R^\T R&=\I_r+A^\T A,\\
 P&=AR^{-1}, & Z&=P^\T C.
 \end{aligned}
 \label{eq:frame}
\end{equation}
where $R$ is the upper Cholesky factor with positive diagonal.
The normalization makes $A^\T A$ an average relation second moment.
The identity term keeps the factorization positive definite and ensures
$\norm{P}_2<1$. We call $P$ a \emph{soft frame}: it provides shared
write--read coordinates with bounded gain. Appendix~\ref{app:frame}
gives its singular values and geometry.

Each head learns a core shared across samples:
\begin{equation}
 J=LL^\T+\Omega,\qquad LL^\T\succ0,\qquad\Omega^\T=-\Omega.
 \label{eq:core}
\end{equation}
Its symmetric part is positive definite, so $J$ is strictly accretive.
We use a lower triangular $L$ with positive diagonal; the unconstrained
parameterization is given in Appendix~\ref{app:parameters}.
Choose the regularizer to match the frame:
\begin{equation}
 \Gamma_X=\I_r+LL^\T-P^\T P\succ0.
 \label{eq:gamma}
\end{equation}
Positivity follows from $P^\T P\prec\I_r$.
This choice cancels the frame Gram term in Eq.~\eqref{eq:joint-field}:
\begin{equation}
 \dot U=Z-(P^\T P+\Gamma_X+\Omega)U
       =Z-(\I_r+J)U.
 \label{eq:dynamics}
\end{equation}
The equilibrium and its reflected map are therefore
\begin{equation}
 \begin{aligned}
 U^\star&=(\I_r+J)^{-1}Z,\\
 F&=2(\I_r+J)^{-1}-\I_r\\
  &=(\I_r+J)^{-1}(\I_r-J).
 \end{aligned}
 \label{eq:solve}
\end{equation}
Here and below, inverse notation denotes a linear solve.
The learned $J$ and $F$ are shared across samples. Each input supplies its
own $P$, $Z$, and $U^\star$. Thus one core factorization serves the batch,
while the frame factorization remains input-dependent.
No inner iteration count or learning rate is needed.

The cancellation is a design choice: the frame and regularizer jointly
define the memory problem. When $\Omega=0$, the equilibrium minimizes
\begin{equation}
 \mathcal E_X(U)=\tfrac12\norm{PU-C}_F^2+
                    \tfrac12\tr(U^\T\Gamma_XU).
 \label{eq:objective}
\end{equation}
With nonzero $\Omega$, it solves a strongly monotone linear equation.
The same existence guarantee holds, although the field is no longer the
gradient of this scalar objective.

\subsection{Reading the memory back to tokens}
\label{sec:readout}

The equilibrium alone specifies a memory, not a token output.
We read it through the same coordinates used for writing.
First, form the reflected response $2U^\star-Z=FZ$.
This gives a contractive compact map $F$
(Theorem~\ref{thm:contraction}). Its parameterization covers every real
strict contraction in $r$ dimensions, including nonsymmetric maps.

We combine this contextual response with a content response:
\begin{align}
 Y&=\eta(\I_N-PP^\T)C+PFP^\T C\\
  &=\underbrace{\eta C}_{\text{content}}
    +\underbrace{P(F-\eta\I_r)P^\T C}_{\text{contextual correction}}.
 \label{eq:readout}
\end{align}
Here $\eta=\tanh(\eta_{\rm raw})\in(-1,1)$ is learned per head.
Equivalently, $Y=\eta C+P[2U^\star-(1+\eta)Z]$.
The factor two comes from the reflection in Eq.~\eqref{eq:solve}.
The paired terms in Eq.~\eqref{eq:readout} preserve the gain bound when
lifting $F$ to token space. Theorem~\ref{thm:contraction} makes this precise.
Head outputs are concatenated and passed through a learned output projection.

The default \textsc{Equilibrium} mode learns $F$ through $J$.
Setting $F=0$ gives \textsc{Complement}, which omits the core parameters:
\begin{equation}
 Y_{\rm com}=\eta(\I_N-PP^\T)C
            =\eta(\I_N+AA^\T)^{-1}C.
 \label{eq:complement}
\end{equation}
Complement still mixes context through $P$.
Neither $PP^\T$ nor $\I_N-PP^\T$ is an orthogonal projector. We initialize Equilibrium at $J=\I_r$, hence $F=0$, and use
$\eta=0.9$ in both modes. With matched remaining parameters, the modes
start from the same function. Equilibrium then learns the compact map,
while both modes learn the frame, content, output projection, and $\eta$.

\paragraph{Optional rotary value encoding.}
Relative position can enter through the content pathway without separating
write and read coordinates. Following RoVE \cite{garcia2026rove}, we rotate
content before aggregation and apply the inverse rotation at readout.
For column vectors $c_i$ and rotations $O_i=O(t_i)$ at positions $t_i$,
\begin{equation}
 y_i=\eta c_i+\sum_j D_{ij}O_i^\T O_j c_j,
 \qquad D=P(F-\eta\I_r)P^\T.
 \label{eq:rove-readout}
\end{equation}
At a fixed frequency scale, $O_i^\T O_j=O(t_j-t_i)$ encodes relative offset.
This extension adds no learned parameters and preserves the fixed-frame
gain bound. Appendix~\ref{app:rove} gives the compact computation and settings.

\section{Properties of the Operator}
\label{sec:theory}

The core equation determines whether memory exists; the readout determines
how it affects tokens. We analyze both in exact arithmetic for one head,
then distinguish the resulting input dependence from bidirectional scans.
Proofs are in Appendix~\ref{app:proofs}.

\subsection{A unique memory and a bounded readout}
\label{sec:stability}

\begin{proposition}[Well-posed memory]
\label{prop:solve}
Let $\mu=1+\sigma_{\min}(L)^2>1$. Then Eq.~\eqref{eq:dynamics} has the
unique equilibrium in Eq.~\eqref{eq:solve}, and
\begin{equation}
 \norm{(\I_r+J)^{-1}}_2\le\mu^{-1},\qquad
 \norm{(\I_r+J)^{-\T}}_2\le\mu^{-1}.
\end{equation}
Every trajectory obeys
\[\norm{U(t)-U^\star}_F\le e^{-\mu t}\norm{U(0)-U^\star}_F.\]
\end{proposition}

The same bound controls right-hand-side perturbations in the forward and
adjoint solves. It does not depend on the number of tokens.

\begin{theorem}[Contractive compact and token maps]
\label{thm:contraction}
The map $F$ in Eq.~\eqref{eq:solve} satisfies
\begin{equation}
 \I_r-F^\T F=4(\I_r+J)^{-\T}LL^\T(\I_r+J)^{-1}\succ0.
\end{equation}
For a realized frame $P$, define
\begin{equation}
 K_X=\eta(\I_N-PP^\T)+PFP^\T.
 \label{eq:tokenmap}
\end{equation}
Then
$\norm{K_X}_2\le\max\{|\eta|,\norm{F}_2\}<1$ and
$\rank(K_X-\eta\I_N)\le r$.
Moreover, $K_Xv=\eta v$ for every $v\in\ker(P^\T)$.
\end{theorem}

This makes the division of work explicit: the content path preserves a
scaled response outside the relation span, while the learned core changes
interactions within that span. Sharing the write and read frame does not
force symmetry: when $F$ is nonsymmetric, $PFP^\T$ may be nonsymmetric too.
The accretive Cayley parameterization covers every real strict contraction
in $r$ dimensions (Appendix~\ref{app:coverage}); the rank and shared-frame
structure still constrain the token operator.

The norm statement holds for a fixed realized frame: it bounds the content
map $C\mapsto K_XC$, rather than the derivative through $P(X)$ or the
surrounding residual block.

The exact singular values of the token map can also be recovered from a
matrix of size at most $r$. Appendix~\ref{app:spectrum} gives this compact
representation and its proof.

\subsection{Interactions across both sides of a token}
\label{sec:ssm}

Global frame normalization lets one side of a token change how the other
side is read. A three-token example shows this directly. Set
$A=(1,1,t)^\T$, $C=(s,0,0)^\T$, $F=0$, and $\eta\ne0$.
Equation~\eqref{eq:complement} gives
\begin{equation}
 y_2=-\frac{\eta s}{3+t^2}.
 \label{eq:cross-context}
\end{equation}
The center token is fixed. Yet changing the suffix variable $t$ changes
the coefficient of the prefix content $s$.

A locally parameterized bidirectional state-space mixer has the form
\begin{equation}
 \begin{aligned}
 h_i^+&=A^+(x_i)h_{i-1}^++b^+(x_i),\\
 h_i^-&=A^-(x_i)h_{i+1}^-+b^-(x_i),\\
 y_i&=C^+(x_i)h_i^++C^-(x_i)h_i^-+d(x_i).
 \end{aligned}
 \label{eq:ssm-class}
\end{equation}
Its boundary states are input-independent. The coefficients may be
nonlinear functions of the current token, and the state dimension is
unrestricted. Once $x_i$ is fixed, the output separates into
$y_i=f_i(x_{1:i})+g_i(x_{i:N})$. Changing the suffix cannot change the
prefix response. This additive structure cannot express
Eq.~\eqref{eq:cross-context} for all $s,t$.

\begin{theorem}[Separation from locally parameterized bidirectional SSMs]
\label{thm:ssm}
For every positive rank $r$, the MemSolve family contains a map that cannot
be represented by Eq.~\eqref{eq:ssm-class} for all inputs, irrespective of
that mixer's state dimension. The result holds for both Equilibrium and
Complement.
\end{theorem}

Appendix~\ref{app:ssm} proves the result by a mixed finite difference and
extends the example to any rank. The theorem concerns individual mixers
with local coefficients and linear directional merging. Stacks, nonlinear
merges, and globally conditioned coefficients define different model classes.

\section{Hardware-Aware Parallel Computation}
\label{sec:implementation}

A compact memory alone does not guarantee efficient execution.
Materializing the frame adds token-sized storage and memory traffic.
We instead reduce the input to two compact statistics, solve in memory
space, and read out token rows in parallel.

\subsection{Reduce, solve, and read out}

Substituting $P=AR^{-1}$ into Eq.~\eqref{eq:readout} gives
\begin{equation}
 \begin{aligned}
 G&=A^\T A,\qquad H=A^\T C,\\
 R^\T R&=\I_r+G,\qquad Z=R^{-\T}H,\\
 W&=R^{-1}(F-\eta\I_r)Z,\\
 Y&=\eta C+AW.
 \end{aligned}
 \label{eq:nop}
\end{equation}
Only $G$ and $H$ aggregate information across tokens.
Once $W$ is available, each output row depends only on its local $A,C$.
Algorithm~\ref{alg:compact-forward} gives this computation.
Equilibrium and Complement use the same steps; Complement takes $F=0$.

\begin{algorithm}[H]
\caption{MemSolve: compact forward computation (one sample and head)}
\label{alg:compact-forward}
\begin{algorithmic}[1]
\Require Relations $B\in\R^{N\times r}$, content $C\in\R^{N\times h}$;
 shared $F$, scalar $\eta$; $N>r$ valid tokens
\Ensure Token output $Y\in\R^{N\times h}$
\State $A\gets B/\sqrt N$
\State $G\gets A^\T A$; $H\gets A^\T C$ \Comment{Parallel token reductions}
\State $R\gets\Chol(\I_r+G)$ \Comment{$R^\T R=\I_r+G$}
\State $Z\gets\Solve(R^\T,H)$
\State $W\gets\Solve(R,(F-\eta\I_r)Z)$
\State \Return $\eta C+AW$ \Comment{Parallel token readout}
\end{algorithmic}
\end{algorithm}

The learned $F$ is evaluated once per head in each forward pass.
Each sample then requires $O(Nr^2+Nrh+r^3+r^2h)$ arithmetic and
$O(r^2+rh)$ compact storage per head. Token storage is linear in $N$.
Input and output projections also have linear sequence cost at fixed width.
For physical length $N\le r$, an equivalent token-space solve avoids
subtraction in the complementary term. Its dimension is at most $r$.
Appendix~\ref{app:forward} gives both length regimes and padding handling.

\subsection{Exact sequence parallelism}

The two statistics are sums over token rows. Partition those rows across
$p$ devices, using the same global valid count $N$ to normalize each shard:
\begin{equation}
 \begin{gathered}
 A_s=B_s/\sqrt N,\\
 G=\sum_{s=1}^{p}A_s^\T A_s,\qquad
 H=\sum_{s=1}^{p}A_s^\T C_s.
 \end{gathered}
 \label{eq:sequence-parallel}
\end{equation}
A sum reduction gives each device the centralized $G,H$.
Each device computes the same $W$ and reads out its own rows as
$Y_s=\eta C_s+A_sW$. The statistic payload is $O(r^2+rh)$ per sample and
head, independent of sequence length. No token activation gather is needed.

The backward pass likewise reduces a compact readout adjoint before
computing local token gradients. Outputs and reduced gradients equal the
unsharded computation in real arithmetic; floating-point reduction order
can change rounding. Algorithm~\ref{alg:sequence-parallel} specifies the
reductions and the treatment of shared parameter gradients.

\subsection{Selective fusion}

The main memory traffic comes from token projections, statistics, and
readout. We fuse token operations around their compact intermediates and
keep factorizations separate. This avoids storing $P$ and lets the
factorizations use specialized solvers. The backward pass reuses compact
factors. It also reduces core gradients across the batch without storing
one core adjoint per sample.

The GPU implementation uses Triton for tiled token operations, cuSOLVERDx
for compact factorizations, and cuBLASLt for projection gradients.
Compact solves and adjoints retain FP32 storage.
The readout splits sensitive coefficients into a BF16 leading word and a
BF16 residual word \cite{henry2019bfloat}. Both products accumulate in FP32
before output rounding. This improves coefficient precision while retaining
Tensor Core products. Appendix~\ref{app:precision} specifies precision,
scheduling, and the surrounding compilation and CUDA Graph execution.

\section{Experiments}
\label{sec:experiments}

We evaluate whether the same equilibrium operator supports visual
recognition and bidirectional language modeling, and whether its sufficient
statistics provide useful sequence parallelism. All MemSolve models below
use Equilibrium unless explicitly labeled Complement.
The reported experiments do not enable the optional RoVE extension.

\subsection{ImageNet classification}

\paragraph{Model and protocol.}
MemSolve-ViT is a non-hierarchical backbone with non-overlapping
$16\times16$ patches and twelve constant-width blocks. Each block adds
residual $3\times3$ depthwise CPE \cite{chu2023cpe}, then applies pre-LayerNorm MemSolve and
GELU FFN branches with residual connections and stochastic depth
(Fig.~\ref{fig:visual-backbone}). A final token-wise LayerNorm precedes mean
pooling and a linear classifier. We report completed Small and Base runs;
Appendix~\ref{app:vision} gives the model configurations.

\begin{figure*}[t]
\centering
\includegraphics[width=5.8in]{visual_backbone.pdf}
\caption{\textbf{MemSolve-ViT.}
The constant-width backbone stacks twelve blocks and uses mean pooling.
The expanded block has three residual branches: depthwise CPE,
pre-LayerNorm MemSolve, and pre-LayerNorm GELU FFN.
Stochastic depth on the latter two branches is omitted.}
\label{fig:visual-backbone}
\end{figure*}

We train from scratch on ImageNet-1K \cite{russakovsky2015imagenet} for
300 epochs at $224\times224$ with a recipe derived from plain ViT$^3$.
Both models use AdamW, cross-entropy, Mixup/CutMix, RandAugment, and
repeated augmentation, with global batch 2,048 and peak learning rate
$2\times10^{-3}$. We evaluate EMA weights with decay $0.9999$ and report
the checkpoint with the highest validation Top-1.
Validation uses bicubic resize to a shorter side of 256 and a
$224\times224$ center crop. Appendix~\ref{app:vision} gives the full recipe.

\subsection{Masked language modeling and GLUE}
\label{sec:language}

\paragraph{A parameter-matched encoder.}
We replace BERT's attention mixer with MemSolve in a 14-layer encoder with
width 768, twelve heads, rank 32, and a SwiGLU FFN with intermediate width
2,048 per branch. It has 112M parameters including the tied MLM head,
close to the 110M BERT-Base scale \cite{devlin2019bert}.
The model uses BERT's post-LayerNorm residual structure and learned
absolute positions. A centered residual depthwise convolution of width
three precedes the relation/content projection in every layer. It starts
as the identity and receives only the corrupted MLM input. The completed
model does not use rotary encoding.

\paragraph{Pretraining.}
We follow the LION/M2-derived C4 masked-language setup
\cite{raffel2020t5,afzal2025lion}: sequence length 128, global batch 4,096,
70,000 optimizer steps, and training mask probability $0.30$.
Local C4 files are streamed and documents are individually truncated;
independent documents are not packed into one attention context.
AdamW uses peak learning rate $8\times10^{-4}$, $6\%$ linear warmup,
and linear decay to $2\%$ of the peak, following the public code setting.
Appendix~\ref{app:nlp} states the optimizer conversion and differences from
the paper description. On a fixed 10,000-document validation subset with
$15\%$ masking, the selected checkpoint reaches $66.4\%$ masked-token
accuracy and masked-token NLL $1.6211$ over 169,544 targets. The complete
run takes 31.80 hours on two A800-80GB GPUs, including scheduled validation
and checkpointing.

\paragraph{Downstream evaluation.}
We fine-tune on eight GLUE tasks using the LION paper's M2-BASE task
hyperparameters \cite{wang2019glue,afzal2025lion}. MNLI, QQP, QNLI,
SST-2, and CoLA start from the MLM checkpoint; RTE, MRPC, and STS-B start
from the fine-tuned MNLI encoder. All tasks use length 128 and final-checkpoint
development evaluation. We repeat the smaller tasks with three to five
seeds while retaining one run for MNLI, QQP, and QNLI.



MemSolve achieves an average of $81.9$ (Table~\ref{tab:glue}).
This exceeds the reported LION M2-BASE aggregates and is $0.4$ points
below the reported BERT aggregate. Relative to BERT, RTE has the largest
gain and CoLA the largest shortfall.
Appendix~\ref{app:glue} reports each task's seed count and standard deviation.
The average combines task means from different numbers of fine-tuning runs.

\section{Discussion and Limitations}

MemSolve concentrates contextual changes in a learned relation span.
Rank controls the number of modified directions and the cost of the compact
systems. Outside that span, the operator retains a scalar content response.
Sharing write and read coordinates supports the contraction guarantee,
but it also ties where information is stored to where it is retrieved.
These choices define the operator's capacity and computational tradeoff.

The experiments show that this construction learns useful representations
in vision and language. Length generalization remains unresolved. The language experiments train
and fine-tune at 128 tokens with learned absolute positions.
The sequence-parallel benchmark establishes execution scaling, while task
accuracy beyond the training length remains to be measured.
ImageNet and MLM pretraining each use one seed per configuration.
Repeated GLUE runs measure fine-tuning variation from a shared pretrained model.

\section{Conclusion}

MemSolve constructs full-context associative memory by solving a joint
error-correction equilibrium. Its frame and regularizer reduce the memory
equation to a shared compact core. The reflected readout gives a contractive
token map for each fixed frame. Global normalization also couples evidence
across both sides of a token, beyond the additive responses of locally
parameterized bidirectional scans.
Two compact statistics make this construction linear in sequence length
at fixed rank and support exact sequence parallelism.
The visual and language results demonstrate its use as a general token mixer.

\section{Proofs and Structural Details}
\label{app:proofs}

We first establish the frame geometry. It gives the positive regularizer
used in the memory equation. We then prove existence, contraction, and
the compact spectrum, followed by the bidirectional-scan separation.

\subsection{Soft-frame geometry}
\label{app:frame}

Since $R^\T R=\I+A^\T A$,
\begin{equation}
 PP^\T=A(\I+A^\T A)^{-1}A^\T.
\end{equation}
An SVD of $A$ gives
\begin{equation}
 \sigma_i(P)=\frac{\sigma_i(A)}{\sqrt{1+\sigma_i(A)^2}}<1.
 \label{eq:soft-singular}
\end{equation}
In particular,
$P^\T P\prec\I_r$ and $PP^\T\prec\I_N$, including rank-deficient cases.
The Woodbury identity yields
\begin{equation}
 \I_N-PP^\T=(\I_N+AA^\T)^{-1}\succ0,
\end{equation}
which proves Eq.~\eqref{eq:complement} and positivity of $\Gamma_X$.
The reduced QR factorization of $[A^\T,\I_r]^\T$ with a positive diagonal
in its triangular factor has top block $P$. Thus the QR reference and the
compact Cholesky construction agree in exact arithmetic.

The $\sqrt N$ normalization controls the scale of the relation statistic. If
$N^{-1}\sum_i\norm{b_i}_2^2\le c$, then
$\norm{A}_2^2\le\norm{A}_F^2\le c$ and
$\kappa_2(\I+A^\T A)\le1+c$, independently of $N$.
Under this feature-energy bound, the condition number does not grow with
sequence length. Accuracy at unseen lengths is a separate empirical question.

Without a positional module, the operator is permutation equivariant:
permuting the rows of $A,C$ leaves $G,H$ unchanged and permutes the rows
of $Y$. The visual and language backbones therefore supply position
information outside the core operator.

\subsection{Memory existence, sensitivity, and convergence}

Write $M=\I_r+J$. For every real $v$,
\begin{equation}
 v^\T Mv=v^\T(\I_r+LL^\T)v\ge\mu\norm{v}_2^2,
 \qquad \mu=1+\sigma_{\min}(L)^2.
\end{equation}
Cauchy--Schwarz gives $\norm{Mv}_2\ge\mu\norm{v}_2$, so $M$ is invertible
and $\norm{M^{-1}}_2\le1/\mu$. The same argument applies to $M^\T$.
For $E(t)=U(t)-U^\star$, $\dot E=-ME$ and
\begin{equation}
 \frac{d}{dt}\norm{E}_F^2
 =-2\tr(E^\T(\I_r+LL^\T)E)\le-2\mu\norm{E}_F^2.
\end{equation}
Integration proves Proposition~\ref{prop:solve}.
For $\Omega=0$, differentiating Eq.~\eqref{eq:objective} gives
$\nabla_U\mathcal E_X=MU-Z$ and Hessian $M\succ0$ for each content column.
When $\Omega\ne0$, the nonsymmetric field need not be a scalar gradient,
although the same convergence argument holds.

\subsection{Cayley contraction and coverage}
\label{app:coverage}

As $M=\I+J$ commutes with $\I-J$,
\begin{align}
 \I-F^\T F
 &=M^{-\T}\left[M^\T M-(\I-J)^\T(\I-J)\right]M^{-1}\\
 &=2M^{-\T}(J+J^\T)M^{-1}
 =4M^{-\T}LL^\T M^{-1}\succ0.
\end{align}
Conversely, let $F_0$ be any real matrix with $\norm{F_0}_2<1$.
Then $\I+F_0$ is invertible and
\begin{equation}
 J_0=(\I-F_0)(\I+F_0)^{-1},\qquad
 \sym(J_0)=(\I+F_0)^{-\T}(\I-F_0^\T F_0)(\I+F_0)^{-1}\succ0.
\end{equation}
Factor $\sym(J_0)=LL^\T$ and set
$\Omega=(J_0-J_0^\T)/2$. The triangular/softplus parameterization can
represent every such $L$ and $\Omega$. This is the classical accretive--Cayley correspondence
\cite{bauschke2017convex}. It establishes coverage of all real strict
contractions in compact space; the token map retains its shared-frame
and rank constraints.

\subsection{Token contraction and the exact compact spectrum}
\label{app:spectrum}

Let $D=(\I_N-PP^\T)^{1/2}$ and
$V_0=[D^\T,P]^\T\in\R^{(N+r)\times N}$, so $V_0^\T V_0=\I_N$.
Then
\begin{equation}
 K_X=V_0^\T\diag(\eta\I_N,F)V_0,
\end{equation}
which proves the norm bound in Theorem~\ref{thm:contraction}.
The rank and nullspace statements follow directly from
$K_X-\eta\I_N=P(F-\eta\I_r)P^\T$.

\begin{proposition}[Exact analysis in compact space]
\label{prop:spectrum}
Let $P=Q S V^\T$ be a thin singular value decomposition with
$k=\rank(P)$, $Q^\T Q=V^\T V=\I_k$, and positive diagonal $S$.
The token map is orthogonally similar to
\begin{equation}
 \left[\eta\I_k+S V^\T(F-\eta\I_r)V S\right]
       \oplus\eta\I_{N-k}.
 \label{eq:certificate}
\end{equation}
Its singular values, including its exact spectral norm, can therefore be
obtained from a matrix of size at most $r$, together with $N-k$ copies of
$|\eta|$.
\end{proposition}

To prove the proposition, extend $Q$ to an orthogonal basis
$[Q,Q_\perp]$. In this basis the low-rank correction acts only on the first
$k$ coordinates, giving Eq.~\eqref{eq:certificate}. If $k=0$, the result is
simply $\eta\I_N$; if $k=N$, the complementary block is absent.
One may compute $V$ and $S$ from the positive eigenspace of $P^\T P$, so no
$N\times N$ matrix or token-space SVD is required.

\subsection{Proof of the bidirectional SSM separation}
\label{app:ssm}

Fix the center token $x_i$ in Eq.~\eqref{eq:ssm-class}. Recursion with
input-independent boundary states gives
$y_i=f_i(x_{1:i})+g_i(x_{i:N})$. For any prefix perturbation $s$ and suffix
perturbation $t$ that leave $x_i$ fixed, its mixed finite difference is
\begin{equation}
 \Delta_{s,t}y_i
 =y_i(s_1,t_1)-y_i(s_1,t_0)-y_i(s_0,t_1)+y_i(s_0,t_0)=0.
 \label{eq:mixed-difference}
\end{equation}
This conclusion holds for arbitrary coefficient functions and state size.

For MemSolve, take three tokens whose two coordinates independently
control relation and content:
$x_1=(1,s)$, $x_2=(1,0)$, and $x_3=(t,0)$.
A fixed relation projection with scale $\sqrt3$ gives
$A=(1,1,t)^\T$ after the normalization in Eq.~\eqref{eq:frame}; a content
projection gives $C=(s,0,0)^\T$. With $F=0$,
\begin{equation}
 PP^\T=\frac{AA^\T}{1+A^\T A},\qquad
 y_2=-\frac{\eta s}{3+t^2}.
\end{equation}
At $(s_0,s_1)=(0,1)$ and $(t_0,t_1)=(0,1)$,
\begin{equation}
 \Delta_{s,t}y_2=-\frac{\eta}{4}+\frac{\eta}{3}
 =\frac{\eta}{12}\ne0.
\end{equation}
Therefore no mixer of Eq.~\eqref{eq:ssm-class} represents this MemSolve
map for all inputs. For any larger rank, append zero relation columns;
the first Cholesky coordinate and the output above remain unchanged.
Complement sets $F=0$ by definition, and Equilibrium realizes $F=0$ at
$J=\I_r$. This proves Theorem~\ref{thm:ssm}.

The distinction concerns how inputs determine the map, not the rank of a
matrix after fixing the input. A realized MemSolve matrix is low rank plus
a diagonal and can admit other algebraic factorizations. Such a
factorization does not supply the local coefficient dependence required
by Eq.~\eqref{eq:ssm-class}.

\section{Algorithms and Numerical Details}
\label{app:implementation}

This appendix gives the core parameterization, the masked forward pass,
and the analytic backward. It then specifies sequence-parallel reductions
and floating-point execution. The pseudocode describes exact arithmetic;
Section~\ref{app:precision} explains how the GPU kernels evaluate it.

\subsection{Core parameters and initialization}
\label{app:parameters}

Each head stores an unconstrained matrix $\Theta\in\R^{r\times r}$.
Its lower and upper entries define the symmetric and skew parts of $J$:
\begin{align}
 L&=\tril(\Theta,-1)+\diag\!\left(
    \operatorname{softplus}(\diag\Theta+\log(e-1))\right),\\
 \Omega&=\triu(\Theta,1)-\triu(\Theta,1)^\T,\qquad J=LL^\T+\Omega.
 \label{eq:core-parameters}
\end{align}
The diagonal of $L$ is positive, so $LL^\T\succ0$.
At $\Theta=0$, $L=\I_r$, $J=\I_r$, and $F=0$.
This initialization preserves the core's training signal:
$\delta F=-\tfrac12\delta J$ at $J=\I_r$.
The initial learned correction is zero, but its derivative need not be.

The per-head scalar is parameterized by $\eta=\tanh(\eta_{\rm raw})$ and
initialized to $0.9$. Floating-point execution uses
\begin{equation}
 \eta_{\rm fp}=(1-\epsilon_{\rm mach})\tanh(\eta_{\rm raw}),\qquad
 \frac{d\eta_{\rm fp}}{d\eta_{\rm raw}}
 =(1-\epsilon_{\rm mach})\frac{4q}{(1+q)^2},\quad
 q=e^{-2|\eta_{\rm raw}|}.
 \label{eq:eta-numerical}
\end{equation}
The scale keeps the value inside $(-1,1)$.
Native $\tanh$ preserves small values near zero; the exponential derivative
retains representable tail gradients after $\tanh$ rounds to an endpoint.

\subsection{Forward computation}
\label{app:forward}

Algorithm~\ref{alg:forward} expands Algorithm~\ref{alg:compact-forward}
to masked batches and short sequences. The input and output projections
are ordinary affine layers. Head outputs are concatenated, projected, and
masked again so that output bias cannot populate padding.

Physical length is $N$; sample $b$ has $n_b$ valid tokens.
Masks multiply rows and are fixed under differentiation. An all-masked
sample uses a divisor of one and produces zero.
We use $\Solve(M,V)$ for the solution of $MU=V$ and $\Chol(S)$ for the
upper factor $R$ satisfying $R^\T R=S$. Thus
\begin{equation}
 \CholSolve(R,V)=\Solve\!\left(R,\Solve(R^\T,V)\right).
 \label{eq:cholsolve}
\end{equation}
A general core system uses LU factorization. For $N\le r$, the
complementary term uses the equivalent solve
$\eta\Solve(\I_N+AA^\T,C)$. This avoids subtracting nearly equal terms
in $\eta(C-PP^\T C)$. Equilibrium adds its learned correction to that result.
The largest factorization has dimension at most $r$ in either regime.

\begin{algorithm}[!ht]
\caption{MemSolve forward without materializing $P$ (one head)}
\label{alg:forward}
\small
\begin{algorithmic}[1]
\Require $\{B_b\in\R^{N\times r},C_b\in\R^{N\times h},m_b\in\{0,1\}^N\}_{b=1}^{s}$;
 mode, $\eta$; $\Theta\in\R^{r\times r}$ for Equilibrium
\Ensure Head outputs $\{Y_b\in\R^{N\times h}\}_{b=1}^{s}$
\If{mode is Equilibrium}
  \State Construct $L,\Omega,J$ from $\Theta$ using Eq.~\eqref{eq:core-parameters}
  \State $M\gets\I_r+J$; factor $M$ once
  \State $F\gets\Solve(M,\I_r-J)$ \Comment{Shared across this batch}
\Else
  \State $F\gets0$ \Comment{Complement}
\EndIf
\For{each sample $b$ in parallel}
  \State $n_b\gets\sum_i m_{b,i}$; $A\gets(m_b\odot B_b)/\sqrt{\max(n_b,1)}$; $C\gets m_b\odot C_b$
  \If{$N\le r$} \Comment{Physical length determines the branch}
    \State $R_N\gets\Chol(\I_N+AA^\T)$; $Y_b\gets\eta\,\CholSolve(R_N,C)$
    \If{mode is Equilibrium}
      \State $R\gets\Chol(\I_r+A^\T A)$; $Z\gets\Solve(R^\T,A^\T C)$
      \State $Y_b\gets Y_b+A\Solve(R,FZ)$
    \EndIf
  \Else
    \State $G\gets A^\T A$; $H\gets A^\T C$; $R\gets\Chol(\I_r+G)$
    \State $Z\gets\Solve(R^\T,H)$; $W\gets\Solve(R,(F-\eta\I_r)Z)$
    \State $Y_b\gets\eta C+AW$
  \EndIf
\EndFor
\State \Return $\{Y_b\}_{b=1}^{s}$
\end{algorithmic}
\end{algorithm}

For $N>r$, the backward below uses $A,C,R,W,Z$ and the shared $F$.
Implementations can save these values or reconstruct them from projections
and compact intermediates. Equilibrium also reuses $L$ and the LU factors
of $\I_r+J$. No token-sized frame is needed.
For $N\le r$, automatic differentiation handles the short-sequence
expression, with an analytic adjoint for the shared core solve.

\subsection{A common compact backward}
\label{app:backward}

Algorithm~\ref{alg:backward} differentiates Eq.~\eqref{eq:nop} for one
sample and head. It applies to both modes: set $F=0$ for Complement and
discard the adjoint of this fixed matrix. A bar denotes a loss adjoint
under the Frobenius inner product, and $\sym(T)=(T+T^\T)/2$.
The algorithm includes both the direct content term and the correction.
Their contributions to $C$ and $\eta$ are added before returning.
Projection gradients follow the usual affine-layer rules.

For an upper Cholesky factor $R$, define
\begin{equation}
 \Phi_u(T)=\triu(T,1)+\tfrac12\diag(\diag T),\qquad
 \mathcal C(R,E_R)=R^{-1}\sym\!\left(\Phi_u(E_RR^\T)\right)R^{-\T}.
 \label{eq:chol-adjoint}
\end{equation}
Here $\mathcal C$ is the adjoint of $R=\Chol(S)$ with respect to the
symmetric matrix $S$; the inverse notation again means two triangular
solves. To obtain it, differentiate $S=R^\T R$ and observe that
$dR=\Phi_u(R^{-\T}(dS)R^{-1})R$. This also fixes the half-diagonal
convention in Eq.~\eqref{eq:chol-adjoint}.

\begin{algorithm}[!ht]
\caption{Rank-space backward ($N>r$, one sample and head)}
\label{alg:backward}
\small
\begin{algorithmic}[1]
\Require $E=\overline Y\in\R^{N\times h}$; forward values $A,C,R,W,Z,F,\eta$;
 fixed mask $m$ and valid count $n$
\Ensure $\overline B,\overline C_{\rm in}$; contributions $\overline\eta,\overline F$
\State $E_W\gets A^\T E$; $\overline A\gets EW^\T$; $\overline C\gets\eta E$
\State $\overline\eta\gets\langle E,C\rangle_F$
\State $E_T\gets\Solve(R^\T,E_W)$
\State $\overline F\gets E_TZ^\T$; $\overline\eta\gets\overline\eta-\langle E_T,Z\rangle_F$
\State $\overline Z\gets(F-\eta\I_r)^\T E_T$; $\overline H\gets\Solve(R,\overline Z)$
\State $\overline R\gets-E_TW^\T-Z\overline H^\T$
\State $\overline G\gets\mathcal C(R,\overline R)$ \Comment{Eq.~\eqref{eq:chol-adjoint}}
\State $\overline A\gets\overline A+C\overline H^\T+A(\overline G+\overline G^\T)$
\State $\overline C\gets\overline C+A\overline H$
\State $\overline B\gets m\odot\overline A/\sqrt{\max(n,1)}$
\State $\overline C_{\rm in}\gets m\odot\overline C$
\State \Return $\overline B,\overline C_{\rm in},\overline\eta,\overline F$
\end{algorithmic}
\end{algorithm}

\paragraph{Reusing the inverse triangular factor.}
The GPU path computes $T=R^{-\T}$ once and reuses it in forward and backward
products. The compact derivatives above can be evaluated directly in terms
of $T$. Let $M_F=F-\eta\I_r$, $E_T=TE_W$, and $V=E_TZ^\T$. Then
\begin{align}
 \overline H&=T^\T M_F^\T E_T,\\
 \overline G&=T^\T\operatorname{sym}_{\ell}
       (-M_FV^\T-M_F^\T V)T,
 \label{eq:inverse-factor-adjoint}
\end{align}
where $\operatorname{sym}_{\ell}(K)=[\tril(K)+\tril(K,-1)^\T]/2$.
The core and scalar contributions reuse $V$:
$\overline F=V$ and $\overline\eta=\langle E,C\rangle_F-\tr(V)$.
This form shares the same compact adjoint between Equilibrium and Complement.

\subsection{Shared-core and scalar gradients}
\label{app:core-backward}

Write $M=\I_r+J$.
For $F=M^{-1}(\I-J)$, differentiation gives
\begin{equation}
 dF=-M^{-1}(dJ)(\I+F).
 \label{eq:core-differential}
\end{equation}
Since the core is shared, its adjoints are summed over samples before the
transposed solve in Algorithm~\ref{alg:core-backward}. The reduction is a
sum: any loss averaging is already contained in $\overline Y$. The fast
path accumulates this reduction in tiles rather than storing one
$r\times r$ core adjoint per sample.

\begin{algorithm}[!ht]
\caption{Shared-core backward (once per head, Equilibrium only)}
\label{alg:core-backward}
\small
\begin{algorithmic}[1]
\Require $E_F=\sum_b\overline F_b$; $\Theta,L,F$ and the saved factorization of $M=\I_r+J$
\Ensure Core-parameter gradient $\overline\Theta\in\R^{r\times r}$
\State $T\gets\Solve(M^\T,E_F)$ \Comment{Reuse the forward LU factors}
\State $\overline J\gets-T(\I_r+F)^\T$
\State $\overline L\gets(\overline J+\overline J^\T)L$
\State $d\gets\diag(\overline L)\odot\operatorname{sigmoid}(\diag\Theta+\log(e-1))$
\State $\overline\Theta\gets\tril(\overline L,-1)+\diag(d)+\triu(\overline J-\overline J^\T,1)$
\State \Return $\overline\Theta$
\end{algorithmic}
\end{algorithm}

For either mode, sum the scalar adjoints over samples before applying
$\overline{\eta_{\rm raw}}=(d\eta/d\eta_{\rm raw})\sum_b\overline\eta_b$.
For the mathematical parameterization, $d\eta/d\eta_{\rm raw}
=1-\tanh^2(\eta_{\rm raw})$.
The fast path provides first-order training gradients.

\subsection{Sequence-parallel reductions}
\label{app:parallel}

Algorithm~\ref{alg:sequence-parallel} expresses the operator for a sum of
local losses. A global mean is obtained by normalizing every local loss
with the same global denominator. $\operatorname{VJP}_W$ denotes the
adjoint of $(G,H,F,\eta)\mapsto W$ in Eq.~\eqref{eq:nop}.
It is the compact part of Algorithm~\ref{alg:backward} and excludes
the direct term $\eta C$.
A sum reduction of $E_W$ gives every device the same compact adjoints.
Shared $F,\eta$ gradients are therefore already global and must be counted
once. The implementation divides their replicated contributions by the
number of devices before the final parameter-gradient sum.

\begin{algorithm}[!ht]
\caption{Exact sequence-parallel MemSolve (one sample and head)}
\label{alg:sequence-parallel}
\small
\begin{algorithmic}[1]
\Require Local rows $B_s,C_s$, mask $m_s$; replicated $F,\eta$; $p$ devices;
 global physical length $N>r$
\Ensure Local output $Y_s$, local input gradients, and global parameter gradients
\State $n\gets\operatorname{AllReduceSum}(\sum_i m_{s,i})$
\State $A_s\gets(m_s\odot B_s)/\sqrt{\max(n,1)}$; $C_s\gets m_s\odot C_s$
\State $(G,H)\gets\operatorname{AllReduceSum}(A_s^\T A_s,A_s^\T C_s)$
\State $R\gets\Chol(\I_r+G)$; $Z\gets\Solve(R^\T,H)$
\State $W\gets\Solve(R,(F-\eta\I_r)Z)$; $Y_s\gets\eta C_s+A_sW$
\State \textbf{Backward:} receive local output adjoint $E_s$
\State $E_W\gets\operatorname{AllReduceSum}(A_s^\T E_s)$
\State $(\overline G,\overline H,\overline F,\overline\eta_W)
  \gets\operatorname{VJP}_W(G,H,F,\eta;E_W)$
\State $\overline A_s\gets E_sW^\T+C_s\overline H^\T+A_s(\overline G+\overline G^\T)$
\State $\overline C_s\gets\eta E_s+A_s\overline H$
\State $\overline\eta\gets\operatorname{AllReduceSum}(\langle E_s,C_s\rangle_F)+\overline\eta_W$
\State $\overline B_s\gets m_s\odot\overline A_s/\sqrt{\max(n,1)}$;
 $\overline C_{{\rm in},s}\gets m_s\odot\overline C_s$
\State Backpropagate local projection gradients and sum them across devices
\State Apply the shared-core adjoint to $\overline F$ once; retain one copy of $\overline\eta$
\end{algorithmic}
\end{algorithm}

The proof is the additivity of $G,H$ in the forward pass and the chain
rule in the backward pass. No recurrence connects neighboring sequence
shards. In a backbone with a centered convolution, that local operation
requires a separate halo exchange; it does not change the memory reduction.
The implemented sequence-parallel path uses the compact formulation and
requires global physical length greater than the operator rank.

\subsection{Precision and scheduling}
\label{app:precision}
The fast path supports ranks 16, 32, 48, and 64. Token projections and
statistics use BF16 multiplicands and FP32 accumulation.
Gram matrices, compact states, factors, and adjoints retain FP32 storage.
Batched compact products use Triton's three-term TF32 decomposition;
small shared-core products and solves retain IEEE FP32 arithmetic.
Readout kernels split sensitive FP32 coefficients into BF16 leading and
residual words before accumulating both products in FP32.
The extra product recovers coefficient precision without using FP32
operands for token-sized products. With very sparse masks and strong
relations, cancellation can still amplify relative error in the compact
complementary readout.

\paragraph{Measured implementation scope.}
The completed training runs used NVIDIA A800-SXM4-80GB GPUs, PyTorch
2.14.0 with CUDA 13.2, and timm 1.0.29. Compilation fuses surrounding
operations; CUDA Graph replay reduces launch overhead. These execution
choices do not alter Eqs.~\eqref{eq:frame}--\eqref{eq:readout}.
Table~\ref{tab:sequence-speed} reports the recorded sequence-parallel

\subsection{Optional rotary value encoding}
\label{app:rove}

Let $\mathcal O$ rotate each content row: $(\mathcal O C)_i^\T=O_i c_i$.
The rotations cover all $h$ channels in adjacent pairs, so $h$ is even.
The compact forward changes only the content statistic and final readout:
\begin{equation}
 \begin{aligned}
 \widetilde C&=\mathcal O C, &H&=A^\T\widetilde C, &Z&=R^{-\T}H,\\
 W&=R^{-1}(F-\eta\I_r)Z, &&Y=\eta C+\mathcal O^{-1}(AW).
 \end{aligned}
 \label{eq:rove-compact}
\end{equation}
The Gram matrix and core solve are unchanged. Both modes use this form,
with $F=0$ for Complement. The inverse rotation covers the full correction,
including its $-\eta\I_r$ term, and precedes the output projection.
Backward applies the transposed rotations around the same compact adjoints.
The rotations cost $O(Nh)$ and fuse into statistics and readout.
Sequence shards use global positions and the same frequency scale.

For a fixed frame, write $\mathcal K(C)=K_XC$ with $K_X$ from
Eq.~\eqref{eq:tokenmap}. Equation~\eqref{eq:rove-compact} is
$\mathcal O^{-1}\mathcal K\mathcal O$.
Since $\mathcal O$ is orthogonal under the Frobenius inner product, this
conjugation preserves singular values and the gain bound in
Theorem~\ref{thm:contraction}.

We follow RoVE's value rotations and upstream frequency interpolation
\cite{garcia2026rove,peng2024yarn}. Frequencies are fixed at
$\omega_k=10000^{-2k/h}$ for $k=0,\ldots,h/2-1$.
The optional language configuration uses a 128-token training window.
Beyond it, frequency-only YaRN retains high frequencies and smoothly
scales low frequencies, with $\beta_{\rm fast}=32$ and $\beta_{\rm slow}=1$.
Forward and inverse rotations use the same frequency table and unit amplitude.
This implemented extension has not yet been evaluated in the full pretraining
and downstream experiments reported here.

\section{Extended Related Work}
\label{app:related}

\subsection{From memory updates to joint error correction}

Linear attention accumulates feature--value associations in a compact
state \cite{katharopoulos2020linear}. Delta-rule fast weights write the
prediction residual instead, allowing each association to correct the
current memory \cite{schlag2021fastweights,yang2025deltanet}.
GDNs add adaptive forgetting and richer erase/write controls
\cite{yang2025gdn,kimi2025linear,hatamizadeh2026gdn2}.
TTT makes the internal-learning view explicit: the hidden state is a
model trained on context \cite{sun2025ttt}. Test-time regression connects
several such update rules \cite{wang2025testtimeregression}.

These connections motivate MemSolve's error-correction equation.
The change is in how associations determine memory. Sequential updates
evaluate each residual against the state reached so far. MemSolve
evaluates all residuals against one shared state and solves their joint
balance. Its construction therefore uses the full context without
following an ordered update trajectory.

\subsection{Regression layers and equilibrium models}

Intention studies global regularized regression with query readout and
feature-dimensional inversion \cite{garnelo2023intention}.
MesaNet solves for locally optimal causal regression states using
conjugate gradients \cite{vonoswald2026mesanet}.
ViT$^3$ studies full-batch inner updates for visual representations
\cite{han2026vit3}. These works establish regression and internal
optimization as ways to construct contextual memory.

MemSolve couples its write--read frame to the regularizer
(Eq.~\eqref{eq:gamma}). This cancels the Gram term in the memory
equation and leaves a learned core shared across samples.
The reflected readout then controls the gain in token space.
This coupling and readout distinguish the construction from a generic
global regression layer.

Deep equilibrium and monotone equilibrium models also define states
through equilibrium equations \cite{bai2019deep,winston2020mondeq}.
MemSolve obtains its state from a compact linear system.
Its contraction analysis uses the classical accretive--Cayley
correspondence \cite{bauschke2017convex}.

\subsection{Bidirectional state-space and linear-recurrence models}

Structured SSMs provide efficient sequence maps
\cite{gu2022s4,gu2024mamba,dao2024mamba2}.
Vim adapts selective scans to vision, Hydra develops bidirectional
matrix mixers, and LION relates full-attention, recurrent, and chunkwise
forms \cite{zhu2024vim,hwang2024hydra,afzal2025lion}.
Video DeltaNet combines local attention with bidirectional memory
updated jointly within each frame \cite{xi2026videodeltanet}.

MemSolve gathers full-input statistics before solving one memory.
Its frame normalization couples information from both sides of a token.
Theorem~\ref{thm:ssm} shows that locally parameterized bidirectional scans
with linear merging cannot express all of these interactions in one
mixer. The distinction concerns input dependence as well as execution:
the compact solve can use full-context statistics while retaining
linear complexity in sequence length at fixed rank.

\begin{abstract}
Gated Delta Networks (GDNs) have advanced causal sequence modeling by
writing prediction errors back into memory to learn and refine associations.
In bidirectional settings, the entire context is available to build a shared memory.
However, LION's bidirectional DeltaNet recurrences and equivalent chunkwise
form correct prefix and suffix memories separately.
The direct full-attention form requires a sequence-sized matrix inverse,
whose cubic cost undermines the efficiency of compact memory.
We propose MemSolve, which directly solves a joint error-correction problem
over all positions to build a compact equilibrium memory.
Writing and reading this memory use the full context,
coupling information on both sides of each token.
We prove that single-layer bidirectional scans with local parameterization
and linear merging cannot represent all such interactions.
Our analysis also establishes a unique equilibrium and a contractive readout
for each fixed write--read frame.
Our hardware-aware algorithm supports exact sequence parallelism across devices
and linear sequence complexity at fixed rank.
At 8,192 tokens, its complete mixer is $7.5\times$ faster than FlashAttention
and $7.9\times$ faster than BiMamba in single-GPU forward--backward execution.
On ImageNet-1K, our Base model reaches $82.7\%$ Top-1 with a plain
non-hierarchical backbone and just $78$M parameters.
It surpasses ViG-B and ViT$^3$-B with approximately $13\%$ fewer parameters.
The same operator powers a BERT-Base-scale encoder with an average
GLUE development score of $81.9$.
\end{abstract}

\section{Introduction}

Gated Delta Networks (GDNs) have advanced causal sequence modeling by
writing prediction errors back into memory to learn and refine associations
\cite{yang2025gdn,kimi2025linear,hatamizadeh2026gdn2}.
Self-attention retains an explicit context for retrieval
\cite{vaswani2017attention}, while linear attention and state-space models
(SSMs) compress it into a fixed-size memory
\cite{katharopoulos2020linear,gu2024mamba}.
Stored associations can interfere within this compact state.
The delta rule addresses this interference by predicting content from
memory and writing back the prediction error
\cite{schlag2021fastweights,yang2025deltanet}.
Each write can therefore revise the memory's existing predictions.
GDNs enrich this correction with control over forgetting and writing.

Error correction can be viewed as training an internal predictor to learn
associations from context. Test-time training (TTT) develops this view
using trainable inner models \cite{sun2025ttt}.
Intention turns regression solves into composable neural modules
\cite{garnelo2023intention}. MesaNet uses regression solves to construct
causal memory states \cite{vonoswald2026mesanet}.
With the full context available, internal learning need not follow token
order. In vision experiments, ViT$^3$ finds that full-batch
updates using all tokens outperform sequential mini-batch updates
\cite{han2026vit3}.
Together, these works motivate our joint error-correction approach:
all associations act on one
memory state, whose equilibrium is solved directly rather than approached
through a finite number of inner updates.

The challenge is to retain the efficiency of compact memory.
LION's bidirectional DeltaNet recurrences correct prefix and suffix
memories separately; an equivalent chunkwise computation preserves these
updates \cite{afzal2025lion}.
The direct full-attention form discussed there requires a sequence-sized
matrix inverse, whose cubic cost undermines that efficiency.
A joint error-correction design must therefore address both how
associations determine memory and how that memory is computed.

We propose \textbf{MemSolve}, which jointly designs full-context error
correction and token readout. It directly solves for a compact equilibrium
memory, then reads this memory back as a low-rank contextual correction
to token content. Our main contributions are as follows.

\paragraph{Global Equilibrium ($\S$\ref{sec:joint-memory}, $\S$\ref{sec:readout}).}
We jointly design the memory's error-correction equation and token readout.
An input-dependent soft frame provides shared write--read coordinates.
A matching regularizer reduces the memory equation to a learned compact
core shared across inputs. An accretive parameterization guarantees a
unique equilibrium. The same frame reads the solution back to tokens.
The readout combines a content branch with a low-rank contextual correction.
For each fixed frame, we prove that the token map is contractive and
compute its exact singular values in compact space.

\paragraph{Beyond Independent Directional Scans ($\S$\ref{sec:ssm}).}
MemSolve is not a reparameterization of a single bidirectional SSM mixer
with local coefficients and linear directional merging.
Such a mixer adds separate prefix and suffix responses.
MemSolve instead normalizes its frame using the full context.
Even with the center token fixed, a suffix change can alter how prefix
content reaches that token.
Theorem~\ref{thm:ssm} proves this separation through a three-token
counterexample.

\paragraph{Parallel Algorithm ($\S$\ref{sec:implementation}).}
We develop a parallel algorithm that preserves the operator.
It organizes the forward pass into compact statistic reductions,
a compact solve, and independent token readouts.
The forward pass exchanges only these statistics across sequence shards.
The learned core is shared across inputs and
evaluated once per head in each forward pass.
Selective fusion avoids storing the token-sized frame and reduces GPU
memory traffic. Computation scales linearly with sequence length at fixed rank.
In our length sweep, MemSolve overtakes FlashAttention at 512 tokens
for complete-mixer forward and backward passes.
At 8,192 tokens, it is $7.5\times$ faster than FlashAttention and
$7.9\times$ faster than BiMamba on one GPU (\S\ref{sec:efficiency}).

\paragraph{Architectures and Results ($\S$\ref{sec:experiments}).}
We use the same operator in a plain non-hierarchical visual backbone and
a BERT-style language encoder.
On ImageNet-1K, Small reaches $81.0\%$ Top-1 with $20$M parameters,
and Base reaches $82.7\%$ with $78$M.
Base surpasses ViG-B and ViT$^3$-B with approximately $13\%$ fewer parameters.
Under their respective training recipes, Small also reaches the same
validation accuracy in fewer epochs than the author-released DeiT-S run.
For language, we match BERT-Base's parameter budget and obtain an average
GLUE development score of $81.9$.

\section{Error-Correcting Memories}
\label{sec:background}

Error-correcting memories learn associations by revising their predictions.
We first express this update as internal learning, then consider how to
use all associations jointly when the full context is available.

\subsection{Learning and refining associations}

Let $U\in\R^{r\times h}$ be a memory that predicts content
$c_i\in\R^h$ from a key $k_i\in\R^r$ as $U^\T k_i$.
An additive write accumulates $k_i c_i^\T$.
The basic delta rule instead computes a prediction error and writes it
back into memory \cite{schlag2021fastweights,yang2025deltanet}:
\begin{equation}
 \begin{aligned}
 e_i&=c_i-U_{i-1}^\T k_i,\\
 U_i&=U_{i-1}+\beta_i k_i e_i^\T.
 \end{aligned}
 \label{eq:delta-background}
\end{equation}
Here $\beta_i$ controls the write strength.
Unlike an additive write, this update depends on the memory's current
prediction. It revises stored associations through their residual errors.
GDNs add adaptive forgetting \cite{yang2025gdn}; later variants introduce
channel-wise forgetting and separate erase/write controls
\cite{kimi2025linear,hatamizadeh2026gdn2}.

Equation~\eqref{eq:delta-background} is also a gradient step on
\begin{equation}
 \ell_i(U)=\tfrac12\norm{U^\T k_i-c_i}_2^2,
 \label{eq:association-loss}
\end{equation}
whose gradient is $-k_i(c_i-U^\T k_i)^\T$.
Each token thus supplies a training example for an internal predictor.
The sequential update evaluates its error at the state reached so far.

\subsection{From sequential updates to full-batch learning}

TTT generalizes this interpretation to trainable inner models
\cite{sun2025ttt}. The sequence supplies training examples, and the
hidden state holds the model learned from them.
Test-time regression relates several memory updates through their
regression objectives \cite{wang2025testtimeregression}.
Internal learning can also use a regression solve.
Intention fits embedded key--value pairs and reads the fitted state at
query embeddings \cite{garnelo2023intention}.
MesaNet constructs causal memory states by applying conjugate gradients
to regression over the available context \cite{vonoswald2026mesanet}.

ViT$^3$ studies internal learning when the full input is visible
\cite{han2026vit3}. Its full-batch update uses all token associations
at the same inner-model state.
Sequential mini-batches instead change that state between groups,
so earlier groups affect the updates made by later groups.
ViT$^3$ finds full-batch updates more effective in its vision experiments.
Further inner passes can improve accuracy, but reduce throughput and
can introduce training instability.

Full-batch updates and direct solves suggest a common direction:
evaluate all association errors at one state and solve for their balance.
Section~\ref{sec:method} develops this joint error-correction problem
together with its token readout.

\subsection{Bidirectional access and token interactions}

BiMamba, Hydra, and LION already let a token receive information from
both sides \cite{zhu2024vim,hwang2024hydra,afzal2025lion}.
Access to both sides does not determine how they interact.
The question is whether changing a suffix token can alter how prefix
content contributes to the output at a fixed center token.

For independent directional scans with local parameterization and linear
merging, fixing the current token leaves an output of the form
$y_i=f_i(x_{1:i})+g_i(x_{i:N})$.
Both sides contribute, but a suffix change cannot modify the prefix
response. Section~\ref{sec:ssm} uses this additive structure to establish
a separation from MemSolve.

LION's Appendix~B.7 gives independent bidirectional DeltaNet recurrences
and discusses a chunkwise extension \cite{afzal2025lion}.
The directional memories perform error correction separately.
An equivalent chunkwise implementation reorganizes the computation
without changing these updates.
The direct full-attention expression discussed there also involves a
sequence-sized matrix inverse, with cubic cost for a dense evaluation.
This motivates a design that lets full-context statistics determine
token interactions while keeping the memory solve compact.

\section{MemSolve}
\label{sec:method}
\label{sec:theory}

MemSolve jointly designs the memory equation and its token readout.
An input-dependent frame supplies their shared coordinates.
We match the regularizer to this frame so that the equilibrium uses a
learned compact core shared across inputs.
All equations describe one head with $N$ valid tokens, rank $r$, and
content width $h$. The theoretical results use exact arithmetic.
Appendix~\ref{app:proofs} gives the full proofs.

\subsection{Joint error correction and compact equilibrium}
\label{sec:joint-memory}
\label{sec:equilibrium}

Let $C\in\R^{N\times h}$ contain the content to be stored, and let
$P\in\R^{N\times r}$ assign memory coordinates to each position.
A memory $U\in\R^{r\times h}$ predicts content as $PU$.
For row $p_i^\T$ of $P$ and row $c_i^\T$ of $C$, let
$e_i^\T=c_i^\T-p_i^\T U$ be the prediction error.
Summing the error-correction writes gives
\begin{equation}
 \begin{aligned}
 &\underbrace{\begin{bmatrix}
   \tokenfirst{p_1}&\cdots&\tokenlast{p_N}
 \end{bmatrix}}_{P^\T}
 \underbrace{\begin{bmatrix}
   \tokenfirst{e_1^\T}\\ \vdots\\ \tokenlast{e_N^\T}
 \end{bmatrix}}_{C-PU}\\[-2pt]
 &\qquad=
 \tokenfirst{p_1e_1^\T}+\cdots+\tokenlast{p_Ne_N^\T}.
 \end{aligned}
 \label{eq:joint-residual}
\end{equation}
All prediction errors are evaluated against the same memory $U$.

To control the joint correction, we add a positive-definite regularizer
$\Gamma_X$ and a learned skew-symmetric coupling $\Omega$:
\begin{equation}
 \dot U=P^\T(C-PU)-\Gamma_X U-\Omega U.
 \label{eq:joint-field}
\end{equation}
The regularizer damps the memory. The skew term couples its coordinates.
Its contribution to the change in squared memory norm is zero:
$\langle U,\Omega U\rangle_F=0$.
MemSolve obtains the memory by solving for the equilibrium of this field.
The next step is to construct $P$ and $\Gamma_X$ so that this solve is
well posed and its core can be shared across inputs.

A learned projection produces relation features $B\in\R^{N\times r}$
and content $C$ from the input $X$. Define
\begin{equation}
 \begin{aligned}
 A&=B/\sqrt{N}, & R^\T R&=\I_r+A^\T A,\\
 P&=AR^{-1}, & Z&=P^\T C.
 \end{aligned}
 \label{eq:frame}
\end{equation}
Here $R$ is the upper Cholesky factor with positive diagonal.
Scaling by $\sqrt N$ makes $A^\T A$ an average relation second moment.
The identity term keeps the factorization positive definite and ensures
$\norm{P}_2<1$. We call $P$ a \emph{soft frame}: it provides shared
write--read coordinates with bounded gain. Appendix~\ref{app:frame}
gives its singular values and geometry.

Each head learns a core shared across samples:
\begin{equation}
 J=LL^\T+\Omega,\qquad LL^\T\succ0,\qquad\Omega^\T=-\Omega.
 \label{eq:core}
\end{equation}
Its symmetric part is positive definite, so $J$ is strictly accretive.
We use a lower triangular $L$ with positive diagonal; the unconstrained
parameterization is given in Appendix~\ref{app:parameters}.
We couple the regularizer to the frame:
\begin{equation}
 \Gamma_X=\I_r+LL^\T-P^\T P\succ0.
 \label{eq:gamma}
\end{equation}
Positivity follows from $P^\T P\prec\I_r$.
This choice cancels the frame Gram term in Eq.~\eqref{eq:joint-field}:
\begin{equation}
 \dot U=Z-(P^\T P+\Gamma_X+\Omega)U
       =Z-(\I_r+J)U.
 \label{eq:dynamics}
\end{equation}
The equilibrium and its reflected map are therefore
\begin{equation}
 \begin{aligned}
 U^\star&=(\I_r+J)^{-1}Z,\\
 F&=2(\I_r+J)^{-1}-\I_r\\
  &=(\I_r+J)^{-1}(\I_r-J).
 \end{aligned}
 \label{eq:solve}
\end{equation}
Here and below, inverse notation denotes a linear solve.
This cancellation removes the input dependence from the system matrix,
while retaining it in the memory coordinates and aggregated content.
Each input supplies its own $P$, $Z$, and $U^\star$.
The learned $J$ and $F$ are shared, so one core factorization serves the
batch. The frame factorization remains input-dependent.

The accretive core guarantees a unique memory and bounds its response
to perturbations.

\begin{proposition}[Well-posed memory]
\label{prop:solve}
Let $\mu=1+\sigma_{\min}(L)^2>1$. Then Eq.~\eqref{eq:dynamics} has the
unique equilibrium in Eq.~\eqref{eq:solve}, and
\begin{equation}
 \norm{(\I_r+J)^{-1}}_2\le\mu^{-1},\qquad
 \norm{(\I_r+J)^{-\T}}_2\le\mu^{-1}.
\end{equation}
Every trajectory obeys
\[\norm{U(t)-U^\star}_F\le e^{-\mu t}\norm{U(0)-U^\star}_F.\]
\end{proposition}

The same bound controls right-hand-side perturbations in the forward and
adjoint solves. It does not depend on the number of tokens.

The matched regularizer also gives a variational interpretation.
When $\Omega=0$, the equilibrium minimizes
\begin{equation}
 \mathcal E_X(U)=\tfrac12\norm{PU-C}_F^2+
                    \tfrac12\tr(U^\T\Gamma_XU).
 \label{eq:objective}
\end{equation}
With nonzero $\Omega$, it solves a strongly monotone linear equation.
The same existence guarantee holds, although the field is no longer the
gradient of this scalar objective.

\subsection{Token readout and contraction}
\label{sec:readout}
\label{sec:stability}

The readout returns memory through the same frame used for writing.
We use the reflected response $2U^\star-Z=FZ$ and combine it with
a complementary content response:
\begin{align}
 Y&=\eta(\I_N-PP^\T)C+PFP^\T C\\
 &=\underbrace{\eta C}_{\text{content}}
   +\underbrace{P(F-\eta\I_r)P^\T C}_{\text{contextual correction}}.
 \label{eq:readout}
\end{align}
Here $\eta=\tanh(\eta_{\rm raw})\in(-1,1)$ is learned per head.
Equivalently, $Y=\eta C+P[2U^\star-(1+\eta)Z]$.
The reflection produces a strict contraction $F$.
The complementary term extends this gain bound to token space
(Theorem~\ref{thm:contraction}). The resulting output is a content
branch plus a contextual correction of rank at most $r$.

\begin{theorem}[Contractive compact and token maps]
\label{thm:contraction}
The map $F$ in Eq.~\eqref{eq:solve} satisfies
\begin{equation}
 \I_r-F^\T F=4(\I_r+J)^{-\T}LL^\T(\I_r+J)^{-1}\succ0.
\end{equation}
For a realized frame $P$, define
\begin{equation}
 K_X=\eta(\I_N-PP^\T)+PFP^\T.
 \label{eq:tokenmap}
\end{equation}
Then
$\norm{K_X}_2\le\max\{|\eta|,\norm{F}_2\}<1$ and
$\rank(K_X-\eta\I_N)\le r$.
Moreover, $K_Xv=\eta v$ for every $v\in\ker(P^\T)$.
\end{theorem}

The token bound follows by compressing a block-diagonal contraction.
Let $D=(\I_N-PP^\T)^{1/2}$ and stack
$V_0=[D^\T,P]^\T$. Then
\begin{equation}
 \begin{aligned}
 V_0^\T V_0&=\I_N,\\
 K_X&=V_0^\T\diag(\eta\I_N,F)V_0.
 \end{aligned}
 \label{eq:readout-compression}
\end{equation}
Thus $V_0$ preserves norms, and the compact gain bound carries over to
the full token map.

The bound applies to $C\mapsto K_XC$ with $P$ fixed.
It does not bound derivatives through $P(X)$ or the surrounding residual
block. Within this map, the content path retains a scaled response
outside the relation span. The contextual correction acts within that span.

The shared frame permits nonsymmetric interactions through $F$.
Indeed, the accretive Cayley parameterization covers every real strict
contraction in $r$ dimensions (Appendix~\ref{app:coverage}).
The token map retains its rank and shared-frame constraints.
Its exact singular values can be recovered from a matrix of size at most
$r$, together with the complementary content response
(Appendix~\ref{app:spectrum}).

The default \textsc{Equilibrium} mode learns $F$ through $J$.
Setting $F=0$ gives \textsc{Complement}, which omits the core parameters:
\begin{equation}
 Y_{\rm com}=\eta(\I_N-PP^\T)C
            =\eta(\I_N+AA^\T)^{-1}C.
 \label{eq:complement}
\end{equation}
The second equality is the Woodbury identity \cite{golub2013matrix} applied to the complementary
content map. Both expressions retain input-dependent context mixing.
Both modes learn the frame, content, output projection, and $\eta$.
Equilibrium starts from the Complement map and learns the additional
compact interaction; Appendix~\ref{app:parameters} specifies initialization.
Head outputs are concatenated and passed through a learned output projection.

\paragraph{Optional rotary value encoding.}
Relative position can enter through the content pathway without separating
write and read coordinates. Following RoVE \cite{garcia2026rove}, we rotate
content before aggregation and apply the inverse rotation at readout.
For column vectors $c_i$ and rotations $O_i=O(t_i)$ at positions $t_i$,
\begin{equation}
 y_i=\eta c_i+\sum_j D_{ij}O_i^\T O_j c_j,
 \qquad D=P(F-\eta\I_r)P^\T.
 \label{eq:rove-readout}
\end{equation}
At a fixed frequency scale, $O_i^\T O_j=O(t_j-t_i)$ encodes relative offset.
This extension adds no learned parameters and preserves the fixed-frame
gain bound. Appendix~\ref{app:rove} gives the compact computation and settings.

\subsection{Interactions beyond independent directional scans}
\label{sec:ssm}

The preceding analysis fixes the frame and studies the readout.
We now examine the token interactions that arise as the frame changes
with the input.

We compare MemSolve with a single bidirectional state-space mixer whose
coefficients depend on the current token and whose directional outputs
merge linearly:
\begin{equation}
 \begin{aligned}
 h_i^+&=A^+(x_i)h_{i-1}^++b^+(x_i),\\
 h_i^-&=A^-(x_i)h_{i+1}^-+b^-(x_i),\\
 y_i&=C^+(x_i)h_i^++C^-(x_i)h_i^-+d(x_i).
 \end{aligned}
 \label{eq:ssm-class}
\end{equation}
Its boundary states are input-independent. The coefficients may be
nonlinear functions of the current token, and the state dimension is
unrestricted. Once $x_i$ is fixed, the output separates into
$y_i=f_i(x_{1:i})+g_i(x_{i:N})$. Changing the suffix cannot change the
prefix response. MemSolve's global frame normalization can change that
response, yielding the following separation.

\begin{theorem}[Separation from locally parameterized bidirectional SSMs]
\label{thm:ssm}
For every positive rank $r$, the MemSolve family contains a map that cannot
be represented by Eq.~\eqref{eq:ssm-class} for all inputs, irrespective of
that mixer's state dimension. The result holds for both Equilibrium and
Complement.
\end{theorem}

The proof uses three tokens. Set $A=(1,1,t)^\T$,
$C=(s,0,0)^\T$, $F=0$, and $\eta\ne0$.
Equation~\eqref{eq:complement} gives
\begin{equation}
 y_2=-\frac{\eta s}{3+t^2}.
 \label{eq:cross-context}
\end{equation}
The first two tokens stay fixed as $t$ varies.
Changing only the third token changes the coefficient $-\eta/(3+t^2)$
that carries the first token's content to the second.

For the four choices $(s,t)\in\{0,1\}^2$, the mixed finite difference
$y_2(1,1)-y_2(1,0)-y_2(0,1)+y_2(0,0)$ is $\eta/12$ for
Eq.~\eqref{eq:cross-context} and zero for every additive prefix--suffix
response. Appendix~\ref{app:ssm} gives the full proof and extends the
example to any rank. The theorem concerns individual mixers
with local coefficients and linear directional merging. Stacks, nonlinear
merges, and globally conditioned coefficients define different model classes.

\section{Hardware-Aware Parallel Computation}
\label{sec:implementation}

The mathematical construction uses a token-sized frame $P$.
Our algorithm avoids storing this matrix. It reduces the input to two
compact statistics, solves in memory space, and reads out token rows
in parallel. Both operator modes follow the same computation.

\subsection{Reduce, solve, and read out}

Substituting $P=AR^{-1}$ into Eq.~\eqref{eq:readout} gives
\begin{equation}
 \begin{aligned}
 G&=A^\T A,\qquad H=A^\T C,\\
 R^\T R&=\I_r+G,\qquad Z=R^{-\T}H,\\
 W&=R^{-1}(F-\eta\I_r)Z,\\
 Y&=\eta C+AW.
 \end{aligned}
 \label{eq:nop}
\end{equation}
The Gram statistic $G$ determines the frame normalization, while $H$
aggregates relation--content associations.
Together they determine $W$. Once $W$ is available, each output row
uses only its local rows of $A$ and $C$.
Algorithm~\ref{alg:compact-forward} gives this computation.
Equilibrium and Complement use the same steps; Complement takes $F=0$.

\begin{algorithm}[H]
\caption{MemSolve: compact forward computation (one sample and head)}
\label{alg:compact-forward}
\begin{algorithmic}[1]
\Require Relations $B\in\R^{N\times r}$, content $C\in\R^{N\times h}$;
 shared $F$, scalar $\eta$; $N>r$ valid tokens
\Ensure Token output $Y\in\R^{N\times h}$
\State $A\gets B/\sqrt N$
\State $G\gets A^\T A$; $H\gets A^\T C$ \Comment{Parallel token reductions}
\State $R\gets\Chol(\I_r+G)$ \Comment{$R^\T R=\I_r+G$}
\State $Z\gets\Solve(R^\T,H)$
\State $W\gets\Solve(R,(F-\eta\I_r)Z)$
\State \Return $\eta C+AW$ \Comment{Parallel token readout}
\end{algorithmic}
\end{algorithm}

The learned $F$ is evaluated once per head in each forward pass.
Each sample then requires $O(Nr^2+Nrh+r^3+r^2h)$ arithmetic and
$O(r^2+rh)$ compact storage per head. Token storage is linear in $N$.
Input and output projections also have linear sequence cost at fixed width.
For physical length $N\le r$, an equivalent token-space solve avoids
subtraction in the complementary term. Its dimension is at most $r$.
Appendix~\ref{app:forward} gives both length regimes and padding handling.

\subsection{Exact sequence parallelism}

The two statistics are sums over token rows. Partition those rows across
$p$ devices and normalize each shard as $A_s=B_s/\sqrt N$,
using the same global valid count $N$.
For two shards, expanding $A^\T[\,A\;\;C\,]$ shows which contributions combine:
\begin{equation}
 \begin{aligned}
 [\,G\;\;H\,]
 &=\begin{bmatrix}
   A_1^\T&A_2^\T
 \end{bmatrix}
 \begin{bmatrix}
   A_1&C_1\\
   A_2&C_2
 \end{bmatrix}\\
 &=
 A_1^\T[\,A_1\;\;C_1\,]+
 A_2^\T[\,A_2\;\;C_2\,]\\
 &=\begin{bmatrix}
    G_1+G_2&H_1+H_2
 \end{bmatrix}.
 \end{aligned}
 \label{eq:sequence-parallel}
\end{equation}
Here $G_s=A_s^\T A_s$ and $H_s=A_s^\T C_s$.
For $p$ shards, a sum reduction gives each device
$G=\sum_sG_s$ and $H=\sum_sH_s$.
Each device computes the same $W$ and reads out its own rows as
$Y_s=\eta C_s+A_sW$. The statistic payload is $O(r^2+rh)$ per sample and
head, independent of sequence length. No token activation gather is needed.

The backward pass likewise reduces a compact readout adjoint before
computing local token gradients. Outputs and reduced gradients equal the
unsharded computation in real arithmetic; floating-point reduction order
can change rounding. Algorithm~\ref{alg:sequence-parallel} specifies the
reductions and the treatment of shared parameter gradients.

\subsection{Selective fusion}

We selectively fuse token operations around the compact statistics and
readout. Compact factorizations remain separate so that specialized
solvers can handle them. The backward pass reuses the compact
factors and reduces core gradients across the batch without storing one
core adjoint per sample.

The GPU implementation uses Triton \cite{tillet2019triton} for tiled token operations, cuSOLVERDx
for compact factorizations, and cuBLASLt for projection gradients.
Compact solves and adjoints retain FP32 storage.
The readout splits sensitive coefficients into a BF16 leading word and a
BF16 residual word \cite{henry2019bfloat}. Both products accumulate in FP32
before output rounding. This improves coefficient precision while retaining
Tensor Core products. Appendix~\ref{app:precision} specifies precision,
scheduling, and the surrounding compilation and CUDA Graph execution.

\subsection{Masked language modeling and GLUE}
\label{sec:language}

\paragraph{A parameter-matched encoder.}
We replace BERT's attention mixer with MemSolve in a 14-layer encoder
with SwiGLU FFNs \cite{shazeer2020glu}. It has 112M parameters including the tied MLM head,
close to the 110M BERT-Base scale \cite{devlin2019bert}.
The model uses BERT's post-LayerNorm residual structure and learned
absolute positions. A centered residual depthwise convolution of width
three precedes the relation/content projection in every layer.
Appendix~\ref{app:nlp} lists the model and pretraining configuration.

\paragraph{Pretraining.}
We follow the LION/M2-derived C4 masked-language setup
\cite{raffel2020t5,afzal2025lion}: sequence length 128, global batch 4,096,
70,000 optimizer steps, and training mask probability $0.30$.
On a fixed 10,000-document validation subset with
$15\%$ masking, the selected checkpoint reaches $66.4\%$ masked-token
accuracy and masked-token NLL $1.6211$ over 169,544 targets. The complete
run takes 31.80 hours on two A800-80GB GPUs, including scheduled validation
and checkpointing.

We fine-tune on eight GLUE tasks using the LION paper's M2-BASE task
hyperparameters \cite{wang2019glue,afzal2025lion}. MNLI, QQP, QNLI,
SST-2, and CoLA start from the MLM checkpoint; RTE, MRPC, and STS-B start
from the fine-tuned MNLI encoder. All tasks use length 128 and final-checkpoint
development evaluation.
\paragraph{Closing the gap to BERT.}
The same operator also delivers competitive language understanding.
At the BERT-Base scale, MemSolve reaches an average GLUE score of $81.9$,
exceeding all three LION M2-BASE variants (Table~\ref{tab:glue}).
Compared with the strongest LION variant, LION-LIT, it reduces the gap
to BERT from $2.0$ points to just $0.4$ points.
MemSolve also achieves the highest scores among the listed models on
RTE, STS-B, and MRPC, exceeding BERT by $9.9$, $2.5$, and $1.4$ points.
CoLA remains its largest shortfall, at $47.5$ versus BERT's $60.4$.
Together with the ImageNet results, these findings demonstrate that
compact equilibrium memory supports strong representations in both
vision and language.

FlashAttention at 512 tokens. The speedup reaches $2.3\times$ at

At the latter length, it also outperforms the fused

The benefit extends to the 196-token visual shapes:

MemSolve has the lowest peak allocated memory in every measured setting.
At 32,768 tokens, its forward--backward pass uses 2.58\,GiB,
compared with 2.87\,GiB for FlashAttention and 6.00\,GiB for BiMamba.
This reduces memory by $10\%$ and $57\%$, respectively.
The compact solve thus supports long sequences with both lower latency
and lower memory use.

\section{Discussion and Limitations}

MemSolve concentrates contextual changes in a learned relation span.
Rank controls the number of modified directions and the cost of the compact
systems. Outside that span, the operator retains a scalar content response.
Sharing write and read coordinates supports the contraction guarantee,
but it also ties where information is stored to where it is retrieved.
These choices define the operator's capacity and computational tradeoff.

The experiments show that this construction learns useful representations
in vision and language. The language experiments train and fine-tune at
128 tokens with learned absolute positions; task accuracy beyond that
length remains to be measured.

\section{Conclusion}

MemSolve turns joint error correction into a compact equilibrium solve.
Its frame and matched regularizer yield a shared core, while each input
determines the memory and its token readout. The readout combines a
content branch with a low-rank contextual correction and is contractive
for each fixed frame. Global frame normalization allows a suffix token
to change how prefix content reaches a fixed position. This interaction
separates MemSolve from single bidirectional scans with local coefficients
and linear merging. Two compact statistics support linear sequence cost
and exact sequence parallelism at fixed rank. Results in vision and
language demonstrate the effectiveness of this shared operator.

\section{Proofs and Structural Details}
\label{app:proofs}

We first establish the frame geometry. It gives the positive regularizer
used in the memory equation. We then prove existence, contraction, and
the compact spectrum, followed by the bidirectional-scan separation.

\subsection{Soft-frame geometry}
\label{app:frame}

Since $R^\T R=\I+A^\T A$,
\begin{equation}
 PP^\T=A(\I+A^\T A)^{-1}A^\T.
\end{equation}
An SVD of $A$ gives
\begin{equation}
 \sigma_i(P)=\frac{\sigma_i(A)}{\sqrt{1+\sigma_i(A)^2}}<1.
 \label{eq:soft-singular}
\end{equation}
In particular,
$P^\T P\prec\I_r$ and $PP^\T\prec\I_N$, including rank-deficient cases.
The Woodbury identity yields
\begin{equation}
 \I_N-PP^\T=(\I_N+AA^\T)^{-1}\succ0,
\end{equation}
which proves Eq.~\eqref{eq:complement} and positivity of $\Gamma_X$.
The reduced QR factorization of $[A^\T,\I_r]^\T$ with a positive diagonal
in its triangular factor has top block $P$. Thus the QR reference and the
compact Cholesky construction agree in exact arithmetic.

The $\sqrt N$ normalization controls the scale of the relation statistic.
Write $b_i^\T$ for row $i$ of $B$. If
$N^{-1}\sum_i\norm{b_i}_2^2\le c$, then
$\norm{A}_2^2\le\norm{A}_F^2\le c$ and
$\kappa_2(\I+A^\T A)\le1+c$, independently of $N$.
Under this feature-energy bound, the condition number does not grow with
sequence length. Accuracy at unseen lengths is a separate empirical question.

Without a positional module, the operator is permutation equivariant:
permuting the rows of $A,C$ leaves $G,H$ unchanged and permutes the rows
of $Y$. The visual and language backbones therefore supply position
information outside the core operator.

\subsection{Memory existence, sensitivity, and convergence}

Write $M=\I_r+J$. For every real $v$,
\begin{equation}
 v^\T Mv=v^\T(\I_r+LL^\T)v\ge\mu\norm{v}_2^2,
 \qquad \mu=1+\sigma_{\min}(L)^2.
\end{equation}
Cauchy--Schwarz gives $\norm{Mv}_2\ge\mu\norm{v}_2$, so $M$ is invertible
and $\norm{M^{-1}}_2\le1/\mu$. The same argument applies to $M^\T$.
For $E(t)=U(t)-U^\star$, $\dot E=-ME$ and
\begin{equation}
 \frac{d}{dt}\norm{E}_F^2
 =-2\tr(E^\T(\I_r+LL^\T)E)\le-2\mu\norm{E}_F^2.
\end{equation}
Integration proves Proposition~\ref{prop:solve}.
For $\Omega=0$, differentiating Eq.~\eqref{eq:objective} gives
$\nabla_U\mathcal E_X=MU-Z$ and Hessian $M\succ0$ for each content column.
When $\Omega\ne0$, the nonsymmetric field need not be a scalar gradient,
although the same convergence argument holds.

\subsection{Cayley contraction and coverage}
\label{app:coverage}

As $M=\I+J$ commutes with $\I-J$,
\begin{align}
 \I-F^\T F
 &=M^{-\T}\left[M^\T M-(\I-J)^\T(\I-J)\right]M^{-1}\\
 &=2M^{-\T}(J+J^\T)M^{-1}
 =4M^{-\T}LL^\T M^{-1}\succ0.
\end{align}
Conversely, let $F_0$ be any real matrix with $\norm{F_0}_2<1$.
Then $\I+F_0$ is invertible and
\begin{equation}
 J_0=(\I-F_0)(\I+F_0)^{-1},\qquad
 \sym(J_0)=(\I+F_0)^{-\T}(\I-F_0^\T F_0)(\I+F_0)^{-1}\succ0.
\end{equation}
Factor $\sym(J_0)=LL^\T$ and set
$\Omega=(J_0-J_0^\T)/2$. The triangular/softplus parameterization can
represent every such $L$ and $\Omega$. This is the classical accretive--Cayley correspondence
\cite{bauschke2017convex}. It establishes coverage of all real strict
contractions in compact space; the token map retains its shared-frame
and rank constraints.

\subsection{Token contraction and the exact compact spectrum}
\label{app:spectrum}

Equation~\eqref{eq:readout-compression} expresses $K_X$ as an isometric
compression of $\diag(\eta\I_N,F)$. Submultiplicativity of the spectral
norm gives the bound in Theorem~\ref{thm:contraction}.
The rank and nullspace statements follow directly from
$K_X-\eta\I_N=P(F-\eta\I_r)P^\T$.

\begin{proposition}[Exact analysis in compact space]
\label{prop:spectrum}
Let $P=Q S V^\T$ be a thin singular value decomposition with
$k=\rank(P)$, $Q^\T Q=V^\T V=\I_k$, and positive diagonal $S$.
The token map is orthogonally similar to
\begin{equation}
 \left[\eta\I_k+S V^\T(F-\eta\I_r)V S\right]
       \oplus\eta\I_{N-k}.
 \label{eq:certificate}
\end{equation}
Its singular values, including its exact spectral norm, can therefore be
obtained from a matrix of size at most $r$, together with $N-k$ copies of
$|\eta|$.
\end{proposition}

To prove the proposition, extend $Q$ to an orthogonal basis
$[Q,Q_\perp]$. In this basis the low-rank correction acts only on the first
$k$ coordinates, giving Eq.~\eqref{eq:certificate}. If $k=0$, the result is
simply $\eta\I_N$; if $k=N$, the complementary block is absent.
One may compute $V$ and $S$ from the positive eigenspace of $P^\T P$, so no
$N\times N$ matrix or token-space SVD is required.

\subsection{Proof of the bidirectional SSM separation}
\label{app:ssm}

Fix the center token $x_i$ in Eq.~\eqref{eq:ssm-class}. Recursion with
input-independent boundary states gives
$y_i=f_i(x_{1:i})+g_i(x_{i:N})$. For any prefix perturbation $s$ and suffix
perturbation $t$ that leave $x_i$ fixed, its mixed finite difference is
\begin{equation}
 \Delta_{s,t}y_i
 =y_i(s_1,t_1)-y_i(s_1,t_0)-y_i(s_0,t_1)+y_i(s_0,t_0)=0.
 \label{eq:mixed-difference}
\end{equation}
This conclusion holds for arbitrary coefficient functions and state size.

For MemSolve, take three tokens whose two coordinates independently
control relation and content:
$x_1=(1,s)$, $x_2=(1,0)$, and $x_3=(t,0)$.
A fixed relation projection with scale $\sqrt3$ gives
$A=(1,1,t)^\T$ after the normalization in Eq.~\eqref{eq:frame}; a content
projection gives $C=(s,0,0)^\T$. With $F=0$,
\begin{equation}
 PP^\T=\frac{AA^\T}{1+A^\T A},\qquad
 y_2=-\frac{\eta s}{3+t^2}.
\end{equation}
At $(s_0,s_1)=(0,1)$ and $(t_0,t_1)=(0,1)$,
\begin{equation}
 \Delta_{s,t}y_2=-\frac{\eta}{4}+\frac{\eta}{3}
 =\frac{\eta}{12}\ne0.
\end{equation}
Therefore no mixer of Eq.~\eqref{eq:ssm-class} represents this MemSolve
map for all inputs. For any larger rank, append zero relation columns;
the first Cholesky coordinate and the output above remain unchanged.
Complement sets $F=0$ by definition, and Equilibrium realizes $F=0$ at
$J=\I_r$. This proves Theorem~\ref{thm:ssm}.

The distinction concerns how inputs determine the map, not the rank of a
matrix after fixing the input. A realized MemSolve matrix is low rank plus
a diagonal and can admit other algebraic factorizations. Such a
factorization does not supply the local coefficient dependence required
by Eq.~\eqref{eq:ssm-class}.

\section{Algorithms and Numerical Details}
\label{app:implementation}

This appendix gives the core parameterization, the masked forward pass,
and the analytic backward. It then specifies sequence-parallel reductions
and floating-point execution. The pseudocode describes exact arithmetic;
Section~\ref{app:precision} explains how the GPU kernels evaluate it.

\subsection{Core parameters and initialization}
\label{app:parameters}

Each head stores an unconstrained matrix $\Theta\in\R^{r\times r}$.
Its lower and upper entries define the symmetric and skew parts of $J$:
\begin{align}
 L&=\tril(\Theta,-1)+\diag\!\left(
    \operatorname{softplus}(\diag\Theta+\log(e-1))\right),\\
 \Omega&=\triu(\Theta,1)-\triu(\Theta,1)^\T,\qquad J=LL^\T+\Omega.
 \label{eq:core-parameters}
\end{align}
The diagonal of $L$ is positive, so $LL^\T\succ0$.
At $\Theta=0$, $L=\I_r$, $J=\I_r$, and $F=0$.
This initialization preserves the core's training signal:
$\delta F=-\tfrac12\delta J$ at $J=\I_r$.
The additional response $PFP^\T C$ starts at zero, while the Complement
map already mixes context. The core remains trainable at this initialization.

The per-head scalar is parameterized by $\eta=\tanh(\eta_{\rm raw})$ and
initialized to $0.9$. Floating-point execution uses
\begin{equation}
 \eta_{\rm fp}=(1-\epsilon_{\rm mach})\tanh(\eta_{\rm raw}),\qquad
 \frac{d\eta_{\rm fp}}{d\eta_{\rm raw}}
 =(1-\epsilon_{\rm mach})\frac{4q}{(1+q)^2},\quad
 q=e^{-2|\eta_{\rm raw}|}.
 \label{eq:eta-numerical}
\end{equation}
Here $\epsilon_{\rm mach}$ is the machine epsilon of the scalar computation
dtype, which is FP32 in the CUDA path. The scale keeps the value inside $(-1,1)$.
Native $\tanh$ preserves small values near zero; the exponential derivative
retains representable tail gradients after $\tanh$ rounds to an endpoint.

\subsection{Forward computation}
\label{app:forward}

Algorithm~\ref{alg:forward} expands Algorithm~\ref{alg:compact-forward}
to masked batches and short sequences. The input and output projections
are ordinary affine layers. Head outputs are concatenated, projected, and
masked again so that output bias cannot populate padding.

Physical length is $N$; sample $b$ has $n_b$ valid tokens.
Masks multiply rows and are fixed under differentiation. An all-masked
sample uses a divisor of one and produces zero.
We use $\Solve(M,V)$ for the solution of $MU=V$ and $\Chol(S)$ for the
upper factor $R$ satisfying $R^\T R=S$. Thus
\begin{equation}
 \CholSolve(R,V)=\Solve\!\left(R,\Solve(R^\T,V)\right).
 \label{eq:cholsolve}
\end{equation}
A general core system uses LU factorization. For $N\le r$, the
complementary term uses the equivalent solve
$\eta\Solve(\I_N+AA^\T,C)$. This avoids subtracting nearly equal terms
in $\eta(C-PP^\T C)$. Equilibrium adds its learned correction to that result.
The largest factorization has dimension at most $r$ in either regime.

\begin{algorithm}[!ht]
\caption{MemSolve forward without materializing $P$ (one head)}
\label{alg:forward}
\small
\begin{algorithmic}[1]
\Require $\{B_b\in\R^{N\times r},C_b\in\R^{N\times h},m_b\in\{0,1\}^N\}_{b=1}^{s}$;
 mode, $\eta$; $\Theta\in\R^{r\times r}$ for Equilibrium
\Ensure Head outputs $\{Y_b\in\R^{N\times h}\}_{b=1}^{s}$
\If{mode is Equilibrium}
  \State Construct $L,\Omega,J$ from $\Theta$ using Eq.~\eqref{eq:core-parameters}
  \State $M\gets\I_r+J$; factor $M$ once
  \State $F\gets\Solve(M,\I_r-J)$ \Comment{Shared across this batch}
\Else
  \State $F\gets0$ \Comment{Complement}
\EndIf
\For{each sample $b$ in parallel}
  \State $n_b\gets\sum_i m_{b,i}$; $A\gets(m_b\odot B_b)/\sqrt{\max(n_b,1)}$; $C\gets m_b\odot C_b$
  \If{$N\le r$} \Comment{Physical length determines the branch}
    \State $R_N\gets\Chol(\I_N+AA^\T)$; $Y_b\gets\eta\,\CholSolve(R_N,C)$
    \If{mode is Equilibrium}
      \State $R\gets\Chol(\I_r+A^\T A)$; $Z\gets\Solve(R^\T,A^\T C)$
      \State $Y_b\gets Y_b+A\Solve(R,FZ)$
    \EndIf
  \Else
    \State $G\gets A^\T A$; $H\gets A^\T C$; $R\gets\Chol(\I_r+G)$
    \State $Z\gets\Solve(R^\T,H)$; $W\gets\Solve(R,(F-\eta\I_r)Z)$
    \State $Y_b\gets\eta C+AW$
  \EndIf
\EndFor
\State \Return $\{Y_b\}_{b=1}^{s}$
\end{algorithmic}
\end{algorithm}

For $N>r$, the backward below uses $A,C,R,W,Z$ and the shared $F$.
Implementations can save these values or reconstruct them from projections
and compact intermediates. Equilibrium also reuses $L$ and the LU factors
of $\I_r+J$. No token-sized frame is needed.
For $N\le r$, automatic differentiation handles the short-sequence
expression, with an analytic adjoint for the shared core solve.

\subsection{A common compact backward}
\label{app:backward}

Algorithm~\ref{alg:backward} differentiates Eq.~\eqref{eq:nop} for one
sample and head. It applies to both modes: set $F=0$ for Complement and
discard the adjoint of this fixed matrix. A bar denotes a loss adjoint
under the Frobenius inner product, and $\sym(T)=(T+T^\T)/2$.
The algorithm includes both the direct content term and the correction.
Their contributions to $C$ and $\eta$ are added before returning.
Projection gradients follow the usual affine-layer rules.

For an upper Cholesky factor $R$, define
\begin{equation}
 \Phi_u(T)=\triu(T,1)+\tfrac12\diag(\diag T),\qquad
 \mathcal C(R,E_R)=R^{-1}\sym\!\left(\Phi_u(E_RR^\T)\right)R^{-\T}.
 \label{eq:chol-adjoint}
\end{equation}
Here $\mathcal C$ is the adjoint of $R=\Chol(S)$ with respect to the
symmetric matrix $S$; the inverse notation again means two triangular
solves. To obtain it, differentiate $S=R^\T R$ and observe that
$dR=\Phi_u(R^{-\T}(dS)R^{-1})R$. This also fixes the half-diagonal
convention in Eq.~\eqref{eq:chol-adjoint}.

\begin{algorithm}[!ht]
\caption{Rank-space backward ($N>r$, one sample and head)}
\label{alg:backward}
\small
\begin{algorithmic}[1]
\Require $E=\overline Y\in\R^{N\times h}$; forward values $A,C,R,W,Z,F,\eta$;
 fixed mask $m$ and valid count $n$
\Ensure $\overline B,\overline C_{\rm in}$; contributions $\overline\eta,\overline F$
\State $E_W\gets A^\T E$; $\overline A\gets EW^\T$; $\overline C\gets\eta E$
\State $\overline\eta\gets\langle E,C\rangle_F$
\State $E_T\gets\Solve(R^\T,E_W)$
\State $\overline F\gets E_TZ^\T$; $\overline\eta\gets\overline\eta-\langle E_T,Z\rangle_F$
\State $\overline Z\gets(F-\eta\I_r)^\T E_T$; $\overline H\gets\Solve(R,\overline Z)$
\State $\overline R\gets-E_TW^\T-Z\overline H^\T$
\State $\overline G\gets\mathcal C(R,\overline R)$ \Comment{Eq.~\eqref{eq:chol-adjoint}}
\State $\overline A\gets\overline A+C\overline H^\T+A(\overline G+\overline G^\T)$
\State $\overline C\gets\overline C+A\overline H$
\State $\overline B\gets m\odot\overline A/\sqrt{\max(n,1)}$
\State $\overline C_{\rm in}\gets m\odot\overline C$
\State \Return $\overline B,\overline C_{\rm in},\overline\eta,\overline F$
\end{algorithmic}
\end{algorithm}

\paragraph{Reusing the inverse triangular factor.}
The GPU path computes $T=R^{-\T}$ once and reuses it in forward and backward
products. The compact derivatives above can be evaluated directly in terms
of $T$. Let $M_F=F-\eta\I_r$, $E_T=TE_W$, and $V=E_TZ^\T$. Then
\begin{align}
 \overline H&=T^\T M_F^\T E_T,\\
 \overline G&=T^\T\operatorname{sym}_{\ell}
       (-M_FV^\T-M_F^\T V)T,
 \label{eq:inverse-factor-adjoint}
\end{align}
where $\operatorname{sym}_{\ell}(K)=[\tril(K)+\tril(K,-1)^\T]/2$.
The core and scalar contributions reuse $V$:
$\overline F=V$ and $\overline\eta=\langle E,C\rangle_F-\tr(V)$.
This form shares the same compact adjoint between Equilibrium and Complement.

\subsection{Shared-core and scalar gradients}
\label{app:core-backward}

Write $M=\I_r+J$.
For $F=M^{-1}(\I-J)$, differentiation gives
\begin{equation}
 dF=-M^{-1}(dJ)(\I+F).
 \label{eq:core-differential}
\end{equation}
Since the core is shared, its adjoints are summed over samples before the
transposed solve in Algorithm~\ref{alg:core-backward}. The reduction is a
sum: any loss averaging is already contained in $\overline Y$. The fast
path accumulates this reduction in tiles rather than storing one
$r\times r$ core adjoint per sample.

\begin{algorithm}[!ht]
\caption{Shared-core backward (once per head, Equilibrium only)}
\label{alg:core-backward}
\small
\begin{algorithmic}[1]
\Require $E_F=\sum_b\overline F_b$; $\Theta,L,F$ and the saved factorization of $M=\I_r+J$
\Ensure Core-parameter gradient $\overline\Theta\in\R^{r\times r}$
\State $T\gets\Solve(M^\T,E_F)$ \Comment{Reuse the forward LU factors}
\State $\overline J\gets-T(\I_r+F)^\T$
\State $\overline L\gets(\overline J+\overline J^\T)L$
\State $d\gets\diag(\overline L)\odot\operatorname{sigmoid}(\diag\Theta+\log(e-1))$
\State $\overline\Theta\gets\tril(\overline L,-1)+\diag(d)+\triu(\overline J-\overline J^\T,1)$
\State \Return $\overline\Theta$
\end{algorithmic}
\end{algorithm}

For either mode, sum the scalar adjoints over samples before applying
$\overline{\eta_{\rm raw}}=(d\eta/d\eta_{\rm raw})\sum_b\overline\eta_b$.
For the mathematical parameterization, $d\eta/d\eta_{\rm raw}
=1-\tanh^2(\eta_{\rm raw})$.
The fast path provides first-order training gradients.

\subsection{Sequence-parallel reductions}
\label{app:parallel}

Algorithm~\ref{alg:sequence-parallel} expresses the operator for a sum of
local losses. A global mean is obtained by normalizing every local loss
with the same global denominator. $\operatorname{VJP}_W$ denotes the
adjoint of $(G,H,F,\eta)\mapsto W$ in Eq.~\eqref{eq:nop}.
It is the compact part of Algorithm~\ref{alg:backward} and excludes
the direct term $\eta C$.
A sum reduction of $E_W$ gives every device the same compact adjoints.
The core adjoint is therefore global. The scalar adjoint also includes
a sum of local direct-content contributions. Each shared-parameter
gradient must be counted once.
The implementation divides their replicated contributions by the
number of devices before the final parameter-gradient sum.

\begin{algorithm}[!ht]
\caption{Exact sequence-parallel MemSolve (one sample and head)}
\label{alg:sequence-parallel}
\small
\begin{algorithmic}[1]
\Require Local rows $B_s,C_s$, mask $m_s$; replicated $F,\eta$; $p$ devices;
 global physical length $N>r$
\Ensure Local output $Y_s$, local input gradients, and global parameter gradients
\State $n\gets\operatorname{AllReduceSum}(\sum_i m_{s,i})$
\State $A_s\gets(m_s\odot B_s)/\sqrt{\max(n,1)}$; $C_s\gets m_s\odot C_s$
\State $(G,H)\gets\operatorname{AllReduceSum}(A_s^\T A_s,A_s^\T C_s)$
\State $R\gets\Chol(\I_r+G)$; $Z\gets\Solve(R^\T,H)$
\State $W\gets\Solve(R,(F-\eta\I_r)Z)$; $Y_s\gets\eta C_s+A_sW$
\State \textbf{Backward:} receive local output adjoint $E_s$
\State $E_W\gets\operatorname{AllReduceSum}(A_s^\T E_s)$
\State $(\overline G,\overline H,\overline F,\overline\eta_W)
  \gets\operatorname{VJP}_W(G,H,F,\eta;E_W)$
\State $\overline A_s\gets E_sW^\T+C_s\overline H^\T+A_s(\overline G+\overline G^\T)$
\State $\overline C_s\gets\eta E_s+A_s\overline H$
\State $\overline\eta\gets\operatorname{AllReduceSum}(\langle E_s,C_s\rangle_F)+\overline\eta_W$
\State $\overline B_s\gets m_s\odot\overline A_s/\sqrt{\max(n,1)}$;
 $\overline C_{{\rm in},s}\gets m_s\odot\overline C_s$
\State Backpropagate local projection gradients and sum them across devices
\State Apply the shared-core adjoint to $\overline F$ once; retain one copy of $\overline\eta$
\end{algorithmic}
\end{algorithm}

The proof is the additivity of $G,H$ in the forward pass and the chain
rule in the backward pass. No recurrence connects neighboring sequence
shards. In a backbone with a centered convolution, that local operation
requires a separate halo exchange; it does not change the memory reduction.
The implemented sequence-parallel path uses the compact formulation and
requires global physical length greater than the operator rank.

\subsection{Precision and scheduling}
\label{app:precision}
The fast path supports ranks 16, 32, 48, and 64. Token projections and
statistics use BF16 multiplicands and FP32 accumulation.
Gram matrices, compact states, factors, and adjoints retain FP32 storage.
Batched compact products use Triton's three-term TF32 decomposition;
small shared-core products and solves retain IEEE FP32 arithmetic.
Readout kernels split sensitive FP32 coefficients into BF16 leading and
residual words before accumulating both products in FP32.
The extra product recovers coefficient precision without using FP32
operands for token-sized products. With very sparse masks and strong
relations, cancellation can still amplify relative error in the compact
complementary readout.

\paragraph{Training implementation.}
The completed training runs used NVIDIA A800-SXM4-80GB GPUs, PyTorch
2.14.0 with CUDA 13.2, and timm 1.0.29. Compilation fuses surrounding
operations; CUDA Graph replay reduces launch overhead. These execution
choices do not alter Eqs.~\eqref{eq:frame}--\eqref{eq:readout}.

\subsection{Optional rotary value encoding}
\label{app:rove}

Let $\mathcal O$ rotate each content row: $(\mathcal O C)_i^\T=O_i c_i$.
The rotations cover all $h$ channels in adjacent pairs, so $h$ is even.
The compact forward changes only the content statistic and final readout:
\begin{equation}
 \begin{aligned}
 \widetilde C&=\mathcal O C, &H&=A^\T\widetilde C, &Z&=R^{-\T}H,\\
 W&=R^{-1}(F-\eta\I_r)Z, &&Y=\eta C+\mathcal O^{-1}(AW).
 \end{aligned}
 \label{eq:rove-compact}
\end{equation}
The Gram matrix and core solve are unchanged. Both modes use this form,
with $F=0$ for Complement. The inverse rotation covers the full correction,
including its $-\eta\I_r$ term, and precedes the output projection.
Backward applies the transposed rotations around the same compact adjoints.
The rotations cost $O(Nh)$ and fuse into statistics and readout.
They are evaluated in FP32. Products involving rotated content use
BF16 leading and residual words, as in Appendix~\ref{app:precision}.
Sequence shards use global positions and the same frequency scale.

For a fixed frame, write $\mathcal K(C)=K_XC$ with $K_X$ from
Eq.~\eqref{eq:tokenmap}. Equation~\eqref{eq:rove-compact} is
$\mathcal O^{-1}\mathcal K\mathcal O$.
Since $\mathcal O$ is orthogonal under the Frobenius inner product, this
conjugation preserves singular values and the gain bound in
Theorem~\ref{thm:contraction}.

We follow RoVE's value rotations and upstream frequency interpolation
\cite{garcia2026rove,peng2024yarn}. Frequencies are fixed at
$\omega_k=10000^{-2k/h}$ for $k=0,\ldots,h/2-1$.
The optional language configuration uses a 128-token training window.
Beyond it, frequency-only YaRN retains high frequencies and smoothly
scales low frequencies, with $\beta_{\rm fast}=32$ and $\beta_{\rm slow}=1$.
Forward and inverse rotations use the same frequency table and unit amplitude.
This implemented extension has not yet been evaluated in the full pretraining
and downstream experiments reported here.

\subsection{Efficiency benchmark}
\label{app:efficiency}

\paragraph{Mixers and shapes.}
We benchmark complete mixers with input and output projections.
MemSolve uses Equilibrium without RoVE or an external positional module.
FlashAttention uses \texttt{timm} attention with packed QKV projections
and PyTorch's FlashAttention-2 SDPA backend, without a causal mask.
BiMamba uses Vim's fused v2 implementation: expansion factor two,
state size 16, convolution width four, and averaged directional outputs.
It shares input and output projections across directions.
The three mixers receive identical input shapes.
The 196-token visual settings use
$(B,D,H,r)=(128,192,6,16)$, $(128,384,6,32)$, and $(64,768,12,48)$
for Tiny, Small, and Base. Here $B$ is batch size, $D$ is width,
$H$ is the head count for MemSolve and attention, and $r$ is MemSolve's rank.
The length sweep fixes $(B,D,H,r)=(4,768,12,32)$ and varies length
from 128 to 32,768.

\paragraph{Execution and measurement.}
All runs use one NVIDIA A800-SXM4-80GB, PyTorch 2.14.0 with CUDA 13.2,
FP32 parameters, BF16 inputs and autocast, and enabled TF32.
All three mixers use CUDA Graphs without \texttt{torch.compile}.
Forward--backward timing includes the mean squared output as a scalar loss
and its backward pass, without an optimizer step.
Forward-only timing uses inference mode.
Each process performs 20 warmup steps, captures the computation,
then performs 20 graph warmups.
CUDA events measure seven groups of 50 replays.
We report the mean of the median latencies from two independent processes,
reversing operator order in the second repetition.
For example, the two MemSolve forward--backward measurements at 2,048
tokens are 0.918 and 1.076\,ms; their mean is 0.997\,ms.
We reset PyTorch's peak allocated memory after the initial warmup and
measure through graph capture and replay.
This includes parameters, gradients, and intermediates;
allocator reserves and the CUDA context are excluded.
Tables~\ref{tab:mixer-efficiency} and~\ref{tab:mixer-forward} report

\section{Extended Related Work}
\label{app:related}

\subsection{Internal optimization and equilibrium models}

Internal learning can be implemented by solving for a state and then
reading from it. Intention makes this construction explicit in the
key--value--query setting \cite{garnelo2023intention}.
It fits a regularized regression model to embedded key--value pairs and
evaluates the fitted model at query embeddings. A learned transformation
can further process the fitted state. The solve thus becomes a composable
network module, connecting internal learning to attention-like computation.

Equilibrium models study how such internal states are defined and computed.
Deep equilibrium models define hidden states through fixed points
\cite{bai2019deep}, while monotone equilibrium models use operator
structure to guarantee well-posedness \cite{winston2020mondeq}.
These approaches make the properties of the state equation part of the
model design.

MemSolve connects these perspectives by designing the memory equation
together with its token readout. The same input-dependent frame writes
associations into memory and reads the response back to tokens.
Matching the regularizer to this frame makes the system matrix shared
across inputs, while the associations determine its right-hand side.
The accretive structure gives a unique state. The reflected readout then
links that structure to a bound on the output gain through the classical
accretive--Cayley correspondence \cite{bauschke2017convex}.
This joint design connects the solvability of the internal problem to
the behavior of the resulting token map.

\subsection{Kernel-based operator learning}

Normalized feature coordinates provide another connection: they can
gather values into a compact representation and redistribute them
across positions. ONO uses this structure to learn solution operators
for partial differential equations \cite{xiao2024ono}.
It represents a kernel through learned eigenfunctions and positive
eigenvalue weights. Cholesky whitening uses covariance statistics
aggregated over training samples and positions; running statistics are
reused at inference. Positive weights give a symmetric
positive-semidefinite kernel on the shared feature coordinates.

MemSolve instead normalizes its frame using the relation statistics of
each input. The identity shift produces a soft normalization: singular
values remain below one rather than being set to one.
The resulting frame therefore adapts the compact representation to the
current context. Within that representation, the Cayley-parameterized
core can express any real strict contraction, including nonsymmetric
maps. The connection to ONO lies in gathering and redistributing content
through normalized features. The normalization statistics and the map
between these features determine different forms of token interaction.

\subsection{Bidirectional state-space and linear-recurrence models}

Structured SSMs provide efficient sequence maps
\cite{gu2022s4,gu2024mamba,dao2024mamba2}.
Vim adapts selective scans to vision, Hydra develops bidirectional
matrix mixers, and LION relates full-attention, recurrent, and chunkwise
forms \cite{zhu2024vim,hwang2024hydra,afzal2025lion}.
Video DeltaNet combines local attention with bidirectional memory
updated jointly within each frame \cite{xi2026videodeltanet}.

For token interactions, the key question is how the two directional
responses are combined. With local parameterization, independent scans,
and linear merging, a fixed center token receives an additive prefix
response and suffix response. Changing the suffix leaves the prefix
response unchanged.

MemSolve uses the full input to normalize its frame. A suffix change can
therefore alter how prefix content contributes to the same center token.
Theorem~\ref{thm:ssm} establishes this distinction for the single-layer
scan class above. It is a distinction in the dependence of the output
on the input, rather than a choice between recurrent and parallel
evaluation. An equivalent recurrent or chunkwise implementation preserves
the interactions of its underlying operator. MemSolve's compact statistics
allow these context-dependent interactions to be evaluated in parallel,
with linear cost in sequence length at fixed rank.

\begin{abstract}
Error-correcting memories such as Gated Delta Networks learn associations by
writing prediction residuals into a compact state.
Bringing this mechanism to bidirectional contexts forces a trade-off.
Directional recurrences correct prefix and suffix memories separately, while a
direct full-context solve inverts a sequence-sized matrix at cubic cost.
We propose MemSolve, a sequence mixer in which all tokens jointly determine one
shared memory and the model solves directly for its equilibrium.
Matching the memory regularizer to an input-dependent write--read frame turns
this global correction into a well-posed compact linear system with a strictly
contractive readout, and it lets tokens interact in ways that locally
parameterized bidirectional scans cannot represent.
Two additive token reductions give linear complexity at fixed rank and exact
sequence parallelism, and our implementation runs $7.8\times$ faster than
FlashAttention at $8{,}192$ tokens in single-GPU forward--backward execution.
On ImageNet-1K, a plain $78$M-parameter MemSolve-ViT-B reaches $82.7\%$ Top-1
accuracy, surpassing ViG-B and ViT$^3$-B with about $13\%$ fewer parameters,
and it transfers competitively to COCO and ADE20K.
MemSolve-BERT averages $81.9$ on GLUE ($81.5$ with parameter-free RoVE), and
MemSolve achieves the highest average accuracy ($67.35\%$) across five Long
Range Arena tasks under a controlled backbone.
\end{abstract}


\section{Introduction}

Gated Delta Networks (GDNs) have advanced causal sequence modeling by writing
prediction errors back into memory
\cite{yang2025gdn,kimi2025linear,hatamizadeh2026gdn2}.
Self-attention keeps every token for retrieval \cite{vaswani2017attention},
whereas linear attention and state-space models (SSMs) compress the context
into a fixed-size state in which stored associations interfere as they
accumulate \cite{katharopoulos2020linear,gu2024mamba}.
The delta rule reduces this interference by predicting content from the
current memory and writing back only the error
\cite{schlag2021fastweights,yang2025deltanet}, so each update can revise what
is already stored.
GDNs add adaptive forgetting and write controls on top of this rule.

Error-correcting updates can also be read as training an internal predictor on
the context.
Test-time training (TTT) uses trainable inner models \cite{sun2025ttt},
Intention turns regularized regression into a composable module
\cite{garnelo2023intention}, and MesaNet builds causal memory states with
conjugate-gradient solves \cite{vonoswald2026mesanet}.
When the whole context is visible, this inner learning need not follow token
order, and ViT$^3$ finds that full-batch updates over all visual tokens
outperform sequential mini-batches \cite{han2026vit3}.
These results suggest letting every association act on one memory state at
once and solving for its equilibrium directly, instead of approximating it
with a few inner steps.

The obstacle is cost.
Recurrent models stay cheap because they update a compact state
incrementally, whereas a memory coupled across all tokens seems to require a
global solve.
LION keeps bidirectional DeltaNet tractable by correcting prefix and suffix
memories separately, and the direct full-attention form it discusses needs a
sequence-sized inverse whose cubic cost cancels the benefit of a compact state
\cite{afzal2025lion}.

We propose \textbf{MemSolve}, an operator that builds full-context associative
memory through one compact equilibrium solve.
We design the error-correction dynamics and the token readout together so that
the solve never leaves rank space.
All positions contribute association statistics in parallel and read context
back from the resulting equilibrium, which keeps the cost linear in sequence
length at fixed rank.
Our contributions are as follows.

\paragraph{Global Equilibrium ($\S$\ref{sec:joint-memory}, $\S$\ref{sec:readout}).}
A joint memory equation aggregates error corrections from all positions.
An input-dependent soft frame decides how associations enter memory and how the
solved response returns to tokens, and a matched regularizer reduces the system
to a learned accretive core shared across inputs.
The result is a unique equilibrium and, for each fixed frame, a strictly
contractive token map whose exact singular values are computable in compact
space.

\paragraph{Beyond Independent Directional Scans ($\S$\ref{sec:ssm}).}
Because MemSolve normalizes its frame over the whole sequence, a suffix token
can change how prefix content reaches a fixed center token.
Theorem~\ref{thm:ssm} uses a three-token example to show that no single
bidirectional SSM mixer with local coefficients and linear merging can
represent this map.

\paragraph{Parallel Algorithm ($\S$\ref{sec:implementation}).}
The exact operator decomposes into two additive token reductions, one shared
core solve, and independent token readouts.
Sequence shards exchange only compact statistics, the core is factored once per
head for the whole batch, and fused kernels never store the token-sized frame.
As a result, MemSolve overtakes FlashAttention at 196 tokens in complete-mixer
forward--backward execution (\S\ref{sec:efficiency}).

\paragraph{Architectures and Results ($\S$\ref{sec:experiments}).}
We use the same operator for image classification, dense prediction, masked
language modeling, and long-range sequence classification.
MemSolve-ViT reaches $81.0\%$ (Small, $20$M) and $82.7\%$ (Base, $78$M) Top-1
on ImageNet-1K and transfers to COCO and ADE20K with ViT-Adapter, MemSolve-BERT
averages $81.9$ on GLUE, and MemSolve leads a controlled comparison of ten
mixers on Long Range Arena.

\section{Background and Related Work}
\label{sec:background}

\paragraph{Error-correcting memory.}
Consider a memory $U\in\R^{r\times h}$ that predicts content $c_i\in\R^h$ from
a key $k_i\in\R^r$ as $U^\T k_i$.
A linear additive write accumulates $k_ic_i^\T$.
The delta rule instead writes back the prediction residual
\cite{schlag2021fastweights,yang2025deltanet}:
\begin{equation}
 e_i=c_i-U_{i-1}^\T k_i,\qquad U_i=U_{i-1}+\beta_i k_i e_i^\T,
 \label{eq:delta-background}
\end{equation}
where $\beta_i$ sets the write strength.
This update is one gradient step on the local loss
$\ell_i(U)=\tfrac12\norm{U^\T k_i-c_i}_2^2$, so each token acts as a training
example for the memory.
GDNs extend it with adaptive forgetting \cite{yang2025gdn}, channel-wise decay,
and separate erase and write gates \cite{kimi2025linear,hatamizadeh2026gdn2}.
Under sequential updates, each residual is evaluated at the intermediate state
$U_{i-1}$, so early tokens shape what later tokens see.
When the whole context is available, all residuals can instead be measured
against one shared state.

\paragraph{Memory as regression.}
TTT treats the hidden state as an inner model trained on the sequence
\cite{sun2025ttt}, and test-time regression unifies many memory mechanisms
under this view \cite{wang2025testtimeregression}.
Some methods solve the regression directly.
Intention fits a regularized key--value regression and evaluates it at query
embeddings \cite{garnelo2023intention}, and MesaNet runs conjugate gradients
over the causal context \cite{vonoswald2026mesanet}.
In the bidirectional setting, ViT$^3$ shows that full-batch inner updates beat
sequential mini-batches for visual recognition, although extra inner passes
cost throughput and stability \cite{han2026vit3}.
These solvers treat each sample separately.
MemSolve keeps the regression view but arranges the system so that its learned
part is shared across the batch (Appendix~\ref{app:related}).

\paragraph{Bidirectional mixers.}
BiMamba, Hydra, and LION let each token gather information from both
directions \cite{zhu2024vim,hwang2024hydra,afzal2025lion}.
Visibility alone does not say how the two sides interact, and
Section~\ref{sec:ssm} asks whether a suffix token can change how prefix content
reaches a fixed center token.
Appendix~\ref{app:related} covers equilibrium models and kernel operator
learning.

\section{MemSolve}
\label{sec:method}
\label{sec:theory}

MemSolve designs the memory equation and its token readout together.
Matching the regularizer to the input-dependent write--read coordinates yields
a compact linear system that every sample shares, and the same coordinates
carry the solution back to each token.
Equations in this section describe one head with $N$ valid tokens, memory rank
$r$, and content width $h$ in exact arithmetic, and
Appendix~\ref{app:proofs} gives all proofs.

\subsection{Joint error correction and compact equilibrium}
\label{sec:joint-memory}
\label{sec:equilibrium}

Let $C\in\R^{N\times h}$ hold the token content and let $P\in\R^{N\times r}$
assign each position write--read coordinates, so that a memory
$U\in\R^{r\times h}$ predicts the content as $PU$.
With rows $p_i^\T$ and $c_i^\T$, token $i$ has error
$e_i^\T=c_i^\T-p_i^\T U$, and summing the delta-rule writes of all tokens gives
$P^\T(C-PU)=\sum_ip_ie_i^\T$, with every error measured against the same state
$U$.
To stabilize this joint correction and let memory coordinates interact, we add
a positive-definite regularizer $\Gamma_X$ and a learned skew-symmetric
coupling $\Omega$:
\begin{equation}
 \dot U=P^\T(C-PU)-\Gamma_X U-\Omega U.
 \label{eq:joint-field}
\end{equation}
The regularizer $\Gamma_X$ damps the state, while $\Omega$ mixes coordinates
without changing
the Frobenius norm because $\langle U,\Omega U\rangle_F=0$.
MemSolve takes the memory to be the equilibrium of this field ($\dot U=0$):
\begin{equation}
 (P^\T P+\Gamma_X+\Omega)U^\star=P^\T C.
 \label{eq:joint-equilibrium}
\end{equation}
With a fixed regularizer, the Gram matrix $P^\T P$ would change from sample to
sample, and every input would need its own non-Hermitian $r\times r$
factorization.
We avoid this by matching $\Gamma_X$ to the frame Gram matrix so that all
samples share one learned system matrix $\I_r+J$, while the right-hand side
$P^\T C$ carries each input's associations.
Each head learns a compact core
\begin{equation}
 J=LL^\T+\Omega,\qquad LL^\T\succ0,\qquad\Omega^\T=-\Omega,
 \label{eq:core}
\end{equation}
built from a lower-triangular $L$ with positive diagonal and a skew-symmetric
$\Omega$ (Appendix~\ref{app:parameters}).
Its symmetric part $LL^\T$ is positive definite, so $J$ is strictly accretive.
Setting the system matrix in Eq.~\eqref{eq:joint-equilibrium} equal to
$\I_r+J$ fixes the regularizer as
\begin{equation}
 \Gamma_X=\I_r+LL^\T-P^\T P,
 \label{eq:gamma}
\end{equation}
and keeping $\Gamma_X\succ0$ for every input only requires $P^\T P\prec\I_r$.

A learned projection maps tokens $X$ to relation features
$B\in\R^{N\times r}$ and content $C$, and we set
\begin{equation}
 \begin{aligned}
 A&=B/\sqrt{N}, & R^\T R&=\I_r+A^\T A,\\
 P&=AR^{-1}, & Z&=P^\T C,
 \end{aligned}
 \label{eq:frame}
\end{equation}
where $R$ is the upper Cholesky factor with positive diagonal.
Scaling by $\sqrt N$ turns $A^\T A$ into an average second-moment matrix, so
the eigenvalues $g_i/(1+g_i)$ of $P^\T P=A^\T(\I_r+AA^\T)^{-1}A$ stay strictly
below one and do not drift toward one as more tokens write into the memory.
The contrast between strong and weak relation directions therefore does not
depend on sequence length.
Hence $\Gamma_X\succ0$, and we call the bounded coordinates $P$ a
\emph{soft frame} (Appendix~\ref{app:frame}).

Substituting Eq.~\eqref{eq:gamma} cancels the sample-dependent Gram term and
gives a closed-form equilibrium:
\begin{equation}
 \dot U=Z-(\I_r+J)U,\qquad U^\star=(\I_r+J)^{-1}Z.
 \label{eq:dynamics}
\end{equation}
Each input therefore needs only the symmetric positive-definite Cholesky
factorization $R^\T R=\I_r+A^\T A$ to form $Z$, and the non-Hermitian system
$\I_r+J$ is factored once per head for the whole batch.
The accretive core also makes this equilibrium unique and stable.

\begin{proposition}[Well-posed memory]
\label{prop:solve}
Let $\mu=1+\sigma_{\min}(L)^2>1$. Then Eq.~\eqref{eq:dynamics} has the unique
equilibrium $U^\star$, with
\begin{equation}
 \norm{(\I_r+J)^{-1}}_2\le\mu^{-1},\qquad
 \norm{(\I_r+J)^{-\T}}_2\le\mu^{-1},
\end{equation}
and every trajectory contracts exponentially as
$\norm{U(t)-U^\star}_F\le e^{-\mu t}\norm{U(0)-U^\star}_F$.
\end{proposition}

The bound $\mu^{-1}<1$ covers both the forward and the adjoint solve and does
not depend on $N$.
When $\Omega=0$, $U^\star$ is also the unique minimizer of the regularized
regression energy
\begin{equation}
 \mathcal E_X(U)=\tfrac12\norm{PU-C}_F^2+\tfrac12\tr(U^\T\Gamma_XU).
 \label{eq:objective}
\end{equation}
When $\Omega\ne0$, the field is no longer a gradient, but
Eq.~\eqref{eq:joint-equilibrium} stays a strongly monotone linear system with
the same guarantees.

\subsection{Token readout and contraction}
\label{sec:readout}
\label{sec:stability}

Reading $U^\star$ back directly would limit the compact response.
In the scalar case $j>0$, the factor $(1+j)^{-1}$ lies in $(0,1)$ and can only
shrink a feature, never flip its sign.
We therefore read out the reflected equilibrium $2U^\star-Z=FZ$, given by the
Cayley transform
\begin{equation}
 F=2(\I_r+J)^{-1}-\I_r=(\I_r+J)^{-1}(\I_r-J).
 \label{eq:reflection}
\end{equation}
Like the scalar reflection $(1-j)/(1+j)$, which covers $(-1,1)$, the matrix
version covers every real strict contraction in compact space, including
nonsymmetric ones (Appendix~\ref{app:coverage}).

Mapping $FZ$ back through $P$ acts only inside the $r$-dimensional relation
span, so we add a complementary content path that keeps the features
orthogonal to that span:
\begin{align}
 Y&=\eta(\I_N-PP^\T)C+PFP^\T C\\
 &=\underbrace{\eta C}_{\text{content}}
   +\underbrace{P(F-\eta\I_r)P^\T C}_{\text{contextual correction}},
 \label{eq:readout}
\end{align}
where $\eta=\tanh(\eta_{\rm raw})\in(-1,1)$ is a learned per-head scalar, and
equivalently $Y=\eta C+P[2U^\star-(1+\eta)Z]$.
The first line shows the geometric split between the complementary projector
and the compact response.
The second writes the output as a token-local content term plus a correction
of rank at most $r$, which is the form our parallel algorithm evaluates
(Section~\ref{sec:implementation}).
This readout is strictly contractive in token space for every realized frame.

\begin{theorem}[Contractive compact and token maps]
\label{thm:contraction}
The compact Cayley map $F$ in Eq.~\eqref{eq:reflection} satisfies
\begin{equation}
 \I_r-F^\T F=4(\I_r+J)^{-\T}LL^\T(\I_r+J)^{-1}\succ0.
\end{equation}
For any realized soft frame $P$, the induced token operator
\begin{equation}
 K_X=\eta(\I_N-PP^\T)+PFP^\T
 \label{eq:tokenmap}
\end{equation}
satisfies $\norm{K_X}_2\le\max\{|\eta|,\norm{F}_2\}<1$ and has rank bound
$\rank(K_X-\eta\I_N)\le r$, with $K_Xv=\eta v$ for all $v\in\ker(P^\T)$.
\end{theorem}

The token bound holds because $K_X$ is an isometric compression of the
block-diagonal contraction $\diag(\eta\I_N,F)$ (Appendix~\ref{app:spectrum}).
It concerns the linear map $C\mapsto K_XC$ at a fixed frame and does not bound
derivatives through $P(X)$ or the surrounding residual block.
All singular values of the $N\times N$ operator $K_X$ also follow exactly from
a compact matrix of size at most $r$ together with $|\eta|$.

Our default \textsc{Equilibrium} mode learns $F$ through $J$.
The ablated \textsc{Complement} mode drops the core by fixing $F=0$:
\begin{equation}
 Y_{\rm com}=\eta(\I_N-PP^\T)C=\eta(\I_N+AA^\T)^{-1}C,
 \label{eq:complement}
\end{equation}
where the second equality is the Woodbury identity \cite{golub2013matrix}.
Both modes learn the relation and content projections, $\eta$, and the output
projection, so both mix context in an input-dependent way.
\textsc{Equilibrium} starts at $J=\I_r$ ($F=0$), so training begins from the
\textsc{Complement} map with nonzero core gradients
(Appendix~\ref{app:parameters}).
Head outputs are concatenated and passed through a linear projection.

\paragraph{Optional rotary value encoding.}
RoVE \cite{garcia2026rove} injects relative position into the content path
without separating write and read coordinates.
It rotates each content vector $c_i$ by $O_i=O(t_i)$ before aggregation and
applies $O_i^\T$ to the contextual correction at readout:
\begin{equation}
 y_i=\eta c_i+\sum_j D_{ij}O_i^\T O_j c_j,
 \qquad D=P(F-\eta\I_r)P^\T.
 \label{eq:rove-readout}
\end{equation}
With a fixed frequency scale, $O_i^\T O_j=O(t_j-t_i)$ encodes relative offsets
in 1D sequences or axial offsets in 2D grids, adds no learned parameters, and
leaves the fixed-frame contraction bound intact (Appendix~\ref{app:rove}).

\subsection{Interactions beyond independent directional scans}
\label{sec:ssm}

The core $J$ is shared across inputs, yet token interactions still depend on
the whole context through the soft frame.
Because $P=AR^{-1}$ is normalized with the second moments of all tokens,
changing one token can change how a second token's content reaches a third,
even when $F=0$.
Take three tokens with normalized relations $A=(1,1,t)^\T$, content
$C=(s,0,0)^\T$, $F=0$, and $\eta\ne0$.
Eq.~\eqref{eq:complement} gives the middle output
\begin{equation}
 y_2=-\frac{\eta s}{3+t^2}.
 \label{eq:cross-context}
\end{equation}
The first two tokens stay fixed, yet the third token's relation $t$ changes the
coefficient $-\eta/(3+t^2)$ that carries the first token's content to the
second.

Single-layer directional scans cannot do this.
Consider bidirectional state-space mixers whose transitions depend only on the
current token and whose two directions merge linearly:
\begin{equation}
 \begin{aligned}
 h_i^+&=A^+(x_i)h_{i-1}^++b^+(x_i),\\
 h_i^-&=A^-(x_i)h_{i+1}^-+b^-(x_i),\\
 y_i&=C^+(x_i)h_i^++C^-(x_i)h_i^-+d(x_i),
 \end{aligned}
 \label{eq:ssm-class}
\end{equation}
with input-independent boundary states, arbitrary local coefficient functions,
and any state dimension.
Fixing the center token $x_i$ splits the output into
$y_i=f_i(x_{1:i})+g_i(x_{i:N})$, so a suffix change cannot alter how $y_i$
responds to the prefix.

\begin{theorem}[Separation from locally parameterized bidirectional SSMs]
\label{thm:ssm}
For every positive rank $r$, the MemSolve family contains a map that cannot
be represented by Eq.~\eqref{eq:ssm-class} across all inputs, regardless of
that mixer's state dimension. This separation holds for both Equilibrium and
Complement.
\end{theorem}

For Eq.~\eqref{eq:cross-context}, the mixed second difference
$y_2(1,1)-y_2(1,0)-y_2(0,1)+y_2(0,0)$ over $(s,t)\in\{0,1\}^2$ equals
$\eta/12$, whereas any additive decomposition gives zero
(Appendix~\ref{app:ssm} extends this to every rank).
The theorem covers single-layer mixers with local coefficients and linear
merging, and multi-layer stacks, nonlinear directional gates, or globally
conditioned scans form broader classes.

\section{Hardware-Aware Parallel Computation}
\label{sec:implementation}

Eq.~\eqref{eq:readout} splits the output into a token-local content path and a
low-rank correction.
We evaluate the correction from two compact summary statistics without ever
storing the $N\times r$ frame $P$, and the additivity of these statistics gives
exact sequence parallelism.

\subsection{Reduce, solve, and read out}

Substituting $P=AR^{-1}$ into Eq.~\eqref{eq:readout} writes the operator with
two token reductions and a compact readout matrix $W$:
\begin{equation}
 \begin{aligned}
 G&=A^\T A,\qquad H=A^\T C,\\
 R^\T R&=\I_r+G,\qquad Z=R^{-\T}H,\\
 W&=R^{-1}(F-\eta\I_r)Z,\\
 Y&=\eta C+AW.
 \end{aligned}
 \label{eq:nop}
\end{equation}
Here $G\in\R^{r\times r}$ collects the relation second moments that
normalize the frame, and $H\in\R^{r\times h}$ collects relation--content associations.
Together they summarize all the context the compact solve needs, after which
each token reads out its response from its own rows $a_i^\T$ and $c_i^\T$
(Fig.~\ref{fig:method}b and Algorithm~\ref{alg:compact-forward} in
Appendix~\ref{app:forward}, where \textsc{Complement} sets $F=0$).

The shared core $F$ is solved once per head in each forward pass.
Each sample then costs $O(Nr^2+Nrh+r^3+r^2h)$ operations and $O(r^2+rh)$
compact storage per head.
A longer sequence only adds work to the reductions and the readout $AW$, so
the whole mixer, projections included, stays linear in $N$ at fixed rank and
width.
For physical lengths $N\le r$, an equivalent token-space solve of size at most
$r$ avoids cancellation in the complementary term (Appendix~\ref{app:forward}).

\subsection{Exact sequence parallelism}

Since $G$ and $H$ are sums over token rows, MemSolve parallelizes across the
sequence without gathering activations.
With the sequence split over $p$ devices and each shard normalized by the
global valid count ($A_s=B_s/\sqrt N$), the statistics add up exactly,
$G=\sum_sA_s^\T A_s$ and $H=\sum_sA_s^\T C_s$.
One all-reduce therefore gives every device the global statistics at a cost of
$O(r^2+rh)$ per sample and head, independent of $N$.
Each device then solves for the same $W$ and computes its own output
$Y_s=\eta C_s+A_sW$.
The backward pass mirrors this with one all-reduce of a compact readout adjoint
(Algorithm~\ref{alg:sequence-parallel}), and outputs and gradients match
unsharded execution up to summation order.

\subsection{Selective fusion}

We fuse token-level work around the reductions and the readout, chain the
per-sample compact matrix products on chip, and keep the compact factorizations
in dedicated dense-solver kernels.
The backward kernels reuse the saved compact factors and accumulate
shared-core gradients across the batch in tiles, which avoids storing an
$r\times r$ core adjoint for every sample.
Our GPU backend combines Triton \cite{tillet2019triton} for tiled reductions
and readouts, cuSOLVERDx for register-level compact factorizations, and
cuBLASLt for projection gradients.
Compact statistics, factors, and adjoints stay in FP32.
The readout kernels split each sensitive FP32 coefficient of $W$ into a
leading and a residual BF16 word \cite{henry2019bfloat} and accumulate both
Tensor Core products in FP32 (Appendix~\ref{app:precision}).

\section{Discussion and Limitations}

MemSolve separates memory capacity from sequence length through a configurable
per-head rank $r$.
Across our vision, language, and long-range sequence benchmarks, a modest rank
($r\in\{16,32,48\}$) suffices to capture global context across sequences of up
to $4{,}096$ tokens.
Because each head compresses its full context into an $r\times h$ equilibrium
state, tasks requiring exact token-by-token copying or unbounded recall over
arbitrarily long inputs remain bounded by the bottleneck rank $r$.

While our evaluations cover ImageNet classification, COCO and ADE20K dense
prediction, GLUE language understanding, and Long Range Arena sequences up to
$4{,}096$ tokens, our masked-language pretraining is conducted at sequence
length $128$ following the LION M2 benchmark.
Scaling multi-node language and multimodal pretraining directly at
multi-thousand-token contexts using our RoVE content transport and exact
sequence-parallel reductions ($\S\ref{sec:implementation}$) is a natural
direction for future work.

\section{Conclusion}

MemSolve brings full-context error-correcting memory to bidirectional models
with a compact state and parallel execution.
All tokens write into one shared memory, and matching the regularizer to an
input-dependent soft frame turns global memory formation into a well-posed
compact equilibrium solve with a strictly contractive readout.
Two additive statistics give linear complexity at fixed rank and exact
sequence parallelism.
Results on ImageNet, COCO, ADE20K, GLUE, and Long Range Arena show that global
equilibrium solves are a practical foundation for scalable bidirectional
modeling.

\section{Extended Related Work}
\label{app:related}

\subsection{Internal optimization and associative memory}

Internal learning can be formulated by solving for an internal state on
context tokens and reading predictions back from that state.
Intention makes this paradigm explicit in the key--value--query setting
\cite{garnelo2023intention}: it fits a regularized regression model to
embedded key--value pairs, optionally applies a learned transformation to the
fitted state, and evaluates the resulting predictor at query embeddings,
turning the regression solve into a composable neural module.
MemSolve shares this regression view and fixes two of its choices.
Reads reuse the write frame, and the ridge shift grows with the number of
tokens, since in raw relation features $PP^\T=B(N\I_r+B^\T B)^{-1}B^\T$.
These two choices keep the token-space gain below one, and the matched
regularizer then leaves a single learned core shared across the batch.

MemSolve co-designs the equilibrium memory equation and its token readout
around a shared, input-dependent soft frame that both writes associations
into memory and reads the response back to tokens.
By matching the regularizer to this frame, the linear system matrix becomes
shared across inputs while the right-hand side aggregates each sample's
associations, allowing the full context to govern both the memory coordinates
and the content stored within them.

\subsection{Deep equilibrium models}
\label{app:deq}

Deep equilibrium models (DEQs) define hidden representations implicitly
through the fixed-point condition $z^\star=f_\theta(z^\star;X)$
\cite{bai2019deep}, replacing an explicit stack of weight-tied layers with a
root-finding solve in the forward pass and implicit differentiation in the
backward pass to save memory across depth.
Multiscale DEQ extends this formulation to coupled multi-resolution feature
maps for both image classification and semantic segmentation
\cite{bai2020multiscale}.

Subsequent work has focused on making equilibrium solves provably stable and
fast: monotone operator equilibrium networks (monDEQ) enforce strongly
monotone structure to guarantee unique equilibria and convergent splitting
solvers \cite{winston2020mondeq}, Jacobian regularization stabilizes forward
and backward iterations while reducing solver steps \cite{bai2021stabilizing},
and Lipschitz MDEQ bounds the fixed-point map's Lipschitz constant to ensure
convergence in both passes \cite{sato2026lipschitz}.

MemSolve brings this structured-equilibrium perspective to compact associative
memory, where the unknown state per head has dimension $r\times h$.
Once the input-dependent soft frame is formed, the equilibrium condition in
Eq.~\eqref{eq:dynamics} is linear in the memory state, allowing a single direct
factorization of the shared $r\times r$ core to replace iterative root
finding.
Strong monotonicity of the accretive core guarantees a unique equilibrium and
uniformly bounds both forward and adjoint solves (Proposition~\ref{prop:solve}),
while the reflected readout maps this core to a strictly contractive token
operator for each fixed frame via the classical accretive--Cayley
correspondence \cite{bauschke2017convex}.

\subsection{Kernel-based operator learning}

Gathering token values into a compact representation and redistributing them
through normalized feature coordinates also connects to kernel-based operator
learning.
Orthogonal Neural Operator (ONO) learns solution operators for partial
differential equations by representing a kernel through learned
eigenfunctions and positive eigenvalue weights \cite{xiao2024ono}, applying
Cholesky whitening based on covariance statistics aggregated across training
samples and positions (and reused as running statistics at inference) to
obtain a symmetric positive-semidefinite kernel.

MemSolve instead normalizes its soft frame using the exact relation statistics
of each individual input, with an identity shift that keeps singular values
strictly below one rather than whitening them to unit norm.
Within this context-adapted coordinate frame, the Cayley-parameterized core
can express any real strict contraction, including nonsymmetric maps, so both
the per-sample normalization and the compact core govern the resulting token
interactions.

\subsection{Bidirectional state-space and linear-recurrence models}

Structured state-space models (SSMs) provide hardware-efficient sequence maps
\cite{gu2022s4,gu2024mamba,dao2024mamba2} that have been adapted to
bidirectional vision and language modeling through selective scans in Vim,
bidirectional matrix mixers in Hydra, and unified recurrent/chunkwise/attention
formulations in LION \cite{zhu2024vim,hwang2024hydra,afzal2025lion}, as well
as frame-local bidirectional memory updates in Video DeltaNet
\cite{xi2026videodeltanet}.

From the standpoint of token interactions, the central question is how
forward and backward contexts combine: under local parameterization,
independent directional scans, and linear merging, fixing a center token
yields an additive sum of prefix and suffix responses, so perturbing the
suffix leaves the prefix response invariant.
Because MemSolve normalizes its write--read frame across the entire sequence,
a suffix perturbation can modulate how prefix content reaches that same
center token (Theorem~\ref{thm:ssm}).
Crucially, this separation reflects the functional dependence of outputs on
inputs rather than the choice between recurrent and parallel execution, and
MemSolve's compact summary statistics allow these globally coupled
interactions to be evaluated in parallel in $O(N)$ time at fixed rank.

\section{Proofs and Structural Details}
\label{app:proofs}

The soft-frame bound $P^\T P\prec\I_r$ ensures that the matched regularizer
$\Gamma_X$ is strictly positive definite and underpins our token-space
contraction proof.

\subsection{Soft-frame geometry}
\label{app:frame}

From $R^\T R=\I+A^\T A$ and $P=AR^{-1}$, we have
\begin{equation}
 PP^\T=A(\I+A^\T A)^{-1}A^\T,
\end{equation}
so the singular value decomposition of $A$ immediately yields
\begin{equation}
 \sigma_i(P)=\frac{\sigma_i(A)}{\sqrt{1+\sigma_i(A)^2}}<1.
 \label{eq:soft-singular}
\end{equation}
In particular, $P^\T P\prec\I_r$ and $PP^\T\prec\I_N$ even when $A$ is
rank-deficient, and applying the Woodbury identity gives
\begin{equation}
 \I_N-PP^\T=(\I_N+AA^\T)^{-1}\succ0,
\end{equation}
which establishes both Eq.~\eqref{eq:complement} and the strict positive
definiteness of $\Gamma_X$.
Moreover, because the reduced QR factorization of the augmented matrix
$[A^\T,\I_r]^\T$ (with positive-diagonal upper triangular factor $R$) has top
block $P=AR^{-1}$, the QR reference implementation and the compact Cholesky
formulation agree in exact arithmetic.

Scaling by $\sqrt N$ also bounds the conditioning of the Gram matrix
independently of sequence length: writing $b_i^\T$ for row $i$ of $B$, if the
average relation energy satisfies $N^{-1}\sum_i\norm{b_i}_2^2\le c$, then
$\norm{A}_2^2\le\norm{A}_F^2\le c$ and hence $\kappa_2(\I+A^\T A)\le1+c$ for
all $N$ (though length extrapolation accuracy remains a separate empirical
question).
Finally, without a positional module, the core operator is permutation
equivariant: permuting the rows of $(A,C)$ leaves $(G,H)$ invariant and
identically permutes the rows of $Y$, so positional structure is supplied by
the surrounding backbone or optional RoVE transport.

\subsection{Memory existence, sensitivity, and convergence}

Let $M=\I_r+J$. Because $\Omega$ is skew-symmetric, every real vector $v$
satisfies
\begin{equation}
 v^\T Mv=v^\T(\I_r+LL^\T)v\ge\mu\norm{v}_2^2,
 \qquad \mu=1+\sigma_{\min}(L)^2.
\end{equation}
By the Cauchy--Schwarz inequality, $\norm{Mv}_2\ge\mu\norm{v}_2$, which
implies that $M$ is invertible with $\norm{M^{-1}}_2\le1/\mu$ (and similarly
$\norm{M^{-\T}}_2\le1/\mu$).
Along any trajectory of Eq.~\eqref{eq:dynamics}, the error $E(t)=U(t)-U^\star$
satisfies $\dot E=-ME$, so
\begin{equation}
 \frac{d}{dt}\norm{E}_F^2
 =-2\tr(E^\T(\I_r+LL^\T)E)\le-2\mu\norm{E}_F^2,
\end{equation}
and Gr\"onwall integration completes the proof of Proposition~\ref{prop:solve}.
When $\Omega=0$, differentiating Eq.~\eqref{eq:objective} gives
$\nabla_U\mathcal E_X=MU-Z$ with positive-definite Hessian $M\succ0$ on each
column, whereas when $\Omega\ne0$ the field is non-conservative but retains
the same exponential contraction.

\subsection{Cayley contraction and coverage}
\label{app:coverage}

Because $M=\I+J$ commutes with $\I-J$, we have
\begin{align}
 \I-F^\T F
 &=M^{-\T}\left[M^\T M-(\I-J)^\T(\I-J)\right]M^{-1}\\
 &=2M^{-\T}(J+J^\T)M^{-1}
 =4M^{-\T}LL^\T M^{-1}\succ0.
\end{align}
Conversely, for any real strict contraction $F_0$ ($\norm{F_0}_2<1$),
$\I+F_0$ is invertible and its inverse Cayley transform satisfies
\begin{equation}
 J_0=(\I-F_0)(\I+F_0)^{-1},\qquad
 \sym(J_0)=(\I+F_0)^{-\T}(\I-F_0^\T F_0)(\I+F_0)^{-1}\succ0.
\end{equation}
Cholesky-factoring $\sym(J_0)=LL^\T$ and setting $\Omega=(J_0-J_0^\T)/2$ shows
that our triangular/softplus parameterization represents every such $L$ and
$\Omega$.
By the classical accretive--Cayley correspondence \cite{bauschke2017convex},
$F$ therefore covers all real strict contractions in compact space, while the
induced token map retains its shared-frame and rank-$r$ structure.

\subsection{Token contraction and the exact compact spectrum}
\label{app:spectrum}

Define $D=(\I_N-PP^\T)^{1/2}$ and stack $V_0=[D^\T,P]^\T$. Then
\begin{equation}
 V_0^\T V_0=\I_N,\qquad K_X=V_0^\T\diag(\eta\I_N,F)V_0,
 \label{eq:readout-compression}
\end{equation}
so $K_X$ is an isometric compression of the block-diagonal operator
$\diag(\eta\I_N,F)$, and submultiplicativity of the spectral norm immediately
yields the contraction bound in Theorem~\ref{thm:contraction}.
The rank and nullspace properties follow from
$K_X-\eta\I_N=P(F-\eta\I_r)P^\T$.

\begin{proposition}[Exact analysis in compact space]
\label{prop:spectrum}
Let $P=Q S V^\T$ be a thin singular value decomposition with
$k=\rank(P)$, $Q^\T Q=V^\T V=\I_k$, and positive diagonal $S$.
Then the token operator $K_X$ is orthogonally similar to
\begin{equation}
 \left[\eta\I_k+S V^\T(F-\eta\I_r)V S\right]
       \oplus\eta\I_{N-k}.
 \label{eq:certificate}
\end{equation}
Its singular values, including its exact spectral norm, can therefore be
computed from a compact matrix of size at most $r$, together with $N-k$
copies of $|\eta|$.
\end{proposition}

\begin{proof}
Extending $Q$ to an orthogonal basis $[Q,Q_\perp]$ of $\R^N$ restricts the
low-rank correction $P(F-\eta\I_r)P^\T$ to the first $k$ coordinates,
yielding Eq.~\eqref{eq:certificate} (reducing to $\eta\I_N$ when $k=0$ and
omitting the second block when $k=N$).
Because $V$ and $S$ can be obtained directly from the positive eigenspace of
the $r\times r$ matrix $P^\T P$, no $N\times N$ matrix construction or
token-space SVD is required.
\end{proof}

\subsection{Proof of the bidirectional SSM separation}
\label{app:ssm}

Fix the center token $x_i$ in Eq.~\eqref{eq:ssm-class}. Unrolling the forward
and backward recurrences from input-independent boundary states yields an
additive decomposition $y_i=f_i(x_{1:i})+g_i(x_{i:N})$, so for any prefix
perturbation $s$ and suffix perturbation $t$ that keep $x_i$ fixed, the mixed
finite difference vanishes identically:
\begin{equation}
 \Delta_{s,t}y_i
 =y_i(s_1,t_1)-y_i(s_1,t_0)-y_i(s_0,t_1)+y_i(s_0,t_0)=0,
 \label{eq:mixed-difference}
\end{equation}
regardless of the state dimension or nonlinear local coefficient functions.

For MemSolve, consider a three-token input whose two channels independently
supply relation and content coordinates: $x_1=(1,s)$, $x_2=(1,0)$, and
$x_3=(t,0)$.
A fixed relation projection scaled by $\sqrt3$ produces $A=(1,1,t)^\T$ after
the $\sqrt N$ normalization in Eq.~\eqref{eq:frame}, while the content
projection produces $C=(s,0,0)^\T$.
Setting $F=0$ gives
\begin{equation}
 PP^\T=\frac{AA^\T}{1+A^\T A},\qquad
 y_2=-\frac{\eta s}{3+t^2}.
\end{equation}
Evaluating the mixed difference at $(s_0,s_1)=(0,1)$ and $(t_0,t_1)=(0,1)$
yields
\begin{equation}
 \Delta_{s,t}y_2=-\frac{\eta}{4}+\frac{\eta}{3}
 =\frac{\eta}{12}\ne0.
\end{equation}
Consequently, no mixer of the form in Eq.~\eqref{eq:ssm-class} can represent
this MemSolve map across all inputs. For any rank $r>1$, padding the relation
projection with zero columns preserves the first Cholesky coordinate and the
output $y_2$ above.
Because \textsc{Complement} fixes $F=0$ and \textsc{Equilibrium} realizes
$F=0$ at $J=\I_r$, Theorem~\ref{thm:ssm} holds for both modes.

Note that this separation concerns how the operator depends functionally on
the input sequence, rather than the algebraic rank of a realized matrix at a
single fixed input: while any fixed-input MemSolve operator is a diagonal-plus-low-rank
matrix, its entries depend globally on the sequence norm in a way that local
scan coefficients cannot reproduce.

\section{Algorithms and Numerical Details}
\label{app:implementation}

The algorithms below specify MemSolve in exact arithmetic, covering padding
masks, short-sequence branches, and sequence-parallel reductions, followed by
their mixed-precision GPU realization in Section~\ref{app:precision}.

\subsection{Core parameters and initialization}
\label{app:parameters}

Each head parameterizes its accretive core through an unconstrained matrix
$\Theta\in\R^{r\times r}$ whose lower and upper triangular entries define
$L$ and $\Omega$:
\begin{align}
 L&=\tril(\Theta,-1)+\diag\!\left(
    \operatorname{softplus}(\diag\Theta+\log(e-1))\right),\\
 \Omega&=\triu(\Theta,1)-\triu(\Theta,1)^\T,\qquad J=LL^\T+\Omega.
 \label{eq:core-parameters}
\end{align}
Because the shifted softplus keeps $\diag(L)>0$, $LL^\T$ is strictly positive
definite. Initializing $\Theta=0$ sets $L=\I_r$, $J=\I_r$, and $F=0$, so
\textsc{Equilibrium} begins training from the \textsc{Complement} map while
preserving nonvanishing first-order core gradients ($\delta F=-\tfrac12\delta J$
at $J=\I_r$).

The per-head complementary gain $\eta=\tanh(\eta_{\rm raw})$ is initialized to
$0.9$ and evaluated in floating-point arithmetic as
\begin{equation}
 \eta_{\rm fp}=(1-\epsilon_{\rm mach})\tanh(\eta_{\rm raw}),\qquad
 \frac{d\eta_{\rm fp}}{d\eta_{\rm raw}}
 =(1-\epsilon_{\rm mach})\frac{4q}{(1+q)^2},\quad
 q=e^{-2|\eta_{\rm raw}|},
 \label{eq:eta-numerical}
\end{equation}
where $\epsilon_{\rm mach}$ is the machine epsilon of the scalar calculation
dtype (FP32 in CUDA).
Scaling by $1-\epsilon_{\rm mach}$ keeps $\eta_{\rm fp}$ strictly inside
$(-1,1)$, while evaluating the derivative via $q=e^{-2|\eta_{\rm raw}|}$
prevents gradient underflow when $\tanh(\eta_{\rm raw})$ rounds to $\pm1$ in
the tails.

\subsection{Forward computation}
\label{app:forward}

Algorithm~\ref{alg:compact-forward} lists the core forward computation of
Eq.~\eqref{eq:nop} for one sample and head.

\begin{algorithm}[H]
\caption{MemSolve: compact forward computation (one sample and head)}
\label{alg:compact-forward}
\begin{algorithmic}[1]
\Require Relations $B\in\R^{N\times r}$, content $C\in\R^{N\times h}$,
 shared $F$, scalar $\eta$, $N>r$ valid tokens
\Ensure Token output $Y\in\R^{N\times h}$
\State $A\gets B/\sqrt N$
\State $G\gets A^\T A,\quad H\gets A^\T C$ \Comment{Parallel token reductions}
\State $R\gets\Chol(\I_r+G)$ \Comment{$R^\T R=\I_r+G$}
\State $Z\gets\Solve(R^\T,H)$
\State $W\gets\Solve(R,(F-\eta\I_r)Z)$
\State \Return $\eta C+AW$ \Comment{Parallel token readout}
\end{algorithmic}
\end{algorithm}

Algorithm~\ref{alg:forward} extends Algorithm~\ref{alg:compact-forward} to
masked batches and short sequences ($N\le r$), with standard affine input and
output projections and an explicit output mask so projection biases cannot
leak into padded positions.
For a batch of physical length $N$, sample $b$ has $n_b$ valid tokens
indicated by the binary mask $m_b\in\{0,1\}^N$ (all-masked samples use a
divisor of $1$ and output zero).
Writing $\Solve(M,V)$ for the solution of $MU=V$ and $\Chol(S)$ for the upper
Cholesky factor $R$ satisfying $R^\T R=S$, we denote two-stage triangular
solves by
\begin{equation}
 \CholSolve(R,V)=\Solve\!\left(R,\Solve(R^\T,V)\right).
 \label{eq:cholsolve}
\end{equation}
While the shared core $M=\I_r+J$ is factored once via LU decomposition, when
$N\le r$ the complementary pathway evaluates $\eta\Solve(\I_N+AA^\T,C)$
directly in token space to avoid catastrophic cancellation in
$\eta(C-PP^\T C)$, ensuring that the largest matrix factorization has
dimension at most $r$ in both regimes.

\begin{algorithm}[!ht]
\caption{MemSolve forward without materializing $P$ (one head)}
\label{alg:forward}
\small
\begin{algorithmic}[1]
\Require $\{B_b\in\R^{N\times r},C_b\in\R^{N\times h},m_b\in\{0,1\}^N\}_{b=1}^{s}$,
 mode, $\eta$, and $\Theta\in\R^{r\times r}$ for Equilibrium
\Ensure Head outputs $\{Y_b\in\R^{N\times h}\}_{b=1}^{s}$
\If{mode is Equilibrium}
  \State Construct $L,\Omega,J$ from $\Theta$ using Eq.~\eqref{eq:core-parameters}
  \State $M\gets\I_r+J$, factor $M$ once
  \State $F\gets\Solve(M,\I_r-J)$ \Comment{Shared across this batch}
\Else
  \State $F\gets0$ \Comment{Complement}
\EndIf
\For{each sample $b$ in parallel}
  \State $n_b\gets\sum_i m_{b,i},\quad A\gets(m_b\odot B_b)/\sqrt{\max(n_b,1)},\quad C\gets m_b\odot C_b$
  \If{$N\le r$} \Comment{Physical length determines the branch}
    \State $R_N\gets\Chol(\I_N+AA^\T),\quad Y_b\gets\eta\,\CholSolve(R_N,C)$
    \If{mode is Equilibrium}
      \State $R\gets\Chol(\I_r+A^\T A),\quad Z\gets\Solve(R^\T,A^\T C)$
      \State $Y_b\gets Y_b+A\Solve(R,FZ)$
    \EndIf
  \Else
    \State $G\gets A^\T A,\quad H\gets A^\T C,\quad R\gets\Chol(\I_r+G)$
    \State $Z\gets\Solve(R^\T,H),\quad W\gets\Solve(R,(F-\eta\I_r)Z)$
    \State $Y_b\gets\eta C+AW$
  \EndIf
\EndFor
\State \Return $\{Y_b\}_{b=1}^{s}$
\end{algorithmic}
\end{algorithm}

For $N>r$, the backward pass below consumes $(A,C,R,W,Z)$ together with the
shared matrix $F$, which implementations may either save from the forward
pass or reconstruct from projections and compact intermediates
(\textsc{Equilibrium} also reuses $L$ and the LU factors of $\I_r+J$), so no
token-sized frame is ever stored.
When $N\le r$, standard automatic differentiation handles the token-space
expression alongside an analytic adjoint for the shared core solve.

\subsection{A common compact backward}
\label{app:backward}

Algorithm~\ref{alg:backward} differentiates Eq.~\eqref{eq:nop} for a single
sample and head, applying uniformly to both modes (with $F=0$ and its adjoint
discarded in \textsc{Complement}).
Here, an overbar denotes a loss adjoint under the Frobenius inner product,
$\sym(T)=(T+T^\T)/2$, and contributions from the direct content branch and
contextual correction are accumulated into $\overline C$ and $\overline\eta$
before returning, while projection gradients follow standard affine-layer rules.

For an upper Cholesky factor $R=\Chol(S)$, we define the Cholesky pullback
\begin{equation}
 \Phi_u(T)=\triu(T,1)+\tfrac12\diag(\diag T),\qquad
 \mathcal C(R,E_R)=R^{-1}\sym\!\left(\Phi_u(E_RR^\T)\right)R^{-\T},
 \label{eq:chol-adjoint}
\end{equation}
which gives the adjoint with respect to the symmetric matrix $S=R^\T R$ via
two triangular solves, derived by differentiating $S=R^\T R$ to obtain
$dR=\Phi_u(R^{-\T}(dS)R^{-1})R$.

\begin{algorithm}[!ht]
\caption{Rank-space backward ($N>r$, one sample and head)}
\label{alg:backward}
\small
\begin{algorithmic}[1]
\Require $E=\overline Y\in\R^{N\times h}$, forward values $A,C,R,W,Z,F,\eta$,
 fixed mask $m$ and valid count $n$
\Ensure $\overline B,\overline C_{\rm in}$, and contributions $\overline\eta,\overline F$
\State $E_W\gets A^\T E,\quad \overline A\gets EW^\T,\quad \overline C\gets\eta E$
\State $\overline\eta\gets\langle E,C\rangle_F$
\State $E_T\gets\Solve(R^\T,E_W)$
\State $\overline F\gets E_TZ^\T,\quad \overline\eta\gets\overline\eta-\langle E_T,Z\rangle_F$
\State $\overline Z\gets(F-\eta\I_r)^\T E_T,\quad \overline H\gets\Solve(R,\overline Z)$
\State $\overline R\gets-E_TW^\T-Z\overline H^\T$
\State $\overline G\gets\mathcal C(R,\overline R)$ \Comment{Eq.~\eqref{eq:chol-adjoint}}
\State $\overline A\gets\overline A+C\overline H^\T+A(\overline G+\overline G^\T)$
\State $\overline C\gets\overline C+A\overline H$
\State $\overline B\gets m\odot\overline A/\sqrt{\max(n,1)}$
\State $\overline C_{\rm in}\gets m\odot\overline C$
\State \Return $\overline B,\overline C_{\rm in},\overline\eta,\overline F$
\end{algorithmic}
\end{algorithm}

\paragraph{Reusing the inverse triangular factor.}
In the GPU implementation, we compute $T=R^{-\T}$ once and reuse it across
both forward and backward matrix products.
Writing $M_F=F-\eta\I_r$, $E_T=TE_W$, and $V=E_TZ^\T$, the compact adjoints
simplify directly in terms of $T$:
\begin{align}
 \overline H&=T^\T M_F^\T E_T,\\
 \overline G&=T^\T\operatorname{sym}_{\ell}
       (-M_FV^\T-M_F^\T V)T,
 \label{eq:inverse-factor-adjoint}
\end{align}
where $\operatorname{sym}_{\ell}(K)=[\tril(K)+\tril(K,-1)^\T]/2$, and the
core and scalar contributions reuse $V$ as $\overline F=V$ and
$\overline\eta=\langle E,C\rangle_F-\tr(V)$.

\subsection{Shared-core and scalar gradients}
\label{app:core-backward}

Writing $M=\I_r+J$, differentiating $F=M^{-1}(\I-J)$ gives
\begin{equation}
 dF=-M^{-1}(dJ)(\I+F).
 \label{eq:core-differential}
\end{equation}
Because the core is shared across the batch, its sample-level adjoints
$\overline F_b$ are summed prior to the single transposed LU solve in
Algorithm~\ref{alg:core-backward} (any batch-wide loss averaging is already
absorbed into $\overline Y$).
Our CUDA kernel accumulates this sum across tiles on the fly, avoiding
per-sample $r\times r$ adjoint storage.

\begin{algorithm}[!ht]
\caption{Shared-core backward (once per head, Equilibrium only)}
\label{alg:core-backward}
\small
\begin{algorithmic}[1]
\Require $E_F=\sum_b\overline F_b$, $\Theta,L,F$, and the saved factorization of $M=\I_r+J$
\Ensure Core-parameter gradient $\overline\Theta\in\R^{r\times r}$
\State $T\gets\Solve(M^\T,E_F)$ \Comment{Reuse the forward LU factors}
\State $\overline J\gets-T(\I_r+F)^\T$
\State $\overline L\gets(\overline J+\overline J^\T)L$
\State $d\gets\diag(\overline L)\odot\operatorname{sigmoid}(\diag\Theta+\log(e-1))$
\State $\overline\Theta\gets\tril(\overline L,-1)+\diag(d)+\triu(\overline J-\overline J^\T,1)$
\State \Return $\overline\Theta$
\end{algorithmic}
\end{algorithm}

Similarly, in both modes the scalar adjoints are summed over the batch before
applying the chain rule
$\overline{\eta_{\rm raw}}=(d\eta/d\eta_{\rm raw})\sum_b\overline\eta_b$,
where $d\eta/d\eta_{\rm raw}=1-\tanh^2(\eta_{\rm raw})$ in exact arithmetic
(and Eq.~\eqref{eq:eta-numerical} in floating-point execution).

\subsection{Sequence-parallel reductions}
\label{app:parallel}

Algorithm~\ref{alg:sequence-parallel} formulates exact sequence-parallel
execution for a sum of shard-local losses (a global mean simply normalizes
each local loss by the global token count).
Here, $\operatorname{VJP}_W$ denotes the compact pullback of
$(G,H,F,\eta)\mapsto W$ in Eq.~\eqref{eq:nop}, corresponding to the compact
steps of Algorithm~\ref{alg:backward} excluding the direct path $\eta C$.
All-reducing $E_W=\sum_s A_s^\T E_s$ provides every device with the exact
global compact adjoints, while $\overline\eta$ additionally accumulates the
all-reduced direct-content inner products $\langle E_s,C_s\rangle_F$.
To prevent overcounting replicated parameter gradients across the $p$
sequence shards, the implementation scales each device's shared-parameter
contributions by $1/p$ before the final data-parallel gradient reduction.

\begin{algorithm}[!ht]
\caption{Exact sequence-parallel MemSolve (one sample and head)}
\label{alg:sequence-parallel}
\small
\begin{algorithmic}[1]
\Require Local rows $B_s,C_s$, mask $m_s$, replicated $F,\eta$, $p$ devices,
 global physical length $N>r$
\Ensure Local output $Y_s$, local input gradients, and global parameter gradients
\State $n\gets\operatorname{AllReduceSum}(\sum_i m_{s,i})$
\State $A_s\gets(m_s\odot B_s)/\sqrt{\max(n,1)},\quad C_s\gets m_s\odot C_s$
\State $(G,H)\gets\operatorname{AllReduceSum}(A_s^\T A_s,A_s^\T C_s)$
\State $R\gets\Chol(\I_r+G),\quad Z\gets\Solve(R^\T,H)$
\State $W\gets\Solve(R,(F-\eta\I_r)Z),\quad Y_s\gets\eta C_s+A_sW$
\State \textbf{Backward:} receive local output adjoint $E_s$
\State $E_W\gets\operatorname{AllReduceSum}(A_s^\T E_s)$
\State $(\overline G,\overline H,\overline F,\overline\eta_W)
  \gets\operatorname{VJP}_W(G,H,F,\eta;E_W)$
\State $\overline A_s\gets E_sW^\T+C_s\overline H^\T+A_s(\overline G+\overline G^\T)$
\State $\overline C_s\gets\eta E_s+A_s\overline H$
\State $\overline\eta\gets\operatorname{AllReduceSum}(\langle E_s,C_s\rangle_F)+\overline\eta_W$
\State $\overline B_s\gets m_s\odot\overline A_s/\sqrt{\max(n,1)},\quad
 \overline C_{{\rm in},s}\gets m_s\odot\overline C_s$
\State Backpropagate local projection gradients and sum them across devices
\State Apply the shared-core adjoint to $\overline F$ once and retain one copy of $\overline\eta$
\end{algorithmic}
\end{algorithm}

Correctness follows immediately from the row-wise additivity of $(G,H)$ in
the forward pass and linearity of the adjoint reductions in the backward pass
($N>r$).
Because no recurrent state crosses shard boundaries, MemSolve requires no
inter-shard scan communication. When embedded in a backbone with a centered
depthwise convolution, only a lightweight boundary halo exchange is needed for
the convolution itself.

\subsection{Precision and scheduling}
\label{app:precision}
Our native CUDA backend supports ranks $r\in\{16,32,48,64\}$.
Token projections and reduction kernels use BF16 multiplicands with FP32
accumulation, while Gram matrices, compact states, triangular/LU factors, and
adjoints are stored in FP32.
Batched compact matrix products subtract the diagonal scalar $\eta$ in IEEE
FP32 before applying Triton's three-term TF32 decomposition, whereas compact
factorizations and linear solves retain strict IEEE FP32 arithmetic.
During token readout, the kernels split sensitive FP32 coefficients in $W$
into BF16 leading and residual words and accumulate both Tensor Core products
in FP32, recovering near-FP32 coefficient accuracy without falling back to
FP32 token operands (though under extreme mask sparsity and large relation
norms, subtraction in the compact complementary form can still amplify
relative rounding error).

\paragraph{Training implementation.}
All training runs were conducted on NVIDIA A800-SXM4-80GB GPUs using PyTorch
2.14.0, CUDA 13.2, and \texttt{timm} 1.0.29, combining \texttt{torch.compile}
for surrounding pointwise operations with CUDA Graph replay to amortize
launch overhead without altering the mathematical operator in
Section~\ref{sec:method}.

\subsection{Optional rotary value encoding}
\label{app:rove}

Let $\mathcal O$ apply planar rotations to each content row,
$(\mathcal O C)_i^\T=O_i c_i$, across all $h$ channels in adjacent pairs
($h$ even).
In compact form, RoVE modifies only the content reduction and final readout:
\begin{equation}
 \begin{aligned}
 \widetilde C&=\mathcal O C, &H&=A^\T\widetilde C, &Z&=R^{-\T}H,\\
 W&=R^{-1}(F-\eta\I_r)Z, &&Y=\eta C+\mathcal O^{-1}(AW),
 \end{aligned}
 \label{eq:rove-compact}
\end{equation}
leaving the Gram matrix $G$ and core solve unchanged in both
\textsc{Equilibrium} and \textsc{Complement} ($F=0$).
The inverse rotation $\mathcal O^{-1}$ wraps the entire contextual correction
(including $-\eta\I_r$) prior to the output projection, while the backward
pass applies transposed rotations around the same compact adjoints.
In CUDA, these $O(Nh)$ rotations are evaluated in FP32 and fused directly
into the reduction and readout kernels using the same leading-plus-residual
BF16 decomposition described in Appendix~\ref{app:precision}, with sequence
shards indexing global token positions under a shared frequency scale.

At any fixed frame $P$, writing $\mathcal K(C)=K_XC$ for the unrotated token
map in Eq.~\eqref{eq:tokenmap} shows that Eq.~\eqref{eq:rove-compact}
evaluates the orthogonal conjugation $\mathcal O^{-1}\mathcal K\mathcal O$,
which preserves all singular values and the strict contraction bound of
Theorem~\ref{thm:contraction}.
Following RoVE and YaRN \cite{garcia2026rove,peng2024yarn}, 1D sequences use
base frequencies $\omega_k=10000^{-2k/h}$ ($k=0,\ldots,h/2-1$, with optional
unit-amplitude YaRN frequency interpolation $\beta_{\rm fast}=32$,
$\beta_{\rm slow}=1$ beyond the training window), while 2D grids of shape
$H_g\times W_g$ apply axial rotations by partitioning the $h/2$ channel pairs
equally between row and column coordinates.
We evaluate 1D RoVE in MemSolve-BERT ($\S\ref{sec:language}$) and both 1D and
2D axial RoVE in Long Range Arena ($\S\ref{sec:lra}$).

\subsection{Efficiency benchmark}
\label{app:efficiency}

\paragraph{Mixers and shapes.}
We benchmark complete token mixers, including input and output projections,
across identical input shapes.
MemSolve runs in \textsc{Equilibrium} mode without RoVE or external positional
layers. FlashAttention uses \texttt{timm}'s packed-QKV attention module
backed by PyTorch's non-causal FlashAttention-2 SDPA kernel, and BiMamba uses
Vim's official fused v2 implementation (expansion factor 2, state dimension
16, causal convolution width 4, shared input/output projections, and averaged
bidirectional outputs).
The 196-token visual benchmarks use $(B,D,H,r)=(128,192,6,16)$,
$(128,384,6,32)$, and $(64,768,12,48)$ for Tiny, Small, and Base,
respectively (where $B$ is batch size, $D$ is channel width, $H$ is head
count, and $r$ is MemSolve rank), while the sequence-length sweep fixes
$(B,D,H,r)=(4,768,12,32)$ and varies $N$ from 128 to 32,768.

\paragraph{Execution and measurement.}
Benchmarks run on a single NVIDIA A800-SXM4-80GB GPU with PyTorch 2.14.0 and
CUDA 13.2, using FP32 parameters, BF16 inputs and autocast, TF32 enabled, and
CUDA Graphs (without \texttt{torch.compile}).
Forward--backward timings include evaluating the mean squared output loss and
full backward pass (excluding optimizer steps), whereas forward-only timings
run under inference mode.
Each process executes 20 eager warmup steps, captures the CUDA Graph, runs 20
graph warmup replays, and records CUDA event timings across seven groups of
50 replays. We report the mean of the median latencies from two independent
processes with reversed operator ordering (for instance, at 2,048 tokens the
two MemSolve forward--backward medians are $0.820$ and $0.840$\,ms, averaging
to $0.830$\,ms).
Peak allocated memory is reset after eager warmup and measured across graph
capture and replay, covering parameters, gradients, and intermediate
activations (excluding CUDA context and caching-allocator reserves).
Tables~\ref{tab:mixer-efficiency} and~\ref{tab:mixer-tiny} report
forward--backward results, and Table~\ref{tab:mixer-forward} reports
forward-only results.

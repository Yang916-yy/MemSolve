\begin{abstract}
Error-correcting associative memories update their state using the mismatch
between stored predictions and incoming content. For tasks with access to the
complete input, this raises a question: can all associations determine one
joint memory without an ordered sequence of updates? We introduce MemSolve,
a bidirectional token mixer that evaluates such a memory at equilibrium.
An input-dependent soft frame aggregates contextual associations, and a
learned accretive core defines a uniquely solvable correction system.
The same frame reads the memory back to tokens, combining a content branch
with a low-rank correction. This construction gives a contractive token map
for each realized frame and permits exact spectral analysis in rank space.
Although the core parameters are shared across inputs, both the frame and
the memory state remain input-dependent. A compact implementation avoids
materializing the frame and has linear cost in sequence length at fixed rank.
On ImageNet-1K, MemSolve-ViT-S reaches $80.95\%$ Top-1 accuracy with
$19.88$M parameters after 300 epochs at $224\times224$ resolution.
A matched ImageNet-100 study further finds that learning the compact core
improves accuracy over the content-complement variant.
\end{abstract}

\section{Introduction}

Error-correcting associative memories store contextual associations by
predicting their content and updating the memory from the residual. The
delta rule implements this mechanism through successive writes, while
test-time training (TTT) treats the state more generally as
an internal model adapted to the current context
\cite{schlag2021fastweights,yang2025deltanet,sun2025ttt}.

For visual recognition and other full-context tasks, all associations are
available together. An ordered update rule nevertheless makes each
correction depend on the memory left by earlier positions, introducing a
sequential dependency into a task that permits joint processing.
ViT$^3$ studies this issue in vision and finds that a full-batch inner update
can outperform sequential mini-batch updates. More inner steps can improve
accuracy, but also reduce throughput and may destabilize training
\cite{han2026vit3}. A natural alternative is to determine a memory that is
already consistent with the joint correction field.

Two obstacles must be resolved. First, exposing bidirectional interactions
does not by itself make error correction cheap. LION's Appendix~B.7 derives
bidirectional recurrent and chunkwise DeltaNet forms, but its discussed
full-attention expression requires an inverse with cubic cost in sequence
length \cite{afzal2025lion}. That expression can therefore lose the
computational advantage sought from a compact memory: doubling the sequence
length multiplies the inversion cost by eight. This is a limitation of that
formulation, rather than an impossibility result for bidirectional DeltaNet.
Second, a well-defined memory state is not enough. Its readout must control
how a compact correction acts on the much larger token space.

We address these obstacles by designing the memory coordinates, correction
system, and readout together. MemSolve maps relation features to a soft frame
whose singular values are below one. It then combines a positive-definite
component with a skew-symmetric coupling to define an accretive system in
rank space. The system has a unique equilibrium; its reflected resolvent
supplies the compact readout map. Using the same frame to write and read
makes the resulting token operator a scalar content map plus a rank-limited
correction, with a spectral norm strictly below one for every realized frame.
The solve dimension depends on the chosen rank, not the sequence length.

This design separates \emph{learning the correction law} from
\emph{adapting the memory state}. The core is learned across training samples,
whereas the frame, contextual statistic, and equilibrium state are computed
anew for each input. A sample-conditioned core generator is therefore not
required for input-dependent memory. This distinction also has a practical
consequence: each head's compact core map can be computed once per forward
pass and reused across the batch.

Intention studies global regression with query readout, and MesaNet develops
locally optimal test-time regression for causal sequence modeling
\cite{garnelo2023intention,vonoswald2026mesanet}. Building on this perspective,
our contribution is the joint construction of a shared soft frame, an
accretive correction law, and a complementary content path. This structure
connects three aspects of the mixer: a uniquely solvable memory, a
contractive readout with an exact compact spectral characterization, and
an implementation whose cost is linear in sequence length at fixed rank.
We evaluate it in a non-hierarchical visual backbone: MemSolve-ViT-S reaches
$80.95\%$ on ImageNet-1K, while a matched short-run comparison on
ImageNet-100 tests the contribution of the learned core.

\section{Related Work}

\paragraph{Error-correcting and test-time memories.}
Fast-weight models connect linear sequence layers with associative-memory
updates \cite{schlag2021fastweights}. DeltaNet replaces additive writes
with residual correction; its chunkwise formulation makes such updates
amenable to parallel training \cite{yang2025deltanet}. TTT uses an internal
learner as the sequence state \cite{sun2025ttt}, and test-time regression
provides a common language for several memory update rules
\cite{wang2025testtimeregression}. MesaNet solves contextual regression
problems with conjugate gradients \cite{vonoswald2026mesanet}.
MemSolve combines residual correction with a direct full-context solve.
Its correction field is defined jointly over the input, rather than by
composing causal memory updates.

\paragraph{Global regression and equilibrium layers.}
Intention maps keys and values to a regularized least-squares solution and
reads that solution with queries \cite{garnelo2023intention}. MemSolve couples
the write and read coordinates through a normalized frame and extends the
compact equilibrium map with a complementary content path. Deep equilibrium models and monotone equilibrium
networks also obtain representations through fixed points
\cite{bai2019deep,winston2020mondeq}. Here the equilibrium is a compact linear
system with a direct factorization. The Cayley transform and its relation to
accretive operators are classical \cite{bauschke2017convex}; we use this
relation to control the realized token mixer.

\paragraph{Bidirectional efficient mixers.}
Linear attention reorganizes feature interactions to avoid a quadratic
attention matrix \cite{katharopoulos2020linear}. Vision Mamba adapts selective
state-space modeling to visual inputs, Hydra constructs bidirectional matrix
mixers, and LION relates full-attention, recurrent, and chunkwise bidirectional
forms \cite{zhu2024vim,hwang2024hydra,afzal2025lion}.
MemSolve instead obtains a joint memory through sufficient statistics and a
rank-space solve. Its operator does not prescribe a spatial scan order.
For vision, we supply local spatial structure through conditional positional
encoding (CPE) \cite{chu2023cpe} in a plain backbone derived from
ViT$^3$ \cite{han2026vit3}.

\subsection{Relation features and a soft frame}

Consider one head with $N$ valid tokens, relation rank $r$, and content width
$h$. A learned projection produces relation features $B\in\R^{N\times r}$
and content $C\in\R^{N\times h}$ from the input $X$. Define
\begin{equation}
 A=\frac{B}{\sqrt{N}},\qquad
 R^\T R=\I_r+A^\T A,\qquad P=AR^{-1},\qquad Z=P^\T C,
 \label{eq:frame}
\end{equation}
where $R$ is the upper Cholesky factor with positive diagonal.
The same $P$ writes content into the statistic $Z\in\R^{r\times h}$ and
reads a compact state back to tokens. There is no independent query
projection. The $N^{-1/2}$ factor makes $A^\T A$ an average relation
second moment instead of an unnormalized sum.

The identity term in Eq.~\eqref{eq:frame} keeps the factorization
positive definite even when the relations are rank deficient. It also gives
\begin{equation}
 \sigma_i(P)=\frac{\sigma_i(A)}{\sqrt{1+\sigma_i(A)^2}}<1.
 \label{eq:soft-singular}
\end{equation}
We call $P$ a \emph{soft frame}: it is a contractive relation map, but its
columns are not generally orthonormal. In particular, $PP^\T$ and
$\I_N-PP^\T$ are not orthogonal projectors.

\subsection{A learned correction law and an input-dependent state}
\label{sec:equilibrium}

Each head learns a matrix $\Theta\in\R^{r\times r}$ shared across samples.
Its lower and upper triangular entries parameterize
\begin{align}
 L&=\tril(\Theta,-1)+\diag\!\left(
    \operatorname{softplus}(\diag\Theta+\log(e-1))\right),\\
 \Omega&=\triu(\Theta,1)-\triu(\Theta,1)^\T,\qquad
 J=LL^\T+\Omega.
 \label{eq:core}
\end{align}
Since $L$ has a positive diagonal, $LL^\T\succ0$; since
$\Omega^\T=-\Omega$, it contributes coupling without changing the symmetric
part of $J$. The equilibrium memory and compact map are
\begin{equation}
 U^\star=(\I_r+J)^{-1}Z,\qquad
 F=(\I_r+J)^{-1}(\I_r-J)=2(\I_r+J)^{-1}-\I_r.
 \label{eq:solve}
\end{equation}
In implementations, inverse notation denotes a linear solve.
$J$ and $F$ are shared across samples; $P$, $Z$, and $U^\star$ are not.

To see the error-correction interpretation, define
\begin{equation}
 \Gamma_X=\I_r+LL^\T-P^\T P\succ0.
 \label{eq:gamma}
\end{equation}
The memory dynamics become
\begin{align}
 \dot U&=\underbrace{P^\T(C-PU)}_{\text{association residuals}}
         -\underbrace{\Gamma_XU}_{\text{regularization}}
         -\underbrace{\Omega U}_{\text{skew coupling}}\\
       &=Z-(\I_r+J)U.
 \label{eq:dynamics}
\end{align}
The residual term sums all positions' prediction errors against the same
state. When $\Omega=0$, its equilibrium minimizes
\begin{equation}
 \mathcal E_X(U)=\tfrac12\norm{PU-C}_F^2+
                    \tfrac12\tr(U^\T\Gamma_XU).
 \label{eq:objective}
\end{equation}
For nonzero $\Omega$, the equilibrium solves the strongly monotone linear
equation $(\I_r+J)U=Z$, while the dynamics need not be a gradient flow of
this scalar objective.

The dependence of $\Gamma_X$ on $P$ is deliberate. It cancels the frame Gram
matrix in the total correction system, leaving the learned matrix
$\I_r+J$. This is a structured regularized-memory construction, not ordinary
ridge regression with an independently chosen scalar penalty. It is also
why the solve can be shared across samples without making their memories
identical. The dynamics explain the state; the forward pass computes that
state directly and does not choose an inner step count or learning rate.

\subsection{Content plus a compact correction}

The solve in Eq.~\eqref{eq:solve} maps the contextual statistic $Z$ to
$U^\star$. Reflecting this resolvent gives $2U^\star-Z=FZ$, a compact
contraction (Theorem~\ref{thm:contraction}). We lift this map through the
same frame used to write the memory and retain a content response through
$\I_N-PP^\T$. With a learned per-head scalar
$\eta=\tanh(\eta_{\rm raw})\in(-1,1)$, the resulting readout is
\begin{align}
 Y&=\eta C+P\left[2U^\star-(1+\eta)Z\right]\\
  &=\underbrace{\eta C}_{\text{content term}}
    +\underbrace{P(F-\eta\I_r)P^\T C}_{\text{rank-limited correction}}.
 \label{eq:readout}
\end{align}
Equivalently, $Y=\eta(\I_N-PP^\T)C+PFP^\T C$.
The factor two is inherited from the reflected resolvent in
Eq.~\eqref{eq:solve}; it is not an arbitrary output scale.
Head outputs are concatenated and passed through a learned output projection.

The default \textsc{Equilibrium} mode learns $F$ through $J$.
The \textsc{Complement} mode fixes $F=0$ and omits the core parameters:
\begin{equation}
 Y_{\rm com}=\eta(\I_N-PP^\T)C
            =\eta(\I_N+AA^\T)^{-1}C.
 \label{eq:complement}
\end{equation}
It is a nonzero, input-dependent mixer. The identity on the right is useful
for analysis; long sequences do not require a token-space inverse.
At initialization, $\Theta=0$ gives $L=\I_r$, $J=\I_r$, and $F=0$.
With identical remaining parameters, both modes therefore start from the
same function. The memory itself is $U^\star=Z/2$, not zero.
Equilibrium can subsequently learn a compact correction, while Complement
continues to learn the frame, content, output projection, and $\eta$.
We initialize $\eta$ to $0.9$.

\section{Properties of the Operator}
\label{sec:theory}

All statements in this section concern one head in exact arithmetic.
Proofs are in Appendix~\ref{app:proofs}.

\begin{proposition}[Well-posed memory]
\label{prop:solve}
Let $\mu=1+\sigma_{\min}(L)^2>1$. Then Eq.~\eqref{eq:dynamics} has the
unique equilibrium in Eq.~\eqref{eq:solve}, and
\begin{equation}
 \norm{(\I_r+J)^{-1}}_2\le\mu^{-1},\qquad
 \norm{(\I_r+J)^{-\T}}_2\le\mu^{-1}.
\end{equation}
Every trajectory obeys
$\norm{U(t)-U^\star}_F\le e^{-\mu t}\norm{U(0)-U^\star}_F$.
\end{proposition}

The bound controls sensitivity to the right-hand side in both the forward
and adjoint solves. The full parameter gradients additionally depend on the
projections, frame, and core parameterization; the system's condition number
also depends on $\norm{\I_r+J}_2$.

\begin{theorem}[Contractive compact and token maps]
\label{thm:contraction}
The map $F$ in Eq.~\eqref{eq:solve} satisfies
\begin{equation}
 \I_r-F^\T F=4(\I_r+J)^{-\T}LL^\T(\I_r+J)^{-1}\succ0.
\end{equation}
For a realized frame $P$, define
\begin{equation}
 K_X=\eta(\I_N-PP^\T)+PFP^\T.
 \label{eq:tokenmap}
\end{equation}
Then
$\norm{K_X}_2\le\max\{|\eta|,\norm{F}_2\}<1$ and
$\rank(K_X-\eta\I_N)\le r$.
Moreover, $K_Xv=\eta v$ for every $v\in\ker(P^\T)$.
\end{theorem}

This makes the division of work explicit: the content path preserves a
scaled response outside the relation span, while the learned core changes
interactions within that span. Sharing the write and read frame does not
force symmetry: when $F$ is nonsymmetric, $PFP^\T$ may be nonsymmetric too.
The accretive Cayley parameterization covers every real strict contraction
in $r$ dimensions (Appendix~\ref{app:coverage}); the rank and shared-frame
structure still constrain the token operator.

The norm bound is conditional on the realized frame. The nonlinear map
$X\mapsto K_XC(X)$ also differentiates through $P(X)$, and the surrounding
output projection and residual connection are unrestricted. We therefore do
not interpret Theorem~\ref{thm:contraction} as a global Lipschitz certificate
for the model or as a proof of generalization.

\begin{proposition}[Exact analysis in compact space]
\label{prop:spectrum}
Let $P=Q S V^\T$ be a thin singular value decomposition with
$k=\rank(P)$, $Q^\T Q=V^\T V=\I_k$, and positive diagonal $S$.
The token map is orthogonally similar to
\begin{equation}
 \left[\eta\I_k+S V^\T(F-\eta\I_r)V S\right]
       \oplus\eta\I_{N-k}.
 \label{eq:certificate}
\end{equation}
Its singular values, including its exact spectral norm, can therefore be
obtained from a matrix of size at most $r$, together with $N-k$ copies of
$|\eta|$.
\end{proposition}

Without a positional module, permuting input rows permutes the output rows:
$A^\T A$ and the shared core are unchanged. This is useful for unordered
full-context aggregation, but it does not encode positions by itself.
The visual backbone introduces spatial information separately through CPE.

\section{Compact Computation}
\label{sec:implementation}

The forward pass can eliminate the frame in Eq.~\eqref{eq:frame} by forming
the sufficient statistics
\begin{equation}
 G=A^\T A,\qquad H=A^\T C,\qquad R^\T R=\I_r+G.
\end{equation}
The forward pass is exactly
\begin{equation}
 Z=R^{-\T}H,\qquad
 W=R^{-1}(F-\eta\I_r)Z,\qquad Y=\eta C+AW.
 \label{eq:nop}
\end{equation}
This eliminates the token-sized intermediate $P$ and computes $F$ once per
head per forward pass. The core is recomputed on each forward pass.
Complement can instead solve
$(\I_r+G)D=H$ and use $Y=\eta(C-AD)$, avoiding the core solve entirely.
The current CUDA implementation uses a common factor-based computation for
both modes: it constructs $T=R^{-\T}$ once by solving triangular systems
with identity right-hand sides, then evaluates $Z=TH$ and
$W=T^\T(F-\eta\I_r)Z$, with $F=0$ for Complement. This replaces repeated
triangular dependencies with compact matrix products without changing the operator.

Per head, the mixer costs
$O(Nr^2+Nrh+r^3+r^2h)$, with token storage linear in $N$ and compact
storage $O(r^2+rh)$. Input and output projections add their usual dense-linear
costs, also linear in $N$ for fixed model dimensions. These bounds concern
sequence scaling; increasing rank still raises the cost of statistics and
factorizations. When physical $N\le r$, the implementation evaluates the
complementary term using the smaller positive-definite system
$\eta(\I_N+AA^\T)^{-1}C$. This algebraically equivalent branch avoids
subtraction of nearly equal terms for short, strong-relation inputs and
never creates a system larger than the supported rank.

Our CUDA implementation combines tiled token statistics and readout kernels
with library factorizations and compact solves. It uses Triton for token
operations and selective fusion, cuSOLVERDx for small factorizations and
solves, and cuBLASLt for projection gradients. The backward pass
uses analytic first-order derivatives for the rank-space path and reuses
compact factors. The short-sequence path differentiates its direct solves;
neither path backpropagates through an unrolled memory trajectory.
BF16 token operands are accumulated in FP32. Compact matrices and solves
remain in FP32, while sensitive readout coefficients are represented by a
BF16 leading part and a BF16 residual part, following the multiword
arithmetic principle of Henry et al.~\cite{henry2019bfloat}.
The output follows the activation dtype. Algorithms~\ref{alg:forward}--\ref{alg:core-backward}
in Appendix~\ref{app:implementation} specify the forward computation,
rank-space backward pass, and shared-core gradients.

\section{Experiments}
\label{sec:experiments}

fixed ImageNet-100 subset. Table~\ref{tab:architecture} also lists Tiny and

\subsection{Visual backbone and training}

MemSolve-ViT uses non-overlapping $16\times16$ patches and twelve blocks at a
constant width. Each block first adds a residual $3\times3$ depthwise CPE,
then applies a pre-LayerNorm MemSolve branch and a pre-LayerNorm GELU FFN
branch, each with a residual connection and stochastic depth.
A final per-token LayerNorm precedes mean pooling and a linear classifier.
There is no class token, absolute position table, LayerScale, or internal
rotary transform. Table~\ref{tab:architecture} specifies the configurations.

\subsection{Does the learned core contribute?}
\label{sec:ablation}

We compare Equilibrium with Complement on the 100 ImageNet classes used in
the public CMC class list\footnote{\url{https://github.com/HobbitLong/CMC/blob/master/imagenet100.txt}}.
Both use the Small backbone, a 100-class classifier, rank 32, seed 0,
and the same initialization for every shared parameter.
The two modes have the same initial mathematical function, since $F=0$;
only Equilibrium has trainable core parameters. We train each for 30 epochs
with batch 512, a five-epoch warmup, peak learning rate $5\times10^{-4}$,
and a full 30-epoch cosine schedule. Other augmentation and optimizer
settings follow the no-RA configuration above.

\section{Discussion and Limitations}

MemSolve concentrates global interaction in a learned relation span.
This gives a direct computational tradeoff: larger ranks can represent more
independent interaction directions, but increase statistics and factorization
costs. The shared frame also couples writing and reading, whereas separate
query and key projections permit different association geometries.
The present results support the shared construction for image classification;
tasks requiring distinct write and read coordinates remain an open direction.

The shared solve relies on co-designing the regularizer with the frame.
Changing the memory objective may require a different factorization and
readout analysis. Empirically, the present evaluation covers a Small visual
backbone and a short core comparison. Larger models, language tasks, and
longer sequences will test how broadly this construction applies. Repeated
runs are also needed to quantify the training variance of the reported
single-seed results.

\section{Conclusion}

MemSolve constructs a full-context associative memory by solving a compact
correction system. A shared soft frame connects memory formation to a
content-plus-correction readout, allowing the solve, contraction, and token
spectrum to be analyzed within one formulation. The learned core is shared
across samples while the memory remains input-dependent. Compact statistics
make this formulation executable without a token-sized frame, and the
completed image-classification experiments demonstrate that the resulting
plain backbone is competitive at Small scale.

\section{Proofs and Structural Details}
\label{app:proofs}

\subsection{Soft-frame geometry}

Since $R^\T R=\I+A^\T A$,
\begin{equation}
 PP^\T=A(\I+A^\T A)^{-1}A^\T.
\end{equation}
An SVD of $A$ gives Eq.~\eqref{eq:soft-singular}. In particular,
$P^\T P\prec\I_r$ and $PP^\T\prec\I_N$, including rank-deficient cases.
The Woodbury identity yields
\begin{equation}
 \I_N-PP^\T=(\I_N+AA^\T)^{-1}\succ0,
\end{equation}
which proves Eq.~\eqref{eq:complement} and positivity of $\Gamma_X$.
The reduced QR factorization of $[A^\T,\I_r]^\T$ with a positive diagonal
in its triangular factor has top block $P$. Thus the QR reference and the
compact Cholesky construction agree in exact arithmetic.

Normalization by $\sqrt N$ has a specific, limited role. If
$N^{-1}\sum_i\norm{b_i}_2^2\le c$, then
$\norm{A}_2^2\le\norm{A}_F^2\le c$ and
$\kappa_2(\I+A^\T A)\le1+c$, independently of $N$.
This conditional bound prevents sequence length alone from scaling the
Gram matrix; it does not assume that feature energy is bounded throughout
training or imply accuracy under length extrapolation.

\subsection{Memory existence, sensitivity, and convergence}

Write $M=\I_r+J$. For every real $v$,
\begin{equation}
 v^\T Mv=v^\T(\I_r+LL^\T)v\ge\mu\norm{v}_2^2,
 \qquad \mu=1+\sigma_{\min}(L)^2.
\end{equation}
Cauchy--Schwarz gives $\norm{Mv}_2\ge\mu\norm{v}_2$, so $M$ is invertible
and $\norm{M^{-1}}_2\le1/\mu$. The same argument applies to $M^\T$.
For $E(t)=U(t)-U^\star$, $\dot E=-ME$ and
\begin{equation}
 \frac{d}{dt}\norm{E}_F^2
 =-2\tr(E^\T(\I_r+LL^\T)E)\le-2\mu\norm{E}_F^2.
\end{equation}
Integration proves Proposition~\ref{prop:solve}.
For $\Omega=0$, differentiating Eq.~\eqref{eq:objective} gives
$\nabla_U\mathcal E_X=MU-Z$ and Hessian $M\succ0$ for each content column.
When $\Omega\ne0$, the nonsymmetric field need not be a scalar gradient,
although the same convergence argument holds.

\subsection{Cayley contraction and coverage}
\label{app:coverage}

As $M=\I+J$ commutes with $\I-J$,
\begin{align}
 \I-F^\T F
 &=M^{-\T}\left[M^\T M-(\I-J)^\T(\I-J)\right]M^{-1}\\
 &=2M^{-\T}(J+J^\T)M^{-1}
 =4M^{-\T}LL^\T M^{-1}\succ0.
\end{align}
Conversely, let $F_0$ be any real matrix with $\norm{F_0}_2<1$.
Then $\I+F_0$ is invertible and
\begin{equation}
 J_0=(\I-F_0)(\I+F_0)^{-1},\qquad
 \sym(J_0)=(\I+F_0)^{-\T}(\I-F_0^\T F_0)(\I+F_0)^{-1}\succ0.
\end{equation}
Factor $\sym(J_0)=LL^\T$ and set
$\Omega=(J_0-J_0^\T)/2$. The triangular/softplus parameterization can
represent every such $L$ and $\Omega$. This establishes coverage of the
strict contraction ball in compact space. It is an application of the
classical accretive--Cayley correspondence, not an unrestricted token-map
universality statement.

\subsection{Token contraction and the exact compact spectrum}

Let $D=(\I_N-PP^\T)^{1/2}$ and
$V_0=[D^\T,P]^\T\in\R^{(N+r)\times N}$, so $V_0^\T V_0=\I_N$.
Then
\begin{equation}
 K_X=V_0^\T\diag(\eta\I_N,F)V_0,
\end{equation}
which proves the norm bound in Theorem~\ref{thm:contraction}.
The rank and nullspace statements follow directly from
$K_X-\eta\I_N=P(F-\eta\I_r)P^\T$.

For Proposition~\ref{prop:spectrum}, extend $Q$ to an orthogonal basis
$[Q,Q_\perp]$. In this basis the low-rank correction acts only on the first
$k$ coordinates, giving Eq.~\eqref{eq:certificate}. If $k=0$, the result is
simply $\eta\I_N$; if $k=N$, the complementary block is absent.
One may compute $V$ and $S$ from the positive eigenspace of $P^\T P$, so no
$N\times N$ matrix or token-space SVD is required.

\section{Algorithms and Numerical Details}
\label{app:implementation}

\subsection{Forward computation}
\label{app:forward}

Algorithm~\ref{alg:forward} gives the computation for one head across a
batch; heads can be evaluated independently. The projections into $B,C$
and the output projection are ordinary affine layers. The algorithm returns
head outputs, which are concatenated, projected, and masked again so that
an output bias cannot populate padded positions.

We distinguish physical length $N$ from the number $n_b$ of valid tokens
in sample $b$. Masks multiply rows and are held fixed under differentiation.
We use $\Solve(M,V)$ for the solution of $MU=V$,
$\Chol(S)$ for the upper factor $R$ such that $R^\T R=S$, and
\begin{equation}
 \CholSolve(R,V)=\Solve\!\left(R,\Solve(R^\T,V)\right).
 \label{eq:cholsolve}
\end{equation}
The solve notation specifies exact-arithmetic dependencies; a general core
system uses an LU factorization. CUDA constructs the inverse triangular factor
$T=R^{-\T}$ with library triangular solves and reuses it in forward and backward
products. It does not form a dense inverse of the token-space operator.
The pseudocode also gives the equivalent Complement-specific derivative for
clarity; the implementation shares the inverse-factor adjoint between modes.
For lower factor $L_R=R^\T$, set $M_F=F-\eta\I_r$,
$U=TE_W$, and $V=UZ^\T$. The common compact adjoints are
$\overline H=T^\T M_F^\T U$ and
$\overline G=T^\T\operatorname{sym}_{\ell}(-M_FV^\T-M_F^\T V)T$,
where $\operatorname{sym}_{\ell}(K)=[\tril(K)+\tril(K,-1)^\T]/2$.
The shared-core and scalar adjoints reuse $V$.
Appendix~\ref{app:precision} gives the execution precision and fusion choices.

\begin{algorithm}[!ht]
\caption{MemSolve forward without materializing $P$ (one head)}
\label{alg:forward}
\small
\begin{algorithmic}[1]
\Require $\{B_b\in\R^{N\times r},C_b\in\R^{N\times h},m_b\in\{0,1\}^N\}_{b=1}^{s}$;
 mode, $\eta$; $\Theta\in\R^{r\times r}$ for Equilibrium
\Ensure Head outputs $\{Y_b\in\R^{N\times h}\}_{b=1}^{s}$
\If{mode is Equilibrium}
  \State Construct $L,\Omega,J$ from $\Theta$ using Eq.~\eqref{eq:core}
  \State $M\gets\I_r+J$; factor $M$ once
  \State $F\gets\Solve(M,\I_r-J)$ \Comment{Shared across this batch}
\EndIf
\For{each sample $b$ in parallel}
  \State $n_b\gets\sum_i m_{b,i}$; $A\gets(m_b\odot B_b)/\sqrt{\max(n_b,1)}$; $C\gets m_b\odot C_b$
  \If{$N\le r$} \Comment{Physical length determines the branch}
    \State $R_N\gets\Chol(\I_N+AA^\T)$; $Y_b\gets\eta\,\CholSolve(R_N,C)$
    \If{mode is Equilibrium}
      \State $R\gets\Chol(\I_r+A^\T A)$; $Z\gets\Solve(R^\T,A^\T C)$
      \State $Y_b\gets Y_b+A\Solve(R,FZ)$
    \EndIf
  \Else
    \State $G\gets A^\T A$; $H\gets A^\T C$; $R\gets\Chol(\I_r+G)$
    \If{mode is Equilibrium}
      \State $Z\gets\Solve(R^\T,H)$; $W\gets\Solve(R,(F-\eta\I_r)Z)$
    \Else \Comment{Complement}
      \State $D\gets\CholSolve(R,H)$; $W\gets-\eta D$
    \EndIf
    \State $Y_b\gets\eta C+AW$
  \EndIf
\EndFor
\State \Return $\{Y_b\}_{b=1}^{s}$
\end{algorithmic}
\end{algorithm}

For $N>r$, backward needs $A,C,R,W$ and either $Z$ or $D$; these can be
saved or reconstructed from saved projections and compact quantities.
Equilibrium also reuses $F$, $L$, and the factorization of $M$ across the
batch. No token-sized frame is needed. For $N\le r$, the implementation
differentiates the short direct-solve expression using automatic
differentiation, with an analytic adjoint for the shared linear solve.
The largest factorization in either branch is at most $r\times r$.

\paragraph{Initialization and scalar parameterization.}
An all-masked input uses a safe divisor of one and yields zero.
The floating-point implementation uses an interior form of $\tanh$ for
$\eta$ to avoid rounding to the endpoints. The theoretical parameterization
uses the open interval $(-1,1)$.
Core initialization $\Theta=0$ does not remove its training signal:
$\delta F=-\tfrac12\delta J$ at $J=\I_r$, so the core can receive gradients
although its initial forward correction $PFP^\T C$ is zero.

\subsection{Rank-space backward and shared-core gradients}
\label{app:backward}

Algorithm~\ref{alg:backward} differentiates the $N>r$ branch for one sample
and head. A bar denotes the adjoint of a variable under the Frobenius inner
product, and $\sym(T)=(T+T^\T)/2$. The algorithm includes both the direct
content term and the correction, so that their contributions to $\eta$ and
$C$ are accumulated together. Projection gradients then follow the usual
affine-layer rules.

For an upper Cholesky factor $R$, define
\begin{equation}
 \Phi_u(T)=\triu(T,1)+\tfrac12\diag(\diag T),\qquad
 \mathcal C(R,E_R)=R^{-1}\sym\!\left(\Phi_u(E_RR^\T)\right)R^{-\T}.
 \label{eq:chol-adjoint}
\end{equation}
Here $\mathcal C$ is the adjoint of $R=\Chol(S)$ with respect to the
symmetric matrix $S$; the inverse notation again means two triangular
solves. To obtain it, differentiate $S=R^\T R$ and observe that
$dR=\Phi_u(R^{-\T}(dS)R^{-1})R$. This also fixes the half-diagonal
convention in Eq.~\eqref{eq:chol-adjoint}.

\begin{algorithm}[!ht]
\caption{Rank-space backward ($N>r$, one sample and head)}
\label{alg:backward}
\small
\begin{algorithmic}[1]
\Require $E=\overline Y\in\R^{N\times h}$; forward values $A,C,R,W,\eta$;
 mode; $F,Z$ for Equilibrium or $D$ for Complement; fixed mask $m$ and count $n$
\Ensure $\overline B,\overline C_{\rm in}$; per-sample contributions $\overline\eta,\overline F$
\State $E_W\gets A^\T E$; $\overline A\gets EW^\T$; $\overline C\gets\eta E$
\State $\overline\eta\gets\langle E,C\rangle_F$; $\overline F\gets0$
\If{mode is Equilibrium}
  \State $E_T\gets\Solve(R^\T,E_W)$
  \State $\overline F\gets E_TZ^\T$; $\overline\eta\gets\overline\eta-\langle E_T,Z\rangle_F$
  \State $\overline Z\gets(F-\eta\I_r)^\T E_T$; $\overline H\gets\Solve(R,\overline Z)$
  \State $\overline R\gets-E_TW^\T-Z\overline H^\T$
  \State $\overline G\gets\mathcal C(R,\overline R)$ \Comment{Eq.~\eqref{eq:chol-adjoint}}
\Else \Comment{Complement: $D=(\I_r+G)^{-1}H$}
  \State $T\gets\CholSolve(R,E_W)$
  \State $\overline H\gets-\eta T$; $\overline G\gets\eta\sym(TD^\T)$
  \State $\overline\eta\gets\overline\eta-\langle E_W,D\rangle_F$
\EndIf
\State $\overline A\gets\overline A+C\overline H^\T+A(\overline G+\overline G^\T)$
\State $\overline C\gets\overline C+A\overline H$
\State $\overline B\gets m\odot\overline A/\sqrt{\max(n,1)}$; $\overline C_{\rm in}\gets m\odot\overline C$
\State \Return $\overline B,\overline C_{\rm in},\overline\eta,\overline F$
\end{algorithmic}
\end{algorithm}

For $F=M^{-1}(\I-J)$, differentiation gives
\begin{equation}
 dF=-M^{-1}(dJ)(\I+F).
 \label{eq:core-differential}
\end{equation}
Since the core is shared, its adjoints are summed over samples before the
transposed solve in Algorithm~\ref{alg:core-backward}. The reduction is a
sum: any loss averaging is already contained in $\overline Y$. The fast
path accumulates this reduction in tiles rather than storing one
$r\times r$ core adjoint per sample.

\begin{algorithm}[!ht]
\caption{Shared-core backward (once per head, Equilibrium only)}
\label{alg:core-backward}
\small
\begin{algorithmic}[1]
\Require $E_F=\sum_b\overline F_b$; $\Theta,L,F$ and the saved factorization of $M=\I_r+J$
\Ensure Core-parameter gradient $\overline\Theta\in\R^{r\times r}$
\State $T\gets\Solve(M^\T,E_F)$ \Comment{Reuse the forward LU factors}
\State $\overline J\gets-T(\I_r+F)^\T$
\State $\overline L\gets(\overline J+\overline J^\T)L$
\State $d\gets\diag(\overline L)\odot\operatorname{sigmoid}(\diag\Theta+\log(e-1))$
\State $\overline\Theta\gets\tril(\overline L,-1)+\diag(d)+\triu(\overline J-\overline J^\T,1)$
\State \Return $\overline\Theta$
\end{algorithmic}
\end{algorithm}

For either mode, $\overline{\eta_{\rm raw}}=
(d\eta/d\eta_{\rm raw})\sum_b\overline\eta_b$.
The mathematical derivative is $1-\tanh^2(\eta_{\rm raw})$.
The implementation evaluates the interior-scaled value with native $\tanh$
and its derivative through the exponential identity. This retains small values
near zero and representable tail derivatives after $\tanh$ itself rounds to an endpoint.
The implementation supports first-order training gradients; higher-order
differentiation is not provided by the fast path.

\subsection{Precision and scheduling}
\label{app:precision}
The fast path supports ranks 16, 32, 48, and 64. Token projections and
statistics use BF16 multiplicands and FP32 accumulation. Gram matrices,
compact states, factorization results, and adjoints retain FP32 storage.
Batched compact products use Triton's three-term TF32 decomposition;
small shared-core products and solves retain IEEE FP32 arithmetic.
Readout kernels split sensitive FP32 coefficients into BF16 leading and
residual words before accumulating both products in FP32.
This retains additional coefficient precision without promoting token-sized
matrix products to FP32 operands. Completely masked inputs are covered explicitly. Very sparse masks
with strong relations can still amplify relative cancellation error in the
rank-space complementary readout; this is a finite-precision boundary,
not a change in the exact operator.

\paragraph{Measured implementation scope.}
The completed training runs used NVIDIA A800-SXM4-80GB GPUs, PyTorch
2.14.0 with CUDA 13.2, and timm 1.0.29. Compilation fuses surrounding
operations; CUDA Graph replay reduces launch overhead. These execution
choices do not alter Eqs.~\eqref{eq:frame}--\eqref{eq:readout}.

latency numbers from older operator implementations or claiming a matched
